# Code Review Workflow

针对当前代码变更或指定模块应用团队代码审查标准。

## 审查范围
- 用户指定的文件或模块，若未指定则审查 `git status` / `git diff` 识别出的所有变更。

## 审查维度
1. **主流程安全**：是否安全捕获所有异常并返回 `df.attrs['__error__']`，严禁直接 raise 破坏主流程。
2. **并发与文件锁**：是否存在 Windows 文件锁竞争或主线程 I/O 阻塞。
3. **架构原则**：KISS (简洁直观)、YAGNI (不预留无用逻辑)、SOLID 与 DRY (无重复逻辑)。
4. **性能与图元**：是否引入对象池、脏检查、内存缓存保护。
5. **文件编码**：是否保持 UTF-8（无 BOM）格式。

## 输出
- 生成格式化 Review 报告，按 **Critical**、**Important**、**Minor** 分级呈现发现与具体修改建议。
