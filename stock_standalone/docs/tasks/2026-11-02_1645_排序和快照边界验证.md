# 排序与快照边界验证

- 价格排序仅在交易日、成员、排序列一致，且没有重点置顶、缺失值、并列或可能交叉时，允许在排序开启状态下原位更新；比较区间同时覆盖旧原始值、两位小数文本中间值和新原始值。其他情况保持 Qt 原排序，不能保证排序长尾已消失。
- 隔离 Qt offscreen 对比：1000 行不同价格、40 次每 100ms 更新，Git 暂存版基线的事件循环采样 p95/p99/max 为 44.41/61.13/76.21ms，23 次 Qt 排序；本次代码为 11.22/26.40/32.13ms，0 次 Qt 排序。两次最终价格均为 10.04；结果仅适用于相邻价格严格不交叉的构造负载，不代表实际点击或滚动延迟。
- 预筛将低精度数值提升为 float64 计算；无法转换的数值列退回全量精判。对昨收 0.11 至 100.00 元的分价，以及触板价格附近、涨幅阈值、非有限数的组合执行隔离断言；该有限范围不能证明所有输入均零漏失。
- 策略快照在可用生产者锁内复制目标列，递归隔离对象列中的可变值；锁竞争或复制失败时跳过本次任务并记录。线程测试覆盖同锁写入与嵌套可变对象；没有证明所有外部生产者都使用该锁。
- 全链路测试等待后台加载和 Qt 分批渲染完成后断言；相关 110 项测试、语法检查及差异空白检查结果见本次交付。
- 5500 行、84 列构造样本：全表复制 p50 约 1.03ms，含对象隔离的 4 列快照 p50 约 1.68ms；小快照减少列数，不应宣称该样本中复制速度更快。
- 未完成的验证：完整 TK/ATS 真实开发实例的同负载对照、跨进程和非锁保护写入审计、源数据年龄及点击/滚动 p95/p99。现有运行实例及其交易、持久化资源未在此次测试中重启或写入。
