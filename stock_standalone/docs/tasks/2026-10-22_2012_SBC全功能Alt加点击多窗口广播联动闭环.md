# SBC全功能Alt加点击多窗口广播联动闭环

## 任务背景与目标
- 用户明确指示：多窗口主题广播同步不应使用键盘快捷键（如 Ctrl+T/Alt+T），而是遵循 SBC 统一的设计哲学——**按住 Alt + 鼠标点击**自动联动广播到所有打开的 SBC 窗口；
- 并且，**SBC 的全部主要功能均应支持 Alt + 鼠标点击广播其他窗口**，形成一致、专业、极度高效的操盘联动交互体验。

## 详细实施计划
1. **抽象通用 SBC 多窗口广播引擎 (`get_all_active_sbc_dialogs`)**：
   - 遵从 DRY 原则，复用 `SBCWindowMemoryManager` 与 `QApplication.topLevelWidgets()` 快速定位当前所有活跃且未被标记关闭的 SBC 窗口。
2. **构建多窗口广播同步函数族**：
   - `sync_all_open_sbc_theme(mode, trigger_dlg)`：同步 3 组主题配色；
   - `sync_all_open_sbc_boll(enabled, trigger_dlg)`：同步 K 线标准 BOLL 布林带开关；
   - `sync_all_open_sbc_gap_channels(enabled, trigger_dlg)`：同步跳空缺口通道带开关；
   - `sync_all_open_sbc_vol_mode(mode, trigger_dlg)`：同步成交量副图模式（正常/折叠/放大）；
   - `sync_all_open_sbc_channel_overlay(enabled, trigger_dlg)`：同步日线通道与支撑线叠加；
   - `sync_all_open_sbc_auto_strategy(enabled, trigger_dlg)`：同步自动策略主动防守开关；
   - `sync_all_open_sbc_reload(trigger_dlg)`：当前窗口立即重载，背景窗口 35ms 错峰分帧重载。
3. **按钮与菜单 Alt 联动挂接**：
   - 顶部工具栏所有核心按钮（主题、BOLL、量能、通道线、自动策略、刷新）在点击时通过 `is_alt_modifier_active()` 识别 Alt 修饰键，自动分流为单窗操作或多窗广播；
   - 按钮 Tooltip 统一补充 `• 按住 Alt 点击: 联动所有已打开的 SBC 窗口`；
   - 右键菜单相应选项支持 Alt 检测并同步广播。
4. **自动化回归测试沉淀**：
   - 编写 `tests/test_sbc_alt_click_broadcast.py`，覆盖多窗口环境下的主题、BOLL、成交量、通道线、自动策略及刷新的 Alt 广播联动；
   - 全量回归确保 100% 纯绿秒级通过。
