# 2026-10-27 15:45 【修复融合梯度各Tab缺名称、赛马与多Tab数据未自动更新及表头悬浮详细信息失效】

## 背景与问题定义
用户在 ATS 融合梯度监视器（`FusionLadderDialog`）使用过程中发现三个明显问题：
1. **各 Tab 缺少 name（名称列空白）**：
   - 在「T+1 订单与成交」Tab 与「按日回放」Tab 中，代码有效但「名称」列完全为空；
   - 根因：`DayReplay.records` 未显式存储 `name`；`ats/fusion/names.py` 的数据源路径候选未考虑打包环境（`get_app_root()`、`sys.executable`）及工作目录，且缺少多通道兜底；
2. **表头鼠标悬浮详细信息（ToolTip）没有显示**：
   - 表头「RAR」、「之后MFE%」、「MAE%」等悬浮时无法弹出自绘深色卡片；
   - 根因：`HeaderToolTip.eventFilter` 监听了 `header.viewport()`，但在获取列索引时错误调用 `obj.logicalIndexAt()`，由于 `viewport` 为普通 `QWidget` 无此方法，抛出 `AttributeError` 被捕获吞掉，同时无条件 `return True` 吞掉了系统 ToolTip；
3. **赛马跟踪及多个 Tab 数据后续未自动更新，点击仍为旧数据**：
   - 切换 Tab 时只有部分 Tab 执行渲染，切回实时梯度无响应；
   - `_live_sig` 在 Tab 0 与 Tab 3 之间共享，导致切换 Tab 时误判签名未变而跳过渲染；
   - 赛马跟踪在入局后若影子流无后续连续记录，MFE/MAE/收盘% 归零（显示 `+0.00%`），未结合实时行情/日内行情动态更新。

## 修复目标与原则
- 严格遵循 KISS, YAGNI, SOLID, DRY 原则；
- 维护 Windows / multiprocessing / 文件锁 / UI 线程安全；
- 不中断主流程，确保所有 Tab 数据更新及时、名称完整、悬浮卡片响应迅速。
