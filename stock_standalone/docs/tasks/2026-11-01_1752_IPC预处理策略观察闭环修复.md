# IPC 大周期预处理策略观察：断点修复

## 三个审核断点

1. **字段时点混源**：锚点和预处理信号分别使用各自来源容器/字段的时间，不借用另一份行情的时间。通道计算源端新增 `_observation_preprocess_ts/asof`；价格增量不能刷新慢字段时间。旧字段没有生成时间时标为待核，不自动激活观察。重新计算旧日期数据只产生历史上下文，不变成今日信号。
2. **L0 在生成证据前被过滤**：真实 `DayReplay.run_day()` 在等级过滤前计算观察证据；符合策略观察条件的 L0 可落档和跨日携带，保留原等级、否决与零仓位，不自动生成订单。
3. **实盘观察候选与跟踪断开**：在旧涨幅/量比漏斗之前选择预处理信号及已观察代码；此通道仅调用影子观察，使用 HOLD，不调用下单入口。名单随跟踪状态持久化，重启后恢复最近九个日历日的观察代码；跨日和名单恢复不依赖曾经入局。

## DF 字段实际应用层级

| 字段 | 本轮应用 |
|---|---|
| `sig_bottom/sig_launch/sig_start/has_bottom_base` | 观察选池、证据落盘、有效时点校验、L0 跨日观察及持续采集 |
| `ch_bc2/ch_tc2/ch_nod` | 保留值、来源、生成时间和时点状态；作为周期锚点证据，未新增权重或任意大小阈值 |
| `sig_top/sig_escape/ch_pattern`、早盘基石/低点、赛马观察等 | 证据记录与查看；未擅自变成买卖条件 |
| 1/3/5/10 日 VWAP | 保留含当日口径、前日参考及来源时点；多周期抬升观察在 L0 时也可保留，未知或过期 VWAP 不产生有效结构判断 |

缺少字段不推断没有信号；缺少原 K 线周期不解释为自然日。不是所有 DF 自定义列均已参与策略，只有上述明确白名单接入；核心评分和交易执行规则未改变。
