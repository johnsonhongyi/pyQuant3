## 二、根因（为什么原来捕捉不到）

`anomaly.py` 的结构验证门槛用的是 `min_vwap_cushion`——**自开盘起全部低点垫的累计最小值**。该值单调不增，任一分钟碰一下均线就永久为负。

实测（全市场 5,576 只，2026-10-29）：
- 全天最低价从不跌破 VWAP+0.20% 的只有 **16 只（0.3%）**；
- **99.3%** 的票盘中都碰过均线；
- 回放插桩 72,732 次形态判定，`cushion >= 0.20` 命中 **0 次**；
- 钧达 002865 在 09:31 悬空垫恰好 **0.000%** → 当日永久失效（该票当日 +11.43%）；
- 中国卫星 600118 在 09:33 回踩后失效（当日 +10.17%）。

即：**设计把"结构是否还在"当成一次性盖章，而价格是随时间流动的。**

## 三、改动

### 3.1 新增 `ats/fusion/structure_timeline.py`（结构状态机）

四态：`WAITING`（有结构底色未点火）→ `CONFIRMED`（悬空+破昨高）→ `BROKEN`（失守）→ `EVICTED`（反复失守被剔除）。

- **失守三条件**：跌破分时均线 0.2%、跌破昨收 1%、自确认后高点回撤 ≥1.5%；
- **剔除**：当日累计失守 ≥3 次 → `EVICTED`，不再给结构保底；
- **复活**：`EVICTED` 后需连续 3 次满足才恢复 `CONFIRMED`（"直到符合条件"）；
- `break_n` 刻意**不归零**：保留当日履历，反复失守的票复活后只有更短的机会。

### 3.2 `enrich.py`：新增滚动悬空垫

`intraday_fields` 新增 `cushion_roll`（最近 20 根最小值，可随价格回升）、`cushion_now`、`vwap_hold_ratio`、`vwap_above_run`；保留 `min_vwap_cushion` 仅作诊断。

关键细节：**必须跳过"首根有效 bar"**——该根 VWAP 等于它自己的均价，`low` 必然 ≤ VWAP，悬空垫恒为负。回放首版就栽在这里（窗口一直含开盘首根，导致仍要等到 10:24 才确认）。

### 3.3 `anomaly.py`：形态判定改用滚动垫

- 结构验证改用 `cushion_roll`（缺省回退全时段值，兼容旧调用）；
- 新增负向形态 `结构失守`，且**不计入形态强度**（避免"越失守分越高"）；
- `struct_status` 为 `BROKEN/EVICTED` 时不再输出结构验证。

### 3.4 `engine.py`：保底不再越过风控 + 重平衡收敛

- `tier_floor` 原在**所有封顶之后**做 `max()`，可顶掉温度封顶、老化衰减、滞后压制、L4 门槛、`tier_cap`。
  现改为：**先按 RAR 分档 → 抬到保底档 → 再统一被风控 `min` 下去**。
  实测：结构验证 + `tier_cap=1` → 现在返回 L1（原 L4）；启动 60 分钟 → L1（原 L4）。
- 新增失守/剔除降档：`BROKEN` 封顶 L2、`EVICTED` 封顶 L1（仅针对结构候选票），并扣 6/12 分。
- `rebalance()` 增加迭代上界与 `_force_downgrade()`：原实现遇到结构票 `while` 永不退出（实测 8s 超时被杀，而 `shadow.observe` 是持锁调用的）。现 4 只结构票可在 82% 预算内正常收敛。
- L4 门槛补上 `is_prime_leader` 豁免（总龙头本身即龙头）。

### 3.5 `shadow.py` / `replay.py`：实盘与回放同构接入

- 每笔行情都调用 `structure_timeline.update()`，状态写入 `event.extra`；
- `_floor=4` 仅在 `CONFIRMED` 且未失守时给出；
- 落盘新增顶层 `struct_status / struct_confirm_n / struct_break_n / struct_reason` 与 `struct{status,label,confirm_n,break_n,cushion_roll,cushion_now,drawdown_pct,reason}`；
- 回放记录 `lead_label` 改用 `lead_label_final`（原来写原始标签，回放里永远看不到"总龙头"）。

### 3.6 `adapter.py` / `stock_live_strategy.py`

- 白名单补 `cushion_roll / cushion_now / vwap_hold_ratio / vwap_above_run`；
- `_fusion_enrich_snap` 对时间轴字段**每轮强制覆盖**（不再走"缺失才补"），否则又会沿用上一轮的值退化成一次性判定。

### 3.7 UI

- `_row_is_structure_opportunity` 优先读 `struct.status`：`BROKEN/EVICTED` 直接排除，`CONFIRMED` 直接入选；
- 证据链新增 `🎯结构验证(悬空+1.23%)`、`⚠️结构失守(跌破分时均线)·保底已撤销`、`🚫结构剔除(失守3次)`。

### 3.8 测试隔离

`test_structure_opportunity_model.py` 两处 `FusionShadow(...)` 补 `log_dir` 指向临时目录。原来测试会把假数据写进生产 `logs/fusion_shadow/`——今日 55 条假记录（4 只票、整数价位、15 个 PID）即由此产生，会污染当晚复盘。
