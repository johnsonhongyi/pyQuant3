## 一、补上的东西

新增 `ats/fusion/trade_sim.py`，把"决策"变成"订单 → 成交 → 持仓 → 卖出"：

| 环节 | 规则 |
|---|---|
| 下单时点 | 信号 bar 的**下一根**（当根不成交），3 分钟内有效 |
| 买入价 | `limit`：挂决策给出的区间，`low<=区间上沿` 才成交，成交价取 `min(区间上沿, 当根开盘)`；`market`：次根开盘价市价成交 |
| 仓位 | 按级别给出的 `size_pct`（L3 18%、L2 10%…），每日最多开 N 个仓（默认 5，按级别+RAR 排序） |
| **T+1** | 买入当日**一律不卖**，`sellable_date` = 下一交易日 |
| 止损 | 次日起生效；次日开盘已破止损则按开盘价出（跳空兜底） |
| 止盈 | 次日起触及 +6% 出 |
| VWAP 结构 | 买入当日收盘跌破 VWAP → **次日开盘**卖出（这是"用结构控回撤"的兑现点） |
| 被锁止损 | 买入当日最低价已跌破止损 → 记为 `stop_blocked`，并量化额外损失 |

命令：

```bash
python -m ats.fusion.replay --day 2026-10-19 --top 300 --focus 688787,300296 --fill market --max-pos 5
```

## 四、三个必须承认的结论

### 结论 1：限价等回踩在 T+1 下有"逆向选择"

限价单只在价格回落时成交，等于**只买到了走弱的那些**；真正走强的（海天瑞声、利亚德）全部未成交。这解释了为什么限价模式胜率反而更低（33.3% vs 48.0%）。

→ 修正方向：**L3/L4 用市价 + 滑点上限（如 ≤0.5%），L1/L2 才用限价**。不要用"等回踩"去接强票。

### 结论 2：止损太窄，买入当日就被击穿，但卖不掉

市价模式 25 笔里 **8 笔（32%）在买入当日就跌破止损**，受 T+1 限制无法执行，只能等次日。这就是"早盘诱多跑不掉"的量化版本。

当前止损锚是 VWAP−0.6% / −1.2%，而 3 分钟线的日内噪声普遍在 1%~2%。**止损落在噪声里，等于没有止损，只剩隔夜风险。**

→ 修正方向：止损宽度改为 `max(3%, 1.2 × 当日振幅)`，并且入场价必须距止损 ≥ 3%（否则降级或放弃）。VWAP 只作为"结构是否还在"的判断，不作为止损价位。

### 结论 3：冷市（10/22）两种模式都救不了

10/22 温度 32~37℃，市价模式 6 笔胜率 16.7%、平均 -2.96%。温度过滤把级别压低了，但只要有 L2 就会开仓。

→ 修正方向：**温度 < 40℃ 时，除"逆势独立走强"外一律不开新仓**（当前只在退潮期否决，冰点期仍放行）。

## 五、对融合层的具体改动建议（待批准后实施）

| 项 | 现状 | 建议 |
|---|---|---|
| 止损锚 | 固定 VWAP−0.6% / −1.2% | `max(3%, 1.2×ATR(3min))`，且入场距止损 ≥3% |
| 入场方式 | 全部限价等回踩 | L4/L3 市价+滑点上限；L2/L1 限价 |
| 早盘信号 | 与午后同权 | 09:30–10:30 的 L2/L3 降一档（T+1 下当日无法纠错） |
| 冰点期 | 仍可开 L2 | 温度<40℃ 只允许"逆势独立走强"（相对强度前 1% 且不随大盘） |
| 持仓上限 | 每日 5 仓 | 按温度调整：冷市 2 仓、回暖 5 仓、过热 3 仓 |

## 六、局限

1. 缓存只有 5 个交易日（10/19–10/23），**10/23 的信号没有 T+1 后续数据**，只能标 `OPEN_T1无后续数据`；因此 T+1 统计只覆盖 10/19–10/22。
2. 未建模涨跌停无法成交、停牌、滑点分布；跳空按开盘价兜底。
3. 3 分钟粒度，买入时点精度约 ±3 分钟。
4. 分批建仓（L4 的 50/30/20）尚未模拟，目前按一次性建仓处理。
