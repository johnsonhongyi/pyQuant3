# 2026-10-27 22:45 【修复全市场退潮虚假100%炸板与非交易时间乱播报】

## 背景与痛点
- **虚假 100% 炸板率与动不动喊雪崩**：
  用户反馈报警日志：
  `2026-10-27 22:25:44,566 [INFO] 📢 [ALERT_NOTIFY] 串行轮播弹出信号 [全市场退潮 | 000001 ]: 全市场退潮雪崩，炸板率100%, 严禁开仓执行止损`
  用户明确指出：**“数据不是真实炸板率，动不动就说雪崩炸板率100%修复这个bug，使用准确数据及市场温度”**。
- **非交易时间乱发盘中交易级紧急语音**：
  在夜间 22:25（非交易时段/休市/复盘时），系统竟然触发了“严禁开仓执行止损”这种盘中语音播报与弹窗，造成严重骚扰。

---

## 根因穿透分析

### 根因 1：炸板率被数学逻辑偷换为 `100.0 - seal_rate`
- **0 样本除零倒置为 100%**：
  在 `LimitUpEngine.get_market_limit_up_summary` 与 `DailyLimitUpDialog` 中，封板率 `seal_rate = zt_count / total_attempts * 100.0 if total_attempts > 0 else 0.0`；
  而代码偷懒将炸板率写为 `100.0 - seal_rate`！
  当当天冲板总数为 0（`total_attempts == 0`，如未出现冲板或记录为空）时，`seal_rate = 0.0`，代码直接得出 `100.0 - 0.0 = 100%` 炸板率！
  即使没有一只股票冲板，也荒谬地报错“炸板率 100%”。真实炸板率应为 `broken_count / total_attempts * 100.0 if total_attempts > 0 else 0.0`。

### 根因 2：退潮雪崩判定粗暴脆弱，缺乏市场温度与多因子共振
- 原判定条件 `(down_cnt >= 3800 and panic_down_cnt >= 150)` 门槛极低；在普跌震荡市中容易被直接击穿；
- 击穿后直接套用上述错误的 `100.0 - seal_rate`，瞬间判定为“全市场退潮雪崩”并报出“炸板率 100%”；
- 判定完全未结合全市场真实温度（`market_temp = (up_cnt / total_cnt) * 100.0`）及冲板样本充分性。

### 根因 3：语音报警缺少交易时段门禁
- `DailyLimitUpDialog._update_kpi_display` 中，触发语音播报前仅判断了 `is_voice_alert_enabled` 与 300 秒时间戳冷却，**完全没有判断当前是否处于连续竞价交易时间**；
- 导致在夜间 22:25 用户打开复盘或刷新界面时，触发了盘中盘口级的退潮语音播报。

## 修复实施措施

1. **真实炸板率（broken_rate）科学计算，杜绝 0 样本误报 100%**：
   - 在 [`ats/limit_up_engine.py`](file:///d:/MacTools/WorkFile/WorkSpace/pyQuant3/stock_standalone/ats/limit_up_engine.py) 中：
     ```python
     broken_rate = round((broken_count / total_attempts * 100.0), 1) if total_attempts > 0 else 0.0
     ```
   - 当 `total_attempts == 0` 时，封板率与真实炸板率均为 `0.0%`；
   - 彻底删除所有 `100.0 - seal_rate` 的粗暴偷换写法；冲板样本不足 5 家时不展示无统计意义的百分比，仅展示真实炸板家数。

2. **引入 SSOT 权威市场温度（0~100℃）与多维度严格防猎判定**：
   - 计算真实市场温度：`market_temp = round((up_cnt / float(total_market_stocks) * 100.0), 1) if total_market_stocks > 0 else 50.0`（与 `UltraShortAnomalyEngine` / `DistributionBarChart` 保持 100% 同源）；
   - 严格限定退潮雪崩（`is_avalanche`）触发条件（多因子共振）：
     ① 真实炸板潮：冲板样本充分（`total_attempts >= 8`）且真实炸板率极高（`broken_rate >= 50.0%`）；
     ② 极寒冰点踩踏：全市场温度处于极低冰点（`market_temp <= 22.0℃`，下跌超 4000 家）且恐慌踩踏严重（`panic_down_cnt >= 200`）；
     ③ 跌停潮爆发：跌停数严重暴增（`limit_down_cnt >= 30` 且 `limit_down_cnt > zt_count`）；
   - 在 `defense_status` 中明确携带真实市场温度与真实炸板率，如 `🚨 全市场退潮雪崩 (温度18.5℃ | 下跌4200家 | 恐慌踩踏210家 | 炸板率55.0% (11/20))`。

3. **增加盘中交易时段门禁，非交易时间坚决静音**：
   - 在 [`ats/ui/daily_limit_up_dialog.py`](file:///d:/MacTools/WorkFile/WorkSpace/pyQuant3/stock_standalone/ats/ui/daily_limit_up_dialog.py) 的 `_update_kpi_display` 中，通过 `is_trading_time()` 增加时段校验；
   - 非交易时段（夜间、休市、周末）只在 UI 界面展示状态文字，**坚决不调用 `AlertNotifier.notify_special_signal` 发出语音播报**；
   - 盘中播报文案严格使用准确数据与市场温度：`全市场退潮雪崩，市场温度{temp_val:.1f}℃，真实炸板率{brk_rate_val:.1f}%，下跌{down_cnt}家，注意防范回落风险`。
