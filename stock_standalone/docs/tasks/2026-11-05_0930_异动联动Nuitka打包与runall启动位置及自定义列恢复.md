# 2026-11-05 09:30 异动联动Nuitka打包与runall启动位置及自定义列恢复

## 任务背景与用户反馈
用户反馈在使用 `runall.bat` 自动化流程启动 `异动联动`（或 Nuitka 打包版 `异动联动_Nuitka.exe`）时遇到两大严重异常：
1. **启动无法获取正确位置**：主窗口每次启动均缩回默认 500x600 居中状态，无法恢复此前设定的几何尺寸与多屏坐标；
2. **无法读取到自定义列信息**：表格中的 `dff`, `dff2`, `dff3`, `rank` 自定义指标列全显示为 `-100.0%` 或完全空白，上方过滤条件（如 `low < ma10d and ma5d > ma10d and close > lastp1d`）命中数显示为 `[Hit: 0]`，甚至过滤框变空白。

---

## 根因深度剖析

### 1. 自定义列显示 `-100.0%` 与过滤 `[Hit: 0]` 的根因
- **PyTables (tables) 缺失导致 HDF5 数据管道彻底断流**：
  在 `build_nuitka_clang.bat` 中，此前为了防止 sqlite3.dll 冲突添加了 `--nofollow-import-to=tables`。打包后的二进制运行时抛出：
  `ModuleNotFoundError: No module named 'tables'`
  `ImportError: Missing optional dependency 'pytables'. Use pip or conda to install pytables.`
  `Failed to load table all from G:\sina_data.h5`
  导致 `sina_df` 与 `tdx_df`（包含 `low_d_120_y_all` 等关键行情与日线均线表）完全加载失败为 None。
- **无价格时的除法负值假象**：
  在计算 `dff` 时，`top_all['buy']` 因无实时行情回退为 0，执行 `(buy - llastp) / llastp * 100` 硬算得出 `(0 - llastp)/llastp*100 = -100.0%`；
  而过滤表达式中的 `low`, `ma10d`, `ma5d`, `close`, `lastp1d` 等列缺失，布尔过滤自然得到 0 条命中记录（`[Hit: 0]`）。
- **`linkage_config.json` 路径解析偏离物理目录**：
  `save_linkage_config` 与 `load_linkage_config` 原使用 `os.path.join(BASE_DIR, "linkage_config.json")`，在 Nuitka Onefile 下落入 Temp 临时解压目录，无法持久化读取用户上次选中的过滤条件。

### 2. 跟随 `runall.bat` 启动无法获取正确位置的根因
- **主窗口 `root` 缺少几何位置持久化与加载机制**：
  原程序仅恢复了各种子监控窗口 `WINDOW_GEOMETRIES[code]`，主窗口 `root` 硬编码为 `root.geometry("500x600")`，且没有绑定 `<Configure>` 事件记录主窗口位置；
- **排布脚本 `findSetWindowPos.py` 字典键缺省**：
  在多屏排布时，若未显式在分辨率字典中配置 `'股票异动数据监控'`，`set_proc_windows_position` 判定 `tdx not in positon.keys()` 而跳过了窗口移动；
- **`ths-tdx-web.py` 进程匹配未对齐**：
  `find_window_by_title_background('异动联动.exe')` 未兼容匹配 `异动联动_Nuitka.exe`，导致可能启动重复进程。

---

## 落地修复方案

### 1. 构建体系恢复 tables 与底层动态库
- **`build_nuitka_clang.bat`**：
  - 彻底移除 `--nofollow-import-to=tables`；
  - 显式引入：`--include-package=tables`、`--include-module=tables._comp_lzo`、`--include-module=tables._comp_bzip2`、`--include-module=filelock`、`--include-module=_ssl`、`--include-module=_hashlib`；
  - 动态安全解析注入 OpenSSL `libcrypto*.dll` 与 `libssl*.dll`；
  - 坚决不手动加入 `sqlite3.dll` 为 data-file，彻底避开 Nuitka tables 插件的 DLL 路径冲突；
  - 额外包含种子数据文件：`window_config.json`、`query_history.json`、`linkage_config.json`。

### 2. 运行时路径权威解析与过滤记忆恢复
- **`sys_utils.py`**：将 `linkage_config.json` 纳入 `RESOURCE_MAP` 字典；
- **`异动联动.py`**：
  - `save_linkage_config()` 与 `load_linkage_config()` 改用 `get_conf_path("linkage_config.json", BASE_DIR)`，确保从真实安装目录（如 `<USER_HOME>\Documents\TDX\55188\`）精准存取；
  - 防御无现价计算：当 `buy <= 0` 时，强制将 `dff`, `dff2`, `dff3` 归零，杜绝 `-100.0%` 假象。

### 3. 主窗口原生几何记忆与外部排布双重保障
- **原生自愈恢复**：
  在 `root = tk.Tk()` 后，优先读取 `WINDOW_GEOMETRIES.get("root")` 并恢复尺寸与坐标；
  绑定 `root` 的 `<Configure>` 事件（1.5s 防抖），在用户调整窗口大小/拖动位置后自动持久化到 `window_config.json`；
- **外部排布增强**：
  - `findSetWindowPos.py`：在 `appendProc` 阶段检测到 `'股票异动数据监控'` 不在字典时，自动补全默认坐标 `'0,0,494,825'`，确保 100% 执行排布；
  - `ths-tdx-web.py`：兼容识别并优先拉起 `异动联动_Nuitka.exe`，防止重复拉起。
- **自动部署集成**：
  在 `stockAlerts-nuitka-to-exe.cmd` 中构建成功后自动同步复制 `异动联动_Nuitka.exe` 到 `<USER_HOME>\Documents\TDX\55188\`。
