# 2026-10-28 11:35 【SBC集合竞价实时虚拟水平线、右轴胶囊对齐与坐标轴防压缩治理】

## 1. 业务痛点与用户诉求
1. **集合竞价价格主图可视性缺失**：原 SBC 走势图集合竞价价格仅在右上角 74px 的小窗口（浮动面板）中显示，主图上没有横贯价格参考线，右侧 Y 轴亦无现价胶囊。操盘手无法在走势图上及时、直观地看到集合竞价当前撮合价处在昨日/历史走势的哪个关键位（是否踩在支撑线上、是否突破阻力位）。
2. **集合竞价期间个股 SBC 图被压缩压扁、清理数据无法消除**：在集合竞价时段，某些个股（如北新路桥 002307、长城军工 601606 等）走势图出现极度压缩塌陷，Y 轴被撑到荒谬数值（如北新路桥 3.22 元被撑到 8.65 元，涨幅显示 +168.5%；长城军工 30 元被拉低到 14.79 元，跌幅 -51.8%），分时线被压成一条细线。用户清理缓存数据后依然出现该坐标问题。

## 2. 根因深度穿透分析
1. **通达信快照硬编码保底污染 (`low_price=10.0`)**：
   在 `ats/tdx_realtime_fetcher.py:3731` 的 `_normalize_quote_to_snapshot` 中：
   ```python
   if low_price <= 1.0 or (trade_price > 5.0 and low_price < trade_price * 0.1):
       low_price = trade_price if trade_price > 0 else (open_price if open_price > 0 else 10.0)
   ```
   集合竞价期间，通达信返回的盘口 `trade_price` 和 `open_price` 均为 0。导致低价股（如 3.22 元的北新路桥）在竞价期间直接被赋予 `low_price = 10.0`！
   外部参考值 10.0 被作为极值塞进 Y 轴候选，导致 3 块钱的股票 Y 轴上限被拉爆压扁。并且因为每次重新从行情拉取都会再次被设为 10.0，故“清理数据也无法消除”！
2. **集合竞价门禁判断漏掉 `auction_open` 与时间窗口**：
   `intraday_strategy_dialog.py` 原先偷懒使用 `getattr(self, "market_phase", "") in ("auction_indicative", "auction_pending")`。
   在 09:25~09:30 时，`market_phase` 变为 `"auction_open"`，直接脱离了竞价防撑爆分支；或者休市/未标记时，`self.high_price`, `self.low_price` 毫无防备地直接进入 `all_cands`。
3. **统计学滤波防御阈值过宽（0.25 ~ 3.5倍）失灵**：
   原逻辑 `med_cands * 0.25 <= c <= med_cands * 3.5` 极其宽松，3.22 元中位数的 3.5 倍高达 11.27 元，污染进来的 10.0 / 8.65 / 7.64 畅通无阻。
4. **左侧刻度极值 (`hi_val`, `lo_val`) 脱离过滤机制**：
   直接取未经清洗的 `df_view['high'].max()`，导致单根脏数据毛刺把刻度打出 `高:8.65 +168.5%`。

## 3. 核心工程改造落地

### A. 通达信行情快照优雅回退昨收价 (`ats/tdx_realtime_fetcher.py`)
- 提取真实的 `last_close`（昨日收盘价）；
- 当早盘/竞价期间 `trade_price <= 0` 且 `open_price <= 0` 时，安全回退到真实 `last_close`，仅当 `last_close <= 0` 时才使用兜底 10.0；
- 彻底根治 3 元标的在竞价期间被无故写成 10.0 的灾难。

### B. 集合竞价虚拟水平线与右轴竞价胶囊全闭环 (`ats/ui/intraday_strategy_dialog.py`)
- **数据流打通**：在 `_apply_chart_payload` 中将 `auction_price` 赋给 `canvas.auction_price`，并在 `_draw_chart_static_layer` 缓存 token 中纳入 `auction_price` 与 `auction_samples`，实现每分钟毫秒级原子刷新。
- **虚拟水平线渲染**：当处于集合竞价阶段（09:15~09:30 或 `auction_*` 状态）且有有效集合竞价价格时，在主图绘制横贯全图的竞价虚线（未成交试撮合为 `#FFAA00` 高亮橙黄，已定盘开盘为 `#00E5FF` 青蓝）。
- **右轴高亮胶囊**：在右侧 Y 轴对应位置绘制竞价胶囊，文字为 `撮:xxx` 或 `开:xxx`，标注相对于昨收的虚拟竞价涨跌幅百分比，与左上角小窗口 100% 同源对齐。
- **自适应 Y 轴包容**：将有效的 `raw_auc_p` 纳入 Y 轴价格候选 `all_cands`，若集合竞价大幅高开或低开，走势图 Y 轴自动舒展包容，虚拟现价线绝对不跑出可视区域外。

### C. 坐标轴防压缩与离群值治理
- **强健集合竞价判定 (`auction_active`)**：统一覆盖 `09:15~09:30` 时间段、`auction_*` 协议、以及竞价样本有效状态；
- **竞价期间严禁未成交异日参考价污染**：集合竞价期间主图严格基于历史成交线（`prices`, `vwaps`, `op_ref`）与当前有效竞价价格缩放，坚决排除盘口未成交的 `high_price`, `low_price`, `target_sell_min`；
- **基于主体价格区间的双向紧凑滤波**：结合真实可视价格 `p_min_real`, `p_max_real` 与中位数 `med_cands` 构建科学过滤边界（`[lower_bound, upper_bound]`），坚决剔除离群噪点；
- **刻度极值约束**：`hi_val` 与 `lo_val` 严格限定在清洗后的有效价格极值范围内，彻底消除左侧刻度被脏数据撑爆。
