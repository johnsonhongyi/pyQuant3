# AGV地区限制与双桥日志复核

- 用户现场11:50、11:53、11:57的AGV任务均收到FAILED_PRECONDITION (code 400): User location is not supported for the API use。上游明确拒绝地区访问；与此前头像GET EOF的瞬时连接中断不同。不能仅凭该错误证明Clash具体哪一条分流规则失效，也不能证明切换推理等级能解决。
- 排查方向：核对AGY实际进程代理、命中规则/是否直连、实际出口是否被服务接受，以及账号地区资格。此任务不修改另一任务正在处理的Clash规则或出口，不宣称代理问题已解决。
- AGV新增AGY_LOCATION_UNSUPPORTED稳定分类，优先于EOF匹配；不进入原任务内网络恢复重试。外层保留领取循环恢复，但日志标为任务失败，不再为地区限制输出“可重试/5秒后重试”。外层保留脱敏上游原因。
- 管理器同时识别旧AGY_RESULT_ERROR日志内的地区限制文本，显示中文原因、建议及原码；其他恢复检查明确不等于原任务已重试。
- Codex11:52为使用额度限制、12:12为超时、12:23任务成功：桥未永久卡死，但后续成功不证明此前两种错误同源或不再复发。
- 验证：AGV模型/恢复22项、双桥日志显示5项通过，diff检查通过。曾从错误工作目录按模块名运行测试导致导入失败，切换正确目录后通过；未计入通过数。
- 未人为更改网络复现地区限制，未实际验证Clash出站链路。菜单7构建及安装状态以随后记录为准。
