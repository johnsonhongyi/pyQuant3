# 异动联动重排策略右键自定义与自动持久化治理

## 1. 任务背景
在股票实时监控联动系统中：
1. 修复了自 09-21 以来无监控数据备份的 4 大致病 Bug，并添加 Q 键将全部监控带到最前；
2. 用户需要对主界面的【重排】功能进行策略升级：
   - 为【重排】按钮添加右键上下文菜单；
   - 支持可视化编辑重排中的过滤策略表达式（如 `close > high4`、`涨幅 > 5` 等）；
   - 支持自定义排序维度（创建时间、涨幅、现价、成交量、代码）、排布方向与分流动作；
   - 策略必须支持自动持久化到本地配置文件中，重启后保持生效；
   - 过滤表达式需要兼容中英文变量名双向别名（`涨幅` ↔ `percent`, `现价` ↔ `close`, `量` ↔ `vol` 等）。

## 2. 核心架构与修改实现

### 2.1 右键菜单与配置交互 (`异动联动.py`)
- 为【重排】按钮绑定 `<Button-3>` 右键事件 `show_rearrange_context_menu`；
- 弹出包含【⚙️ 编辑重排策略与过滤规则】、【▶ 立即执行重排】、【🔄 恢复默认策略】的右键快捷菜单；
- 点击配置后唤起 `open_rearrange_policy_dialog` 弹窗，支持所见即所得地调整过滤表达式、启用状态、排序维度、正反序与排布方向。

### 2.2 策略自动持久化
- 持久化配置文件：`window_config.json` 中的 `rearrange_policy` 键；
- 具备完整的默认降级保障与容错机制（`DEFAULT_REARRANGE_POLICY`），保存后即时写盘生效。

### 2.3 表达式安全评估与中英文双向映射 (`eval_rearrange_condition`)
- 构建中英文双向映射表 `aliases`，无论数据字典提供英文键还是中文键，或者用户在表达式中编写 `涨幅 > 5` 还是 `percent > 5`，均能正确双向填充；
- 建立安全沙箱，禁用 `__builtins__`，提供默认 0.0 浮点数兜底，杜绝 `NameError` 或表达式异常中断重排主流程。

### 2.4 重排逻辑动态分流与纵向优先满高换列修复 (`rearrange_monitors_per_screen`)
- **纵向换列 Bug 彻底根治**：原代码在纵向并排时缺失换列逻辑，直接横向累加 `current_x` 导致排成超长单行。现严格实现纵向自上而下排列，当 `current_y + h + margin_y > work_b` 时智能换下一列；
- **分流组向左换列**：满足过滤条件的股票窗口排在屏幕右下角红底提示，纵向模式下从右向左向上排列；
- **常规窗口排序与排布**：按照设定的维度（创建时间/涨幅/现价/成交量/代码）进行动态排序与多屏排布。

### 2.5 过滤测试与字段数据查看器 (`open_rearrange_test_dialog`)
- 在过滤表达式输入框右侧嵌入【🧪 测试/详情】快捷按钮；
- 弹窗内设双 Tab 视图：
  - **Tab 1: [ 检查结果摘要 ]**：控制台文本区展示标的、当前涉及字段及数值、是否通过（✅ / ❌）、子条件拆解等；
  - **Tab 2: [ 📊 可用字段与当前数据 (cols) ]**：Treeview 表格罗列当前标的系统全部可用字段（`close`, `high4`, `ma5d`, `ma10d`, `dff`, `dff2`, `dff3`, `ch_pos`, `percent`, `vol`, `涨幅`, `现价` 等数十个字段）、别名、当前值及数据类型；双击某字段可直接插入表达式；
  - 表达式微调测试后可一键【📥 应用至策略】回填主配置。

### 2.6 窗口位置持久化与配置安全合并
- 主配置弹窗（`rearrange_policy_dialog`）与测试弹窗（`rearrange_test_dialog`）均支持记忆几何位置（`geometry`）并持久化至 `window_config.json`；
- 修复 `save_window_positions`，写盘前保留 JSON 中现有的其他节点，彻底杜绝窗口保存操作冲掉 `rearrange_policy` 策略配置。

### 2.7 交易期刷新间隔优化与监控报警策略全面对齐
- **5 分钟刷新间隔**：将 `_get_sina_data_realtime` 中的交易时段刷新间隔从 10 分钟调整为 5 分钟，显著提高盘中突破感知度；
- **重排策略与报警弹窗统一**：`check_monitor_break_high4` 读取 `load_rearrange_policy()` 中的 `filter_expr` 与 `filter_enabled`，用户在重排中修改自定义策略后，监控报警变红与重排分流 100% 步调一致；
- **未打开小窗口自动弹出限额与生命周期**：
  - 新增 `auto_popup_enabled`（可选配置开关）与 `auto_popup_limit=10`；
  - 自动创建时打上 `_auto_popup = True` 分组标记，存活窗口严格限制最多 10 个；
  - 用户手动关闭旧窗口后，允许自动弹出新标的补位到 10 只；
  - 每日 15:00 收盘持久化后，自动清除 `_auto_popup` 标记归入常规监控，重置次日额度，杜绝刷屏。

### 2.8 重排右键与策略配置弹窗新增实时弹出与报警测试入口 (`test_realtime_popup_scan`)
- **UI 快速入口**：
  - 在【重排】按钮右键菜单新增【🔔 测试实时弹出与报警 (模拟扫描)】；
  - 在策略配置弹窗【盘中自动弹出新监控小窗口】控制行右侧新增【▶ 测试弹出/报警】；
- **非交易时段豁免**：
  - `check_monitor_break_high4` 引入 `force_work_time=False` 参数；在测试扫描时传 `force_work_time=True`，彻底解除盘后或周末无法演练测试的痛点；
- **智能行情回退与反馈**：
  - 优先调取内存全局异动和实时行情，若无则自动生成高仿真测试样本；
  - 自动触发策略扫描、自动弹出（受 10 只有效限额控制）、震动与红色标记；
  - 运行完成后以浮动 Toast 给出测试结果（扫描标的数、新增弹出数及当前存活额度）。

### 2.9 重排策略配置与测试弹窗改为独立无模态顶层窗口
- **解除模态锁定**：
  - 彻底移除 `open_rearrange_policy_dialog` 中的 `win.grab_set()`，解脱主界面和其他已打开几十个小监控窗口的事件锁定；
  - 彻底移除 `win.transient(...)` 与 `test_win.transient(...)`，升级为平级的独立顶级窗口，支持任务栏原生独立切换与多屏拖拽；
- **单例激活防重**：
  - 增加 `_rearrange_policy_dialog_win` 与 `_rearrange_test_dialog_win` 全局单例句柄；
  - 窗口未关闭再次点击唤起时，直接 `deiconify()`、`lift()`、`focus_force()` 将已有窗口带到前台，杜绝重复创建；
- **闭环生命周期**：
  - 保存并重排时通过 `on_close_policy_dialog()` 清除单例句柄、保存几何位置，并将 Toast 绑定在 `root` 保证显示平稳。

### 2.10 无异动冷门个股 close 多源级联回退、保存保持常驻与 Esc 关闭
- **无异动个股数据源破案与治理**：
  - 异动数据流仅推送触发活跃异动的个股。对于走势平稳未触发异动的个股（如 `002526 山东矿机`），初始化监控小窗口时其 `stock_info` 中的价格默认仍为 `0.0`；
  - 旧版 `get_stock_eval_dict` 仅读取 `GLOBAL_TOP_ALL`，且用 `stock_info` 里的 0.0 覆盖了有效数据；
  - 现重构为健全的多源级联回退系统：`GLOBAL_TOP_ALL` -> 全市场实时行情快照 `_get_sina_data_realtime()`（5500+ 只股票完整行情） -> 全市场技术指标表 `_get_tdx_data_df()`（`ma5d`, `lastp1d` 等） -> 实时流 `realdatadf` -> 监控小窗口 `tree`；
  - 强化防 0 覆盖保护：仅在数值 > 0 时才更新，并在 `close`, `now`, `price`, `现价`, `价格`, `nclose` 之间智能寻找有效现价并对齐；若无涨幅则根据现价与昨收（`lastp1d`/`llastp`）自动自愈计算；
- **保存并重排保持常驻**：
  - 点击【💾 保存并立即重排】后不再调用销毁窗口函数，保存并重排后窗口常驻打开，方便持续观察与调试；
- **Esc 一键关闭**：
  - 在配置窗口及测试窗口、输入框 `entry_expr`、`entry_test_expr`、`entry_code` 等所有控件上均绑定 `<Escape>` 事件，光标聚焦任何地方按 Esc 键均可平稳关闭。

### 2.11 测试弹窗直接联动按钮与后台数据合并类型冲突根治
- **测试弹窗直接联动按钮**：
  - 在【重排策略过滤测试与字段数据查看】弹窗（`open_rearrange_test_dialog`）顶部【🔄 载入数据】按钮右侧新增【🔗 联动】按钮；
  - 一键调用 `send_to_tdx(code)` 向行情终端/分时图广播代码联动，无需反复切回主界面；
- **彻底根治后台异动刷新 Merge 类型冲突异常**：
  - 排查并修复 `_get_stock_changes` 中 `ValueError: You are trying to merge on int64 and object columns`；
  - 在 `temp_df.merge(right_df, on='代码', how='left')` 之前强制将两边的 `'代码'` 列统一规范化为 6 位字符串（`astype(str).str.zfill(6)`），彻底杜绝后台刷新任务中断。

### 2.12 测试弹窗新增指定股票一键弹出与微抖震动测试
- **测试弹窗快捷测试按钮**：
  - 在测试弹窗顶部【🔗 联动】右侧嵌入【🔔 弹出震动】按钮；
  - 提取当前下拉框（如 `300680 隆盛科技`）或输入框的代码，触发 `trigger_stock_popup_and_shake`；
- **微抖震动引擎 (`shake_window`)**：
  - 自动将监控窗口置顶唤醒（`deiconify()`, `lift()`, `topmost` 闪唤），并以安全位移 `dx = ±8px` 进行 8 轮快速左右抖动后复位，模拟 Windows 经典窗口震动提示；
  - 自动打上 `_alter_tdx = True` 标记并触发变红高亮；
  - 若标的尚未打开小窗口，则即时创建新窗口并打上 `_auto_popup = True` 标记后执行微抖震动；
  - 同步赋能实盘报警引擎 `check_monitor_break_high4`，盘中策略命中的窗口均具备微抖震动效果。
