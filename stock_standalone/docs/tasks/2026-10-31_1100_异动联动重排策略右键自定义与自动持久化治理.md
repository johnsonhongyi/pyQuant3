# 异动联动重排策略右键自定义与自动持久化治理

## 1. 任务背景
在股票实时监控联动系统中：
1. 修复了自 09-21 以来无监控数据备份的 4 大致病 Bug，并添加 Q 键将全部监控带到最前；
2. 用户需要对主界面的【重排】功能进行策略升级：
   - 为【重排】按钮添加右键上下文菜单；
   - 支持可视化编辑重排中的过滤策略表达式（如 `close > high4`、`涨幅 > 5` 等）；
   - 支持自定义排序维度（创建时间、涨幅、现价、成交量、代码）、排布方向与分流动作；
   - 策略必须支持自动持久化到本地配置文件中，重启后保持生效；
   - 过滤表达式需要兼容中英文变量名双向别名（`涨幅` ↔ `percent`, `现价` ↔ `close`, `量` ↔ `vol` 等）。

## 2. 核心架构与修改实现

### 2.1 右键菜单与配置交互 (`异动联动.py`)
- 为【重排】按钮绑定 `<Button-3>` 右键事件 `show_rearrange_context_menu`；
- 弹出包含【⚙️ 编辑重排策略与过滤规则】、【▶ 立即执行重排】、【🔄 恢复默认策略】的右键快捷菜单；
- 点击配置后唤起 `open_rearrange_policy_dialog` 弹窗，支持所见即所得地调整过滤表达式、启用状态、排序维度、正反序与排布方向。

### 2.2 策略自动持久化
- 持久化配置文件：`window_config.json` 中的 `rearrange_policy` 键；
- 具备完整的默认降级保障与容错机制（`DEFAULT_REARRANGE_POLICY`），保存后即时写盘生效。

### 2.3 表达式安全评估与中英文双向映射 (`eval_rearrange_condition`)
- 构建中英文双向映射表 `aliases`，无论数据字典提供英文键还是中文键，或者用户在表达式中编写 `涨幅 > 5` 还是 `percent > 5`，均能正确双向填充；
- 建立安全沙箱，禁用 `__builtins__`，提供默认 0.0 浮点数兜底，杜绝 `NameError` 或表达式异常中断重排主流程。

### 2.4 重排逻辑动态分流与纵向优先满高换列修复 (`rearrange_monitors_per_screen`)
- **纵向换列 Bug 彻底根治**：原代码在纵向并排时缺失换列逻辑，直接横向累加 `current_x` 导致排成超长单行。现严格实现纵向自上而下排列，当 `current_y + h + margin_y > work_b` 时智能换下一列；
- **分流组向左换列**：满足过滤条件的股票窗口排在屏幕右下角红底提示，纵向模式下从右向左向上排列；
- **常规窗口排序与排布**：按照设定的维度（创建时间/涨幅/现价/成交量/代码）进行动态排序与多屏排布。

### 2.5 过滤测试与字段数据查看器 (`open_rearrange_test_dialog`)
- 在过滤表达式输入框右侧嵌入【🧪 测试/详情】快捷按钮；
- 弹窗内设双 Tab 视图：
  - **Tab 1: [ 检查结果摘要 ]**：控制台文本区展示标的、当前涉及字段及数值、是否通过（✅ / ❌）、子条件拆解等；
  - **Tab 2: [ 📊 可用字段与当前数据 (cols) ]**：Treeview 表格罗列当前标的系统全部可用字段（`close`, `high4`, `ma5d`, `ma10d`, `dff`, `dff2`, `dff3`, `ch_pos`, `percent`, `vol`, `涨幅`, `现价` 等数十个字段）、别名、当前值及数据类型；双击某字段可直接插入表达式；
  - 表达式微调测试后可一键【📥 应用至策略】回填主配置。

### 2.6 窗口位置持久化与配置安全合并
- 主配置弹窗（`rearrange_policy_dialog`）与测试弹窗（`rearrange_test_dialog`）均支持记忆几何位置（`geometry`）并持久化至 `window_config.json`；
- 修复 `save_window_positions`，写盘前保留 JSON 中现有的其他节点，彻底杜绝窗口保存操作冲掉 `rearrange_policy` 策略配置。
