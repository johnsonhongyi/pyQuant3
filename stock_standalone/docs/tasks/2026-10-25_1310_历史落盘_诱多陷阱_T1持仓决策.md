# 历史落盘 + 诱多陷阱 + T+1 持仓决策

- 日期：2026-10-25
- 分支：`feature/signal-fusion-ladder`
- 新增：`ats/fusion/trap.py`、`ats/fusion/live_bridge.py`；改造 `tracker.py`、`replay.py`、`context.py`

## 一、三句话对齐

| 你说的 | 落成什么 |
|---|---|
| 不能每天都是新的一天，得有历史、得有记录 | 跟踪器状态落盘（`logs/fusion_state/tracker_state.json`），次日加载继续；日线上下文补昨日形态（振幅/收盘位置/上影） |
| 冲高回落的诱多、昨日大涨今日杀跌，都是非常不好的信号 | `trap.py` 五个盘中陷阱 + 跨日风险分；入局前硬拦，入局后清仓 |
| T+1 昨天买的，今天要不要跟 | `position_decision()`：清仓 / 减半 / 持有 / 加仓，每天开盘做一次 |

另外：**不新开系统**。`live_bridge.py` 只是订阅 `ats/ipc_bridge.py` 已有的 `signal_callback`，把上游已经流过的异动信号喂进同一个跟踪器。

## 二、五个陷阱（全部只用当下可见量）

| 标签 | 判定 | 含义 |
|---|---|---|
| **冲高回落** | 日内高点涨过 2%，自高点回落 ≥2.5%，且已跌破均价 | 拉给你看的 |
| **高开回落** | 高开 ≥3%，自开盘回吐 ≥1.5% | 开盘追进去当天被埋 |
| **前日大涨今日杀跌** | 昨日 ≥+7%，今日 ≤−2% 且量比 ≥1.3 | 隔夜风险，止损来不及 |
| **放量滞涨** | 量比 ≥2 但涨幅 <1%，且在均价下方 | 有人在派发 |
| **跌破均价放量** | 跌破均价 0.5% 且量比 ≥1.5 | 承接断了 |

## 三、跨日风险分（0~100）

买入当日不能卖，唯一可控的是"昨天长什么样"：

```
昨日涨停/接近涨停        +40
昨日大涨 >= +7%          +32
昨日长上影 >= 45%        +22
昨日收在低位 <= 35%      +14
5 日已涨 >= 25%          +18
昨日振幅 >= 10%          +8
```

- **≥80：禁止入局**（不管形态多漂亮）
- **≥50：只接"首异动 ≤2%"的更早第一波**

## 四、T+1 持仓决策

每天开盘对"昨日持仓"做一次，且开盘半小时内允许按强信号改判：

| 情形 | 动作 |
|---|---|
| 昨日大涨今日杀跌 | **清仓**（不留幻想） |
| 跨日风险 ≥85 | 清仓 |
| 冲高回落 ≥2% | 清仓 |
| 高开回落 | 减半 |
| 跌破均价且持续性 <50 | 减半 |
| 持续性 ≥75 且创新高、无陷阱 | 加仓 |
| 其余 | 持有 |

## 五、落盘（不能每天都是新的一天）

```python
tracker.save("logs/fusion_state/tracker_state.json")   # 收盘
tracker.load(...)                                      # 次日开盘
```

存的是：发令枪、证据链摘要、持续性、入局价、近 3 日摘要、陷阱计数。
不存：临时 bar 数据（避免膨胀）。恢复时只保留近 3 个交易日有活动的票。

回放里只要 `ReplayConfig(state_path=...)` 就会自动 load/save，跨日携带"昨日入局"。

## 六、接入现有 IPC（不新开发系统）

```python
from ats.ipc_bridge import IPCBridge
from ats.fusion.live_bridge import FusionLiveBridge

bridge = FusionLiveBridge()            # 自动加载昨日状态
ipc = IPCBridge()
ipc.start_realtime_listener(
    port=26670,
    data_callback=原有行情回调,
    signal_callback=bridge.make_callback(),   # ← 只换这一行
)
```

- 字段容错：`code/secid/stock_code/ts_code`、`price/last/now`、`pct/change_pct/percent` 都认；
- 回调里任何异常都吞掉，**绝不影响行情线程**（实测 6 类畸形输入，`errors=0`）；
- 输出：`snapshot()` 分四档（可下单 / 持仓 / 观察 / 剔除），`status_text()` 可直接打日志。

## 七、实测（10/19–10/23 全市场闭卷）

### 1. 陷阱拦截确实在起作用

```
被拦下：冲高回落中 1980 次｜跨日风险偏高且首异动>2% 102｜前日大涨今日杀跌 42｜跨日风险>=80 3
```

### 2. 结果对比（陷阱开启前 → 开启后）

| 口径 | 笔数 | 当日收盘 | T+1 | T+1胜率 |
|---|---|---|---|---|
| 开启前·可下单 | 28 | +0.65% | +1.93% | 62% |
| **开启后·可下单** | **22** | +0.72% | **+2.39%** | **65%** |

**少做 6 笔，T+1 从 +1.93% 提到 +2.39%，胜率 62%→65%。** 这正是"宁可不做"的定价。

### 3. 跨日风险分组（入局事件）

| 分组 | 笔数 | T+1 | 胜率 |
|---|---|---|---|
| 风险 0~30 | 685 | −0.06% | 46% |
| 风险 30~60 | 33 | **+2.36%** | 48% |
| 风险 60~100 | 2 | **−8.64%** | 0% |

风险 60 以上虽然样本少，但方向极差（−8.64%），支持"≥80 硬拦"。

### 4. T+1 持仓决策

```
持有 38｜减半 11｜加仓 1｜清仓（开盘半小时内昨日大涨今日杀跌）
```

## 八、诚实的代价

1. **答案覆盖从 34/48 掉到 28/48（71%→58%）**。陷阱拦掉了一些后来确实走出来的票——这是"不追冲高"的必然代价，换来的是 T+1 胜率与回撤改善。
2. **`冲高回落` 拦了 1980 次**，是五个陷阱里最激进的一条。它是逐 bar 判定的：价格重新站上均价就自动解除，所以不是"一天黑名单"，但会明显减少午后加速票的参与机会。
3. **清仓只在开盘半小时内触发**。再晚就不是"昨日大涨今日杀跌"的形态了，交给通用剔除规则（跌破 VWAP / 回撤 4%）。
4. **5 天样本**。22 笔可下单、2 笔高风险样本，方向可信，数值不可外推。

## 九、下一步

1. 用 `live_bridge` 跑一个真实交易日的影子，核对 IPC 信号字段映射是否覆盖全部上游模块（这是接入的第一道验收）。
2. 把 `trap` 的阈值（回落 2.5%、高开 3%）按板块分档：双创波动大，2.5% 的回落属于噪声。
3. 跨日风险分目前是线性加权，应改成按历史胜率拟合的单调映射（有 60 日样本后再做）。
4. `state_path` 接进 ATS 收盘流程，确保每天 15:05 落盘一次，而不是只在回放里落盘。
