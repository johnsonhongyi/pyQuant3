## 桌面桥改动

| 文件 | 最终行为 |
| --- | --- |
| `stock-strategy/desktop_bridge_runtime.py` | 串行常驻引擎池、RPC 之外的有界事件缓冲、异步进度发送、持久终态 outbox。 |
| `stock-strategy/desktop_strategy_agent.py` | 修复 queue 模块覆盖；按 RPC ID 分发响应；复用 HTTP 连接并保留 HMAC；统一领取接口与旧接口回退；有任务立即续领；空闲心跳节流。 |
| `stock-strategy/desktop_chat.py` | 使用后端下发的剩余预算，覆盖准备/恢复/生成；预留 15 秒用于中断和结果交付；进度约 200ms 合并，内容未变时不重复写。 |
| `stock-strategy/desktop_sidebar.py` | 侧边栏后台工作，线程独立 SQLite 连接；退出可取消 RPC 等待并关闭连接。 |
| `stock-strategy/muse_research_threads.py` | 缓存已确认 project ID；日常报告索引仅处理既有最近 100 项加新报告，首次/显式重建仍扫描完整目录。 |
| `stock-strategy/tools/run_desktop_strategy_bridge.py` | 打包线程模式下捕获桥后台线程日志；结构化日志加锁防止交错。 |
| `manage_window_layout.spec` | 默认打包配置显式加入新增运行时模块。 |

- 常驻进程在引擎指纹变化、传输故障、回合状态不确定时回收；空闲边界切换新引擎。
- 完成后按已安装协议尝试 `thread/unsubscribe`；旧引擎不支持时在 128 次完成后回收进程，限制常驻线程累积。
- 相邻文本增量合并；缓冲限制 4096 个事件/4MiB，溢出明确失败，不静默丢弃终态或 RPC 响应。
- 成功结果先进入本地缓存和 outbox，原租约/原 payload 重放；旧租约被替换或任务取消后不复活任务。
- 账本记录已经发出的回合；重领时发现未知完成状态会安全失败并要求重新提交，避免盲目再次调用模型。
- outbox 独立重试，已确认或已明确拒绝的记录保留 30 天/最近 5000 项并分批清理，未确认结果不清理。
- 取消、单任务证据错误等不再导致全桥无差别暂停 5 分钟；账号额度、速率和认证错误保留既有全局冷却。
- 增加排队、引擎准备、thread 准备、turn 启动、首段输出、模型完成和后端确认时间记录。

## Web/API 协同

内部库新增统一等待领取 `next` 和策略租约检查 `lease`；保留原 claim/chat_claim/result/chat_result 接口。

Web 对话、桥检测和个股研究使用带原有认证的 SSE，断线/旧接口回退到已有 GET 路径。API 使用持久数据库连接及领取/会话/过期索引，进程内通知取代研究阶段每 250ms 查库。

研究阶段下发绝对 deadline，桥领取时由后端换算剩余秒数，避免跨机时钟误差；取消记录保留为墓碑，迟到回执返回明确原因码。通用模型错误去掉硬编码 Hermes 前缀。

详见内部库任务记录：`stock-strategy/source/docs/tasks/2026-10-17_0112_Web桥流式派发性能优化.md`。
