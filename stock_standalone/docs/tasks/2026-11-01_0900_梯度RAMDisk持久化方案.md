# 梯度信号长期记忆：RAMDisk 与落盘边界

- 换手特征库通过 `get_multiday_store_path` 优先使用 RAMDisk，默认保留 9 个交易日；收盘及退出路径采集当日特征。RAMDisk 本身不等于可靠的长期备份。
- `linkage_storage` 对注册的运行状态使用 RAMDisk，收盘窗口稳定 120 秒后才归档，归档间隔 30 分钟，退出时再尝试保存。其有大小限制的普通文件备份会截取尾部，不可直接用于完整梯度日志。
- 目标：实时追加与缓冲优先放 RAMDisk；已结束的日期在后台直接压缩到物理盘临时文件，校验后发布，保存原始时点和来源。退出和收盘调度应复用现有时间窗口；不得在 UI 线程压缩。
- 恢复优先读取可用的 RAMDisk 当前文件；历史日期使用经过验证的物理压缩档。须区分实时、回放来源和交易日，禁止把收盘数据伪装为当时可用的盘中数据。
- 自动清理必须先确认归档完整、所有读取方支持压缩、无活跃写入、未涉及 PAPER 和未归档记录；还需明确保留期限、容量上限、磁盘空间不足和恢复失败的处理。当前只列候选，不实施删除。
- 本地 `logs/fusion_shadow` 检查到 5 个 JSONL 共 459254 字节；以 gzip 等价算法在内存中压缩这些样本共约 21751 字节。这些样本较小且重复度高，不能据此外推全年压缩率或 SSD 寿命。
- 尚未接入自动调度、实时日志 RAMDisk 路由、跨日 UI 压缩档读取与生产恢复验收；不要把当前基础模块视为完整方案。
