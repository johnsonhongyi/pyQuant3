- 管理器通过“启动程序”功能执行 shell 命令时，为 shell 加 `CREATE_NO_WINDOW`，保留命令解析、工作目录和环境变量；避免启动 Python 或其他命令时短暂显示蓝色 CMD。
- 性能分析器回退启动从 `CREATE_NEW_CONSOLE` 改为 `CREATE_NO_WINDOW`。用户确认本次没有打开该分析器，因此此项是清除明确存在的控制台创建点，不把它认定为用户闪窗来源。
- 两项针对性测试分别验证 GUI 命令 shell 隐藏，以及性能分析器回退不再新建控制台。
