# 信号面板跨日查询与同股汇总

- 范围：`signal_dashboard_panel.py` 的信号查询和显示，不改变信号产生、执行、风控或原累计计数器。
- 默认今日；可选择保留记录中的具体日期或全部日期。今日模式在跨午夜后自动重新查询。
- 按日期及代码汇总，显示最新匹配记录；搜索和类型筛选先于汇总，避免旧类型被新类型遮蔽。
- 日期时间显示至秒并参与排序；次数仍取原 `_stock_stats` 累计值，不能当作查询日期内次数。
- 右键查看该股明细，保留日期范围；“全部明细”取消日期、类型、搜索和折叠限制。
- 底部区分匹配记录、股票数、显示行数和保留记录量；卡片与类型计数取原始计数器，不随查询变化。
- 取消全表刷新仅取最后 500 行的限制；保留原 `_all_events` 最近 5000 条内存边界。未新增无限历史存储，已淘汰或重启前未保存的信号不能由本功能恢复。
- 保留分片填表；分片结束后才排序。刷新期间新事件或查询变更合并后重新准备完整任务。
- 验证：`QT_QPA_PLATFORM=offscreen python -m pytest tests/test_signal_dashboard_query.py -q --disable-warnings`，13 项通过；语法及 `git diff --check` 通过。
- 尚未验证：重新打包后的实际窗口布局和长时间实盘行情运行。未修改线上文件或重启线上进程。
