# IPO Codex CLI 互动与模拟账户对账

本文件保留分阶段实施记录，早期测试数量及“未打包”等描述仅代表当时状态。最终交付口径、生产版本及后续任务以 [完整交付说明](2026-10-15_1224_IPOCodexCLI完整交付与后续任务.md) 为准。

- 用户范围：在 IPO 控制台直接交流、分析 IPO 数据、审核并核对模拟账户；全部模拟，不接入券商。
- 本机 codex-cli 0.157.1，ChatGPT 登录已实测可用。本入口由用户点击触发 subprocess/codex exec，不配置 API Key，不改变原自动策略 Provider 开关。

## 入口与操作

```powershell
python run_ats.py --ipo-learning --codex-chat
```

- 现有控制台顶部“Codex CLI 对话”按钮，或“Codex CLI 互动 / 对账”页签。
- --codex-chat 直达轻量互动窗口，不启动自动采集或策略Worker；完整控制台的嵌入页签仍可使用。
- 可选六位股票代码，自由提问，或点击“分析 IPO”“审核 / 对账”。支持数据预览、新对话、恢复最近四轮对话和取消。
- 默认模型 gpt-6-luna，输入框可调整；每次最长180秒。旧的自动 Agent CLI 仍保持原有30秒上限。
- 问题、近期历史与限定数据摘要通过已登录的 CLI 发送；界面显式说明发送范围。忽略用户配置及项目文档自动注入，工作目录为独立临时 scratch，read-only 沙箱；提示词要求只使用所给证据、不调用工具、不修改文件或下单。
- 只读沙箱限制模型写入，但“不调用工具”是提示词约束，不宣称有独立的OS级读取隔离；本入口不提供自动代码修复权限。

## 证据与对账

- 只读生产 signal_history 最近30条日期信号，明确标为非实时行情；不读取任意列、密钥或配置全文。
- 读取原始及含费用回放的汇总，明确区分历史回放与当前账户。
- 读取隔离模拟账户持久化快照，按全部订单重放现金与持仓，并核对全部持仓的数量和成本。发送最近20条订单、最多30个持仓及完整核对结果；注明展示截断范围。
- 缺失、过大、非法或不可读数据明确返回状态，不伪装正常。没有券商回报不构成本项目模拟验收缺口。
- 对话和实际证据 JSON、SHA-256 保存至 data/ipo_learning/codex_dialogue.sqlite；不写生产数据库、不生成训练标签。取消/调用失败不写成功对话。
- 扩展已有 bounded CLI runner 的显式超时上限和取消事件，保留旧调用默认30秒及输出限额、进程树清理。
- 补齐标准桌面安装目录 Programs/OpenAI/Codex/bin 自动探测，并更新 PyInstaller/Nuitka 模块清单。
