# IPO 自动模拟交易运行

- 范围已确认全部模拟，不需要券商回报；真实成交证明不作为本任务验收项。
- 复用 TradingKernelService 的 PAPER 执行入口和账户。独立状态位于 data/ipo_learning/paper_auto/state，不重置现有 TK 主账户。
- 沿用现有默认初始模拟资金 100 万元；未改变策略仓位比例、T+1、止损和最终决策门禁。

## 已实现

- 双向成交额乘 0.0000754；每笔 SELL/REDUCE 成交再收 5 元，按分四舍五入，无最低佣金，不额外添加税费。现金扣费、订单 fee、累计费用、FIFO 配对净利润和重启对账一致。
- PAPER 适配器费用参数默认 0，兼容旧入口；自动入口显式配置本次费率。重启发现已保存费率不一致则阻断。
- 进程内串行成交，重复 order_id/request_id 幂等；持久化未确认则返回失败并阻断后续成交，保留内存状态供诊断，不宣称已落盘。落盘 flush/fsync 后原子替换。
- 自动入口只读发现最近 30 个信号日期的候选，启动时并入隔离账户已有持仓。本次候选 199 个；运行中候选不动态扩充，重新启动会重读。
- 每轮候选扫描后执行 ATS 统一决策，再进入 TK PAPER。源行情必须为当日且不超过 300 秒，执行前复查新鲜度及交易时段。缺行情等待，不合成交易。
- 单实例 Windows 文件锁；心跳、账户与现金/持仓对账。对账失败阻断后续成交。隔离退出不写主账户 reentry tracker。
- 修正构建指纹读取 git 输出在 Windows 下误用 GBK 的解码错误。

## 运行与停止

```powershell
python -u tools/run_ipo_paper_auto.py --interval 30
# 优雅停止：下一轮或下一标的检测到标记后退出
New-Item -ItemType File data/ipo_learning/paper_auto/STOP -Force
# 再次启动前仅移除上述停止标记
Remove-Item -LiteralPath data/ipo_learning/paper_auto/STOP
```

- auto_status.json：心跳、PID、扫描标的、有效行情数；完整轮次包含账户、现金和持仓对账。
- state/paper_account_state.json：持仓、现金、订单和费用；state/kernel_trace.jsonl 为执行审计。
- runner.stdout.txt / runner.stderr.txt：后台进程输出。后台进程受当前 Windows 会话管理，未配置开机自启或故障自动重启。
- 非交易时段 WAITING_MARKET_SESSION；无新鲜行情 WAITING_FRESH_MARKET_DATA；实际成交仍依赖现有 S5/执行门禁，不保证每天产生买卖。

## 验证

- 64 项定向测试通过：费用、FIFO 净盈亏、现金约束、幂等/并发重试、T+1、持久化故障、状态恢复及既有 PAPER/影子/回放回归。
- 生产数据单轮运行成功；测试标的被 S4 OBSERVE 门禁拒绝执行，未为了测试强行买卖。
- 含费用回放另存 data/ipo_learning/vwap_trade_replay_with_fees：170 笔，毛盈亏 17042 元，费用 948.08 元，净盈亏 16093.92 元。该历史回放仍未计滑点和组合资金约束，不能等同自动模拟账户收益。
- 原始数据库只读，未连接券商。既有不含费用回放产物保留。

## 仍有边界

- 当前模拟执行是一委托一次完整成交，撤单不模拟未成交挂单，不声称实现盘口排队或分笔撮合。
- 历史回放与实时模拟账户独立，历史交易不会导入实时现金或持仓。主界面是否显示隔离账户不在本次改动范围，隔离运行以 auto_status.json 和状态文件为准。
