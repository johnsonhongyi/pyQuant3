## 3. 可复现操作入口

在项目根目录执行。第一条仅输出当前盘点；退出码 2 表示业务前置条件未齐，不是工具崩溃。

```powershell
python tools/run_ipo_offline_learning.py --code 301689
python tools/run_ipo_offline_learning.py --candidates D:\审核数据\accepted_candidates.json --seal --json-out data/ipo_learning/offline_pipeline.latest.json
```

- 候选必须是现有 `offline_learning.validate_learning_candidate` 契约的 JSON 数组，含完整原始输入、规则 Proposal、Gate 因果链、成熟证据引用和人工审核标识；DPO 偏好也必须来自真实审核。
- 工具只读取 `logs/ipo_learning_reviews.sqlite` 的权威审核记录；缺记录、哈希/身份/时间不匹配或任一候选非法，整批失败关闭。
- 无候选或分组不足不会封存；`--seal` 才写封存仓库，`--json-out` 才写报告；工具不训练模型、不调用 Provider、不晋级、不下单。
- SEALED_AND_VERIFIED 只证明本批数据封存并回读通过；READY_FOR_TRAINING 是已有数据契约状态名，不构成训练授权。
- 盘点 JSON 的 `components.outcome_reviews.records` 提供 14 份证据 ID、哈希、路径与复核状态，供操作者在控制台逐条审核；本轮没有代替人工决策。
