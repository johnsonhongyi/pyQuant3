# 2026-10-22 21:26 【ATS退出同进程SBC联动持久化与Alt批量关闭闭环】

## 1. 任务背景与痛点根因

操盘手实盘使用反馈：
1. **ATS 退出未联动关闭同进程 SBC 走势窗口**：
   - 操盘手在 ATS 模式下打开了多个 SBC 个股走势图（同进程模式）；
   - 当关闭 ATS 主程序时，SBC 走势窗口未跟随退出，孤立遗留在桌面上；
   - 操盘手重启测试时发现“有时能随 ATS 一起退出，有时退不了”。
2. **正常点击关闭被 `[SBC防误关]` 误拦截**：
   - 日志出现多条 `🛡️ [SBC防误关] 检测到鼠标操作派发的异常关闭信号，已拦截并忽略关闭事件！`；
   - 操盘手点击窗口标题栏右上角关闭按钮被误判，导致点按关闭无效。
3. **Alt+点击关闭在 ATS 模式下被粗暴阻断**：
   - 操盘手按住 Alt 点击关闭想批量一键关闭这 5 个遗留窗口，日志提示 `ℹ️ [SBC关闭] 当前处于 ATS 模式，严格忽略 Alt+全部关闭功能，仅正常关闭当前个股窗口`，导致操盘手只能一个个手动点击 5 次关闭。

### 核心根因透析
1. **ATSMainWindow 退出时与同进程 SBC 的脱节**：
   - ATS 中通过表格、天梯、龙虎榜等打开的 SBC 窗口均为 `SBCIntradayChartDialog(parent=None)` 的同进程独立顶级窗口；
   - `ATSMainWindow.closeEvent` 遍历关闭子窗口时，`sbc_dlg.close()` 被防误关机制误拦截；主窗口关闭后，因仍存在打开的顶级窗口，Qt 事件循环无法退出，SBC 孤悬桌面；
   - 之前“有时能退”是因为通过持仓盯盘启动器打开的 SBC 是独立子进程（由 `SBCProcessManager` 统一关闭），而同进程窗口则受防误关拦截影响。
2. **防误关判定的设计缺陷**：
   - 原防误关设计的初衷是防止在走势图画布上双击或右键时派生误触 Esc；
   - 但原代码在 `closeEvent` 中简单用 `now < lock_until` 或 `mouseButtons != NoButton` 且 `(cursor.x >= width - 45)` 进行判定；当操盘手刚在走势图上查价缩放（`lock_until = now + 0.8`），随后点击系统标题栏关闭、任务栏关闭、系统菜单关闭或 Alt+关闭时，因光标不在窗口客户区内部的狭窄 45 像素内，被判定为“异常信号”强行 `event.ignore()` 吞掉。
3. **ATS 模式下 Alt+全部关闭被一刀切阻断**：
   - 原逻辑担心调用独立子进程的 `quit_and_save_all_sbc_windows()` 导致把 ATS 主程序也误 `quit()`，因而粗暴输出“严格忽略 Alt+全部关闭”；
   - 实际上操盘手的心智是：**按住 Alt 点击走势图关闭时，一键批量清空桌面所有走势图并持久化，同时保留 ATS 主程序正常运行**。

## 2. 解决方案与实施明细

### 2.1 彻底重构加固防误关机制（`ats/ui/intraday_strategy_dialog.py`）
- **放行边界明确**：
  1. 系统/ATS 退出流程（`is_app_exiting` 或 `_is_ats_shutting_down()`）下**绝对放行**，绝不阻断正常退出；
  2. 操盘手按住 Alt 联动关闭或全局批量关闭时**绝对放行**；
  3. 操盘手点击窗口标题栏右上角关闭按钮、系统菜单、任务栏关闭或代码调用 `close()` 时**绝对放行**；
- **精准防御边界**：
  仅当鼠标光标**明确落在走势图画布绘图区域内部**（`canvas.rect().contains(canvas_pos)`）且处于双击/右键锁定期时，才拦截误触信号，兼顾看盘防护与正常关闭。

### 2.2 解除 ATS 模式下 Alt+点击关闭阻断并抽象批量关闭引擎（`ats/ui/intraday_strategy_dialog.py`）
- 抽象通用函数 `close_all_open_sbc_dialogs(exclude=None)`：
  1. 先行原子写盘落盘保存当前所有打开窗口的几何坐标、尺寸与周期模式（`save_all_open_sbc_windows()`）；
  2. 启用全局防重入锁 `SBCIntradayChartDialog._global_alt_closing = True`；
  3. 遍历同进程内所有存活的走势窗口，逐一调用 `w.close()` 安全优雅注销定时器并从内存注册中心除名；
  4. 绝不调用 `app.quit()`，确保 ATS 主程序安然无恙；
- 同步加固快捷键 `Alt+Escape` 与 `Ctrl+Shift+Q`，在 ATS 模式下统一联动一键关闭桌面所有走势图。

### 2.3 加固 ATSMainWindow 退出收尾双重保障（`ats/ui/main_window.py`）
- 进入主窗口退出收尾时，立即将 `QApplication.instance().setProperty("is_app_exiting", True)` 并设置环境变量 `ATS_IS_CLOSING = "1"`，让所有子窗口瞬间获知退出状态；
- 在关闭独立子进程之余，显式调用 `close_all_open_sbc_dialogs()`，实现同进程走势窗口 + 独立子进程窗口双闭环统一回收，彻底终结孤儿窗口。
