# 2026-10-27 09:30 【窗口布局管理器添加 Alt+Shift+F 探测并应用推荐布局全局热键、快捷键编辑与开关功能闭环】

## 1. 任务背景与用户需求
用户在使用桌面窗口布局管理器（`webTools/manage_window_layout.py`）时，希望增加通过全局快捷键快速执行“探测屏幕分辨率并自动应用推荐布局”的能力（默认快捷键 `alt+shift+f`）。
具体要求：
- 在原有的“全局热键”配置之后紧随添加“探测推荐”热键项；
- 支持用户点击输入框直接按下组合键录入/编辑（`HotkeyLineEdit`）；
- 配备“绑定”测试保存按钮；
- 配备“启用”复选开关控制热键的激活与注销；
- 所有配置（热键键位、开关状态）跨会话自动持久化到 `window_layout_config.json`；
- 全局热键与原有的窗口呼出/隐藏热键（默认 `ctrl+alt+w`）支持互斥冲突检测，保证稳定性。

## 2. 核心架构与工程实现

### 2.1 独立子线程与 Win32 全局热键注册解耦 (`ManagerHotkeyThread`)
- **多热键 ID 解耦**：`ManagerHotkeyThread` 扩展支持 `hotkey_id` 参数（默认 `0xAFC0`，探测推荐使用 `0xAFC1`），彻底杜绝 Windows 热键 ID 冲突；
- **非阻塞消息循环**：通过 `RegisterHotKey(None, hotkey_id, ...)` 将热键注册至独立子线程的 Windows 消息队列，利用 `PeekMessageW` 轮询与 `sleep(0.05)` 实现 0% CPU 占用；
- **Qt 信号线程安全通知**：子线程捕获 `WM_HOTKEY` 后通过 `detect_apply_signal.emit()` 发送 Qt 信号，主 UI 在主线程安全调度布局探测与应用逻辑。

### 2.2 推荐布局应用逻辑抽取与复用 (`detect_and_apply_recommended_layout`)
- 将原托盘菜单中的推荐布局探测逻辑抽取为公共入口 `detect_and_apply_recommended_layout(self, source, show_tray_message)`；
- 无论是托盘右键触发还是后台全局热键触发，均统一调用：
  1. `self.load_screen_info()` 探测硬件显示器分辨率与拓扑；
  2. `core.detect_display_config_name(self.config_manager)` 计算最匹配的方案名称；
  3. `self.apply_layout_by_name(rec_name, show_tray_message=True)` 切换并精准移动窗口，并在托盘弹出气泡通知。

### 2.3 UI 紧凑流式排列与自适应右对齐 (`bottom_bar` / `FlowLayout`)
- 在底部栏左侧，紧跟“全局热键”之后依次排列：
  1. `lbl_detect_apply_hotkey` ("探测推荐:")
  2. `le_detect_apply_hotkey` (只读快捷键录入框，默认 `alt+shift+f`)
  3. `btn_bind_detect_apply` ("绑定" 按钮)
  4. `chk_detect_apply` ("启用" 开关复选框)
- `FlowLayout` 右对齐分水岭自适应调整为 `align_right_from_index=8`，保证左侧两组热键配置与自启复选框整齐紧凑居中，右侧保存/应用/工具箱按钮平稳右对齐。

### 2.4 配置持久化与生命周期管理
- `window_layout_config.json` 顶层增加 `detect_apply_hotkey` 与 `detect_apply_hotkey_enabled` 字段；
- `on_detect_apply_switch_changed`、`on_bind_detect_apply_clicked` 与 `save_all_config` 均完整同步最新配置并落盘；
- 窗口关闭（`closeEvent`）与强制退出（`force_quit`）均严格释放并注销热键线程，杜绝僵尸线程与资源泄漏。
