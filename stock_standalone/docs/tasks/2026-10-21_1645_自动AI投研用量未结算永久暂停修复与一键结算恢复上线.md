# 2026-10-21 16:45 自动AI投研用量未结算永久暂停修复与一键结算恢复上线

## 1. 任务背景与问题定位

- **用户反馈**：
  - 界面提示：“用量未结算 · 已暂停” / “已暂停：存在未结算或用量未知的任务”。今日用量显示“未结算 1”，没有任何自动恢复方式；
  - 用户明确要求：“修复这个用量未结算 · 已暂停问题，没有自动恢复方式；添加可以直接处理结算，并恢复自动 AI 投研后台工作流程的功能”；并在 UI 截图中的“自动 AI 投研”摘要区“系统设置”按钮左侧红圈标注了期望的操作入口。

- **根因穿透**：
  1. 任务认领时向 `automatic_research_runs` 插入记录 `(job_id, day, started_at, token_budget)`，其中 `usage_known` 默认为 0；
  2. 若模型发生超时（如历史出现的 `MODEL_TIMEOUT`）、CLI报错（`CLI_ROUTING_DISCOVERY_FAILED`）或租约过期，任务在 `ai_jobs` 中被置为 `expired`/`failed`，但从未上报 `token_usage`，故 `settleAutomaticResearch` 从未被有效调用；
  3. 后端判定 `u.Unknown = sum(CASE WHEN usage_known=0 THEN 1 ELSE 0 END)`，只要 `u.Unknown > 0` 便永久返回 `usage_unsettled`，且 `claimAutomaticResearch` 永久拦截后续所有任务派发；
  4. 系统此前**既缺乏对终态/超时任务的自动对账自愈机制，又缺乏前端/后端的一键手动结算恢复手段**，导致系统因单次异常任务终身卡死。

---

## 2. 解决方案与核心改动

### 2.1 后端全链路双重自愈对账（Automatic Self-Healing & Reconciliation）
- 在 `source/easy-stock-analysis/backend/internal/httpapi/automatic_research.go` 中实现 `autoReconcileResearchRuns(e dbExecer)`：
  1. 租约与生命周期超时清理：将 `expires_at <= now` 或租约 `lease_until` 过期的运行中任务置为 `expired`；
  2. 终态任务对账结算：对 `usage_known = 0` 的记录，只要其关联的任务已达终态（`expired`, `failed`, `cancelled`, `completed`），自动标记 `usage_known = 1` 且 `total_tokens = COALESCE(total_tokens, 0)`；
  3. 在 `automaticResearchDaily` 及 `claimAutomaticResearch` 前自动触发对账，彻底消除未结算死锁；
  4. 支持通用 `dbExecer` 接口（`*sql.DB` 与 `*sql.Tx`），杜绝 SQLite 嵌套事务 write lock 死锁。
- 在 Python 策略引擎 `follow_ai.py` 的 `sync_ai` 循环中补充防御性对账 SQL，实现策略主循环与 Go API 层的双重自愈保障。

### 2.2 一键手动直接结算与工作流恢复功能（Direct Manual Settle & Resume）
- **Go 后端新增接口**：
  - 注册 `POST /api/v1/ai/auto-research/settle` 与 `POST /api/v1/ai/auto-research`；
  - 接收管理员请求，将当前所有租约过期任务置为 `expired`，并将所有 `usage_known = 0` 记录强制结算为 `usage_known = 1, total_tokens = 0`，重置系统状态并返回最新的投研运行时与记录快照。
- **React Web 前端可视化入口**：
  - 在 `source/easy-stock-web/src/components/AutomaticResearchSettingsPanel.tsx` 的 `summary` 视图（即用户红圈标注位置）增加操作区：
    当存在未结算任务（`status === 'usage_unsettled'` 或 `unsettled_runs > 0`）时，醒目高亮展示 **【结算并恢复】** 琥珀色操作按钮；
  - 在设置抽屉（`settings` 视图）的“历史用量与运行记录”区域增加 **【一键处理结算并恢复】** 按钮；
  - 点击按钮后异步调用 `/api/v1/ai/auto-research/settle`，无缝将状态恢复为“可运行”（`ready`），并给出成功提示。
- **样式与交互对齐**：
  - 在 `auto-follow.css` 与 `styles.css` 中适配明暗双色主题风格，支持禁用态与加载态防抖。
