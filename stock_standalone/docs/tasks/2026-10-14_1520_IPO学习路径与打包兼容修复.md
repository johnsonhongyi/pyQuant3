# IPO 学习路径与打包兼容修复

## 改动

- 默认运行根统一使用 sys_utils.get_app_root()；源码 bootstrap 的 __file__ 仅帮助导入模块，不能作为数据库、配置、报告或账本根目录。
- 覆盖 IPO 回放、验收、离线学习、影子评估、模拟自动运行、模拟验收、来源采集、配置初始化、预检和成熟标签工具；控制台和影子运行器同步对齐。
- IPO/LLM 运行时、请求生产器、控制线程、快照/交互库、封存读取、来源采集、CLI 路径和 UI 路径使用 safe_resolve_path，兼容 Windows RamDisk 不支持 GetFinalPathNameByHandle 的情况。
- Gate 默认根在源码与打包模式下均尊重 INSTOCK_APP_ROOT，省略 root 时在调用时获取系统根；显式 root 仍优先。
- 决策快照使用 IPOTradingCenter.learning_root，新增可选参数保持旧调用兼容；自动模拟入口显式传入隔离报告根。默认交易账本也在实例创建时绑定物理运行根，保留原 ats/config 相对布局。
- ListingAnchorStore 默认路径锚定系统根；显式 store_path 保持不变。部署配置移除源码目录和 CWD 搜索回退，使用系统配置释放入口。
- 配置释放传递准确 base_dir；LLM 运行时仅在系统运行根下触发默认配置恢复，不向任意显式隔离目录复制系统配置。

## 安全边界

- 不盲目替换所有 resolve：券商无关的 Ollama 验收证据、成熟标签复核证据、报告输出边界仍执行严格物理解析及目录包含检查；无法验证物理路径时拒绝该操作，不回退到可能越界的词法路径。
- 成熟证据目录解析失败现在返回 UNREADY，避免异常逃出安全边界。
- 未移动既有数据、覆盖配置或改变交易门禁。打包解包目录中旧的临时数据不会自动迁移。

- 最后一次针对默认账本与证据错误边界的回归 41 项通过，其中包含 29 项路径测试。

- compileall 和 git diff --check 通过。测试未训练模型、未连接券商、未写生产数据库。

## 运行衔接

- 使用 STOP 标记优雅停止原自动模拟进程，再以同一隔离账户重新启动加载新路径实现；不重置现金、订单或持仓。
