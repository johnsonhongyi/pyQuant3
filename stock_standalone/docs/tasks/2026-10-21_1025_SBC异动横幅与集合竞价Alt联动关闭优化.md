# SBC 异动横幅与集合竞价面板 Alt 联动关闭优化

## 1. 任务背景与核心诉求
用户提出以下三大核心要求：
1. **严格禁止自行打包**：项目中已存在经过工程化打磨的标准打包工具，严禁自行执行 `pyinstaller ats.spec`，打包工作由用户或专属打包流程统筹；
2. **优化持仓盯盘 (SBC) 顶部异动提醒横幅的 `✕ 关 (X)` 按钮**：
   - 支持按住 Alt 鼠标点击进行全局窗口联动关闭；
   - 行为与系统中现有的 Alt 联动机制（如 Alt+点击连板天梯联动、Alt+标的切换等）保持高度一致，点击后批量收起所有已打开 SBC 窗口的异动提醒横幅和脉冲动画；
3. **集合竞价面板添加小关闭按钮并支持 Alt 联动**：
   - 在图表右上角竞价叠图（`09:25 成交/开盘` 浮层）的左侧添加小巧精致的关闭按钮 `✕`；
   - 单击普通关闭当前窗口的集合竞价叠图；
   - 按住 Alt 点击联动关闭所有已打开 SBC 窗口的集合竞价叠图。

## 2. 根因剖析与交互设计

### 2.1 异动横幅关闭按钮 (`btn_ack_attention`)
- **原逻辑**：
  - 按钮绑定 `_ack_attention_banner()`，仅收起当前单个窗口的横幅（`self.banner_attention.hide()` 并停止 `timer_attention_pulse`）；
  - 快捷键方面，`keyPressEvent` 曾将 `Alt+X` 绑定为触发全量退出 SBC，产生歧义；
- **优化方案**：
  - 借助 `is_alt_modifier_active()` 或检测当前鼠标/键盘 修饰键 `Qt.KeyboardModifier.AltModifier`；
  - 单击普通关闭：调用 `_do_ack_single_attention_banner()` 仅收起当前窗口；
  - Alt + 单击 或 键盘按下 `Alt+X`：调用 `_ack_all_sbc_attention_banners()`，借助 `SBCWindowMemoryManager` 与 `QApplication.topLevelWidgets()` 遍历当前进程内所有活动的 `IntradayStrategyDialog` 实例，批量安全收起横幅；
  - 彻底将 `Alt+X` 释放为“全局联动收起异动横幅”，符合用户心智模型；更新 ToolTip 提示。

### 2.2 集合竞价叠图 (`_draw_auction_overlay`)
- **原逻辑**：
  - 集合竞价叠图是 `SBCChartCanvas` 在 `paintEvent` 中通过 `_draw_auction_overlay` 绘制的 QRect 浮层，之前只能通过右键菜单或快捷键切换开关，右上角缺乏直观的物理关闭按钮；
- **优化方案**：
  - 在 `SBCChartCanvas.__init__` 中实例化专用的悬浮关闭微型按钮 `self.btn_close_auction = QToolButton(self)`：
    - 尺寸设定为 15x15 像素无边框微按钮，半透明深灰背景，悬停时高亮红底白字；
    - ToolTip: `"关闭集合竞价图 (按住 Alt 点击将关闭所有窗口竞价图，快捷键: Alt+C)"`；
  - 在 `_draw_auction_overlay` 绘制竞价叠图时，动态计算竞价卡片矩形位置 `(x, y)`，将 `btn_close_auction` 精确移动到 `(x + 5, y + 4)` 停靠在卡片左上角，同时将竞价标题文字向右平移至 `x + 24`，保证布局紧凑、不遮挡任何文字与图表曲线；
  - 当 `show_auction_chart` 为 False 或图表数据为空时，自动隐蔽 `btn_close_auction.hide()`；
  - 按钮点击响应：
    - 若按住 Alt 键，调用模块级 `set_all_sbc_auction_visible(False)` 联动关闭全局所有 SBC 窗口的集合竞价叠图并重绘；
    - 若未按住 Alt 键，仅将当前窗口 `self.show_auction_chart = False` 并重绘；
  - 快捷键支持：按下 `Alt+C` 触发全局所有窗口竞价图显示状态联动翻转。

## 3. 代码变动与工程实现

### 3.1 核心改动文件
- **`ats/ui/intraday_strategy_dialog.py`**:
  1. `SBCChartCanvas`:
     - 增加 `self.btn_close_auction` 及其专属 QSS 悬停样式；
     - `_draw_auction_overlay`: 动态同步位置与显隐；
     - `_on_auction_close_btn_clicked`: 实现单窗与 Alt 联动关闭；
  2. 模块级全局同步函数：
     - `set_all_sbc_auction_visible(visible: bool)`: 遍历所有 topLevel SBC 窗口同步 `show_auction_chart` 状态；
     - `_ack_all_sbc_attention_banners()`: 遍历所有 topLevel SBC 窗口批量收起异动提醒横幅；
  3. `IntradayStrategyDialog`:
     - 升级 `_ack_attention_banner`: 检查 `is_alt_modifier_active()`，支持 Alt 联动收起；
     - 优化 `keyPressEvent`: 释放 `Alt+X` 为全局收起横幅，增加 `Alt+C` 全局开关竞价叠图；
     - 升级相关 UI ToolTip 提示文本。

### 3.2 自动化测试
- **`tests/test_sbc_alt_close_linkage.py`**:
  - `test_sbc_attention_banner_alt_linkage_close`: 验证单窗横幅关闭与 Alt 联动关闭所有窗口横幅；
  - `test_sbc_auction_chart_alt_linkage_close`: 验证竞价叠图左侧按钮创建、单窗关闭与 Alt 联动关闭所有窗口竞价叠图。
