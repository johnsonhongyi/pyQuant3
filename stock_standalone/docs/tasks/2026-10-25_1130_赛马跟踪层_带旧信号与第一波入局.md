# 赛马跟踪层：带上旧信号、第一波入局、入局后才剔除

- 日期：2026-10-25
- 分支：`feature/signal-fusion-ladder`
- 模块：`ats/fusion/tracker.py`（新增）、`ats/fusion/replay.py`（接入）、`ats/ui/fusion_ladder_dialog.py`（页签）、`ats/fusion/validate_track.py`（验收）

## 一、要解决的问题

之前的融合层是**无状态**的：每一根 bar 独立打分，打不出分就 L0，出过分也不记得。

后果有三个，正好对应实战里的三个痛点：

| 现象 | 原因 |
|---|---|
| 10:12 看到"缩量转放量"，却不知道 09:45 已经"逆势带头" | 旧证据全部丢失 |
| 某个时点被否决一次，全天再没机会 | 没有连续迭代，否决=永久出局 |
| 尾段加速的票只能靠追高进场 | 判断依据是"位置漂亮"，不是"跑到了第几圈" |

## 二、设计：一只票一条状态

```
发令枪（首异动） → 证据链累积 → 持续性分 → 第一波入局 → 持有 → 走弱 → 剔除
```

### 1. 发令枪

每只票第一次出现异动（任一形态 / L2+ / 相对强度）时记下：时间、价格、涨幅、触发原因。
之后所有判断都以这个点为原点，`since_first_pct`（自首异动涨幅）才是"第几圈"的度量，不是当日涨幅。

### 2. 带上旧信号（证据链）

- 形态首次出现记一条，同形态同日只记一次（不刷屏）；
- 级别抬升记一条（同级别 15 分钟内不重复）；
- 输出成可读链：`09:45 逆势带头(L2) → 09:54 缩量转放量 → 10:12 两阳加速(L3)`；
- 每条入局记录都带 `attach_n`（证据条数）与 `chain`，下单时能看到"为什么是它"。

### 3. 三个可计算量（把口语变成公式）

| 说法 | 字段 | 算法 |
|---|---|---|
| 量能持续 | `vol_frac` + `vol_recent/vol_base` | 放量 bar（量比≥1.2）占比 + 近期量能是否衰减 |
| 想的多回踩的少 | `efficiency` | 累计上涨 / (累计上涨 + 累计回踩)，bar 级 |
| 站得住 | `hold_frac` | 站上 10 日 VWAP 的 bar 占比 |

持续性分 `persist` = 0.24·vol_frac + 0.22·efficiency + 0.16·hold_frac + 0.15·证据 + 0.09·量能保持 + 0.06·新鲜度 + 0.08·跨日携带。

### 4. 第一波入局（不是追高）

入局需要同时满足：

- `persist ≥ 55`
- 至少 3 根 bar 观察、至少 2 条证据
- **自首异动涨幅 ≤ 5%**（第一波）
- 站上 10 日 VWAP（启动确认门槛）
- `efficiency ≥ 0.52`（不是来回震荡）

### 5. 入局以后才开始剔除

| 阶段 | 允许的动作 |
|---|---|
| 入局前（观察） | **不因分数低而剔除**，只在 90 分钟毫无新证据时过期 |
| 入局后 | 跌破 10 日 VWAP×0.985 / 回撤≥4% / 8 根未创新高且量能衰减 → 剔除 |

这是刻意的：入局前做减法会把"还没跑起来的好马"筛掉，正是之前召回上不去的根因。

### 6. 跨日携带

同一 `RaceTracker` 实例跨日复用：昨日入局且未剔除 → 今日以"持有"开局，并给 `persist` 加 0.08 的连续性权重。
这就是"一天可以骗人，多日骗不了"的落地方式。

## 三、从入局到可下单：两条路径

入局 624 笔/5 天（约 125/日）仍然太多，加最后一道闸。闸门不是拍脑袋，是用 5 日 T+1 结果网格搜出来的：

| 路径 | 条件 | 用途 |
|---|---|---|
| **A 主升延续** | 两阳加速 + 赛道强度≥0.6 + 首异动≤3% + persist≥55 + 效率≥0.85 | 当机立断 |
| **B 低风险收敛** | 缩量转放量 + 赛道强度≥0.6 + 首异动≤3% + persist≥60 + 效率≥0.85 | 观察参与 |

两条路径共用三道否决：赛道弱、已追高、回踩过多。命中任一形态即放行，因此不会漏掉"刚启动"的另一种走法。

## 四、实测（10/19–10/23，全市场 5573 只，闭卷）

### 1. 漏斗

```
L2+ 记录 11682 条  →  第一波入局 624 笔  →  可下单 28 笔
                     (约125/日)            (约5.6/日)
```

### 2. 结果

| 口径 | 笔数 | 命中榜单 | 当日收盘 | 次日收盘(T+1) | T+1胜率 | 之后MFE | 之后MAE |
|---|---|---|---|---|---|---|---|
| 第一波入局（全部） | 624 | 54 | +1.21% | -0.01% | 46% | +2.77% | -1.59% |
| **可下单清单** | **28** | **4** | +0.65% | **+1.93%** | **62%** | +2.55% | -1.22% |

- 入局时自首异动平均 **+1.87%**，即"发令枪响后不久"，不是追高；
- 入局后剔除 473 笔，平均 **-0.00%**——剔除规则基本做到"不赚不亏地离场"，没有把利润砍掉；
- 观察期过期 1575 笔（入局前自然消亡，不占名额）。

### 3. 逐日可下单

| 日期 | 入局 | 可下单 | 命中榜单 |
|---|---|---|---|
| 10/19 | 52 | 10 | 1 |
| 10/20 | 128 | 8 | 3 |
| 10/21 | 101 | 2 | 0 |
| 10/22 | 107 | 6 | 0 |
| 10/23 | 236 | 2 | 0 |

10/21、10/23 只有 2 笔——不是系统坏了，是那两天"两阳加速"结构稀缺（多数是跳空一字型），闸门按设计"宁可不做"。

### 4. 答案覆盖

本周涨幅榜 48 只（可映射代码的），**34 只（71%）拿到过入局信号**，答案组入局 54 笔，T+1 **+10.16%**、胜率 **85%**。

## 五、必须承认的缺口

**跟踪层解决了"质量"和"可解释"，但没解决"认得出答案"。**

答案组 vs 其他组的入局时刻特征对比：

| 特征 | 答案组 | 其他组 | 差值 |
|---|---|---|---|
| persist | 60.26 | 60.12 | +0.14 |
| vol_frac | 0.26 | 0.34 | **-0.08** |
| efficiency | 0.88 | 0.85 | +0.04 |
| evidence_n | 2.54 | 2.53 | +0.00 |
| **first_pct** | **3.17** | **1.53** | **+1.64** |
| **enter_pct** | **5.44** | **3.40** | **+2.05** |
| theme_rank | 0.85 | 0.86 | -0.01 |

结论三条：

1. **持续性分几乎不区分答案**（60.26 vs 60.12）。它能保证"进得去、出得来"，但不能保证"抓到最大的那匹"。
2. **唯一显著差异是"已经涨得更多"**（首异动 +1.64%、入局时 +2.05%）。也就是说，答案在入局那一刻就已经更强——这就是必须把"低风险参与"和"当机立断"分成两套清单的原因。
3. **答案组的量能占比反而更低**（0.26 vs 0.34）。大牛不是靠脉冲放量，是靠**连续、均匀、不衰减**的量能——这印证了"量能持续"比"放量"更重要。

## 六、接口

```python
from ats.fusion.tracker import RaceTracker, deploy_path

tracker = RaceTracker()          # 跨日复用，才能携带"昨日入局"
st = tracker.update(code="300296", ts=ts, price=px, pct=pct,
                    vwap10=vw10, vol_ratio=vr, tier=3, rar=71.0,
                    patterns=["两阳加速"], day="2026-10-23")
if st.stage == "入局":
    path = deploy_path(st.to_dict())   # "A 主升延续" / "B 低风险收敛" / ""
```

- 回放：`ReplayConfig(track=True)`（默认开），结果里 `res.entries` / `res.meta["evictions"]`；
- 报告：`render_report()` 新增「赛马跟踪·第一波入局」「入局后剔除」两节；
- 验收：`python -m ats.fusion.validate_track` → `logs/fusion_mine/track_validation.md`；
- UI：ATS「梯度🧬」→「赛马跟踪（第一波入局）」页签，按持续分排序，带证据链。

## 七、下一步

1. **多日赛道热度**：目前 `theme_rank` 是当日实时强度，答案组与其他组无差异（0.85 vs 0.86）。应改为"近 3 日赛道强度滚动均值"，让"机器人"这类连续多日强的赛道自然浮出——这是唯一还没试过的、非未来函数的区分维度。
2. **加仓与减仓**：现在只有"入局/剔除"两档。持续性分 ≥75 且连续创新高应加仓，走弱应减半，而不是一次清仓。
3. **样本扩到 60 个交易日**：5 天 28 笔的结论方向可信、数值不可外推。当前门槛（55/60/3%/0.85）都是在 5 天上搜出来的，必然有拟合成分。
4. **真实盘口替代代理**：`taker_buy_ratio` / `bid_pressure` 仍由 bar 推导，接入逐笔后"量能持续"的判定精度会明显提升。
