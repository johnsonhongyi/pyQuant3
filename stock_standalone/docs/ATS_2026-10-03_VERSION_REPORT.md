## 合成 GUI 测试说明与本次修正

- `python scripts/ats_gui_workload.py` 默认是 **60 秒、5,000 行、Qt offscreen** 合成负载：每 250ms 推送固定格式的变动行情帧、每 20ms 采集事件循环延迟，并调用 ATS 的真实接收/投影/刷新路径。它不弹出可交互窗口，不连接实盘行情，也不执行真实账户业务，因此不能用来观察完整产品功能。
- 原日志中的核心资源缺失来自测试只复制了 `config/`，没有复制 `JSONData/stock_codes.conf` 和 `MonitorTK.ico`；Sina 名称缓存启动会尝试历史/网络补全；行情刷新会排入 IPC 请求；测试帧还可能排入 HDF 历史读取。
- `2026-10-03` 是非交易日，生产 `archive_window()` 按策略拒绝归档窗口外写入。合成 UI 关闭时发现脏缓存会安全拒绝关闭并恢复 watcher，原测试又在超时后强制退出，造成重复退出日志。
- 已修正测试隔离：每次运行使用唯一 `.ats_validation` 子目录并复制核心资源；设置专用 `ATS_SYNTHETIC_QT_WORKLOAD` 跳过名称缓存联网/历史引导；关闭合成测试里的 TDX、IPC、价格和历史读取；测试数据库及缓存落在隔离目录；只对该测试进程的临时缓存开放排空窗口，不改变生产归档门禁。测试完成状态现在要求退出码为 0 且主窗口确实关闭。
- 本次短冒烟：`python scripts/ats_gui_workload.py --seconds 5 --rows 500`，`exit_code=0`、`completed=true`、`shutdown_complete=true`；关闭/归档定向用例 4 项通过。剩余 Qt 字体目录及 offscreen 插件提示是非致命环境提示；本次没有执行 72 小时测试。
