# stock-strategy / MUSE 策略分析与全流程自动化落地方案

日期：2026-10-04。主策略：stock-strategy/strategy.yaml，v1.9。用户确认 MUSE 当前执行范围为模拟交易、信号生成与复盘，策略正在更新。

**结论**

- 应在 MUSE 已运行的模拟闭环上补齐配置校验、确定性回放、实验对照和成交归因，再按独立阶段接入本地 ATS/TK 与真实交易接口。
- 当前策略主要采用“环境许可 → 趋势筛选 → 个股触发 → 仓位管理 → 逻辑证伪退出”；已有规则体系不等于已经验证收益优势。
- 首要问题是 YAML 中 P28/P29 的结构重复，其次是配置与代码阈值的对应、不同入场通道的评分口径，以及模拟成交的时间与成本真实性。

**5. 快速迭代交易信号的方法**

**5.1 先把0信号、0成交拆开**

```text
输入可用
→ 宇宙有效
→ 候选池入选
→ 环境与趋势资格
→ P8 / P9 / P24 / P18触发
→ 硬风控允许
→ 订单受理
→ 实际/模拟成交
→ 平仓完成
→ 标签成熟与复盘
```

- 每层同时记录输入数、通过数、首个拒绝原因和全部规则结果；用唯一候选/意图计数，避免把重复轮询当新样本。
- 无信号但数据完整属于策略结果；行情缺失、报价过期、资金不足、订单拒绝分别属于不同问题。
- 某门通过率很低时，先检查数据与口径，再用对照回放判断过滤价值；通过率低本身不证明规则应放宽。

**5.2 每个实验固定一套可复现输入**

- 每次运行冻结release_id、strategy_version、config_hash、code/build_id、data_snapshot_hash、市场、方向、账户和sleeve。
- 主策略与实验策略读取同一批按时间截断的快照，固定手续费、撮合、退出和初始状态；只改变一个明确变量。
- 运行中不重新读取正在编辑的YAML给交易或日志换版本；新版本在预先声明的市场日边界生效，旧持仓保留入场依据。
- 原始bar时间、收盘时间、available_at和decision_at一起存；盘中累计VWAP不能被收盘后的整日VWAP覆盖。

**5.3 第一轮实验优先顺序**

| 实验 | 当前依据 | 唯一变量/研究口径 | 主要验收指标 |
| --- | --- | --- | --- |
| E01 池分8与6 | crypto_exp已定义 | 延续入场池分单变量实验，方向独立 | 新增机会的净期望、回撤、换手、资金占用 |
| E02 v1.9追空偏离 | 上限2.5%已定义 | 固定现行冷却与止损，按入场VWAP距离分桶分析 | 逆向最大波动、净收益、触发后反抽与误杀 |
| E03 v1.9冷却 | 不及预期后12h已定义 | 先量化同币种重复入场和冷却期机会；反事实只在回放研究 | 每个交易episode成本、重复止损率、冷却损失 |
| E04 P25持续性 | YAML记“站上≥N天待定” | 在候选实验中增加连续站上条件，主参数不变 | 延续捕获率、弱反抽误入率、机会减少量 |
| E05 P24质量 | 跟随独立通道 | 单独校准P24影子分；每次只检验一个增量因子 | 跟随净收益、板块过滤增益、入场延迟 |

- 扩大币圈宇宙提高的是覆盖范围，也改变标的分布；不要同时改宇宙与池分后把收益变化归为某一个规则。
- 已实现的near-miss应补上同时间点的其余门状态，不能把所有6–8分标的都视为“本该成交”。

**5.4 样本外与反事实评价**

- 按时间划分研究、验证和最后留出的样本外窗口；相邻窗口按最长标签/持仓跨度隔离，避免同一轮行情重复泄漏。
- 股票记录T+1/T+3/T+5机会和交易结果；币圈按策略持仓周期记录小时标签，未成熟样本暂不计入胜率。
- 动态宇宙保存当日真实选择结果和可用时间，历史回放不能用今天的Top18或事后新币历史替代当时宇宙。
- P30的摆动需要右侧2根小时K确认；事件只能从确认时刻开始使用，不能在摆动发生时提前标注可交易信号。
- 被过滤标的的反事实需要跑完整退出、成本和持仓约束；最高价可用于机会标签，不能当作保证能实现的卖价。
- 多个候选版本与同日相关标的不能简单当独立观测；按交易日/episode聚合估计差异，并记录试过的全部实验。

**5.5 复盘看板**

| 维度 | 必须输出 |
| --- | --- |
| 交易质量 | 净收益、每笔净期望、盈亏比、最大回撤、尾部损失、收益/风险占用 |
| 信号质量 | 漏斗通过率、拒绝原因、成熟标签、误入/误杀、入场后的最大顺向/逆向波动 |
| 执行质量 | 受理率、成交率、部分成交、滑点、费用、报价新鲜度、信号到成交延迟 |
| 归因 | 市场/方向/通道/版本/sleeve/情绪状态/板块/入场时段/流动性 |
| 对照 | 主版本与候选版本在共同样本的差异、独立交易日、区间估计、样本不足标记 |

- 规则升格同时看净期望、回撤与稳定性；提高胜率但降低盈亏比、提高成本，不能视为进步。
- 20–30笔适合早期诊断；仍遵循当前“小于20笔不改规则、止损不放宽、用户批准升版本”的约束。

**8. 真实交易执行需要补齐的能力**

| 主题 | 必须实现的行为 |
| --- | --- |
| 订单生命周期 | INTENT→APPROVED→SUBMITTING→ACK/PARTIAL/FILLED/CANCELED/REJECTED；受理状态不更新已成交持仓 |
| 提交结果未知 | 持久化UNKNOWN并查询券商订单/成交，核实后再决定重试，避免超时导致重复发单 |
