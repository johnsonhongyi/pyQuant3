# ATS 2026-09-21 版本说明

## 版本结论

本版本加强了 IPO 交易中心的执行端风险闸门。所有改动仍限于模拟决策、回放和测试；未连接券商网关，未启用自动真实下单或自动合并。

## 已完成

### 仓位上限与全仓轮动

- 全仓轮动在生成和执行阶段都扣除保留持仓，避免换入后组合仓位穿透潮汐上限。
- 无可信快照时，轮动只可使用被平旧仓对应的预算；买入前完成现金与最小一手预检查，失败时不平旧仓、不扣现金、不写平仓记录。

### 普通买入最终闸门

- `BUY`、`BUY_SCOUT`、`BUY_CONFIRM` 成交前必须复核市场快照。
- 快照必须新鲜、同交易日、非 `T0_INSUFFICIENT`，并与指令时间戳在 300 秒内关联。
- `T4_PANIC_ACCEL`、`BLOCK_NEW_BUYS`、零风险乘数、组合或同标的仓位满额、现金不足一手时均拒绝成交，且不创建幽灵持仓。
- 合法指令按剩余预算截断到整手，不得超过可用现金。

### 测试与历史夹具

- 历史手工成交夹具改为显式提供同日关联快照，不向生产逻辑引入兼容后门。
- 新增跨日快照执行路径回归：三种普通买入动作均被拒绝，并验证持仓、现金、平仓记录不变。

### Antigravity 编排收敛

- Worker 回传严格压缩为结构化 JSON；外层冗余对话、日志和传输错误不进入后续模型上下文。
- 单轮 worker 时限为 240 秒，Python 侧保留强制终止兜底。
- Worker 提示不再携带会要求其自行 `claim` 或 `submit` 的旧协议，任务状态只由编排器与复审控制。
- 读取预算和文件白名单已写入提示。CLI 缺少工具调用上限，因此下一阶段应由本地监控器实施硬性早停。
