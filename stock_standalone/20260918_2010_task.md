# 2026-09-18 20:10 任务记录：集中交易指挥室全表格列宽自由拖拽与跨会话自动持久化能力接入

## 1. 核心需求与视觉痛点
- **操盘手现场明确指示 (P0)**：
  > “添加列持久化能力”
- **排版与交互痛点诊断**：
  1. **列宽截断痛点**：在全池横向赛马排位天梯表 (`tbl_rank`) 中，由于默认宽度设置过紧，导致“动能分”截断为“动能...”，“启动时点”截断为“启动...”，影响超短核心信息的直观读取；
  2. **缺少持久化能力**：操盘手手动拉伸各列后，未落盘至物理配置，下次打开窗口或数据刷新时列宽被重置回硬编码的狭窄尺寸；
  3. **持仓与指令表同样需要**：持仓组合表 (`tbl_pos`) 与待执行指令表 (`tbl_orders`) 同样需要支持列宽记忆与自适应；
  4. **窗口与分割比例记忆**：窗口尺寸（`geometry`）和左右分屏比例（`QSplitter`）需要支持跨会话记忆，避免反复手动拉伸。

---

## 2. 架构设计与工程落地 (KISS / SOLID / DRY)

### 1. 接入全系统统一标准的列宽持久化体系 (`setup_persistence`)
- 在 `IPOCommandRoomTableWidget` 中增加标准持久化接口：
  - `setup_persistence(config_key, default_widths, max_widths)`：对接 `ats.ui.styles.setup_header_persistence`；
  - 表头全列设为 `QHeaderView.ResizeMode.Interactive`，支持操盘手鼠标平滑自由拖拽；
  - 监听 `sectionResized` 并通过 1000ms 防抖定时器原子写入 `window_config.json`，与全系统其他 Tab 保持 100% 一致的设计规范。

### 2. 精调默认列宽，彻底杜绝文字省略号截断
- **天梯表 (`tbl_rank`)**（持久化键：`ipo_cmd_rank_table_header_v1`）：
  - 排名: 45
  - 代码: 58
  - 名称: 78
  - 现价: 58
  - 动能分: **70px** (原 55px，彻底消灭“动能...”)
  - 启动时点: **78px** (原 65px，彻底消灭“启动...”)
  - 角色: 85px
  - 决议: 280px (自适应填满)
- **实盘持仓组合 (`tbl_pos`)**（持久化键：`ipo_cmd_pos_table_header_v1`）：
  - `[58, 78, 60, 62, 62, 68, 85]`
- **集中待执行指令 (`tbl_orders`)**（持久化键：`ipo_cmd_orders_table_header_v1`）：
  - `[75, 58, 78, 60, 70, 240]`

### 3. 提供一键自适应与恢复默认列宽功能
- `auto_fit_columns()`：一键根据当前视口内容自适应列宽，且强制保持 `Interactive` 并立即落盘；
- `reset_default_widths()`：一键恢复最佳排版并持久化；
- 在右键菜单中增加对应动作项：“📐 一键自适应列宽” 与 “🔄 恢复默认列宽布局”。

### 4. 窗口几何尺寸与 Splitter 状态集中持久化
- `_load_dialog_state()`：启动时自动恢复上次保存的窗口位置尺寸（`ipo_cmd_dialog_geometry`）与左右分割比例（`ipo_cmd_splitter_state`）；
- `_save_dialog_state()`：在 `closeEvent` 和 `hideEvent` 中集中原子落盘，同时显式调用三张表格的 `save_column_widths()`，彻底杜绝关窗时防抖延时丢失。
