# ATS 系统底层关键链路全流程性能优化实施任务清单 (2026-09-26 09:05)

## 任务背景与核心原则
依据最新 ATS 源码底层关键链路与 8 大关键纠偏与技术实质，全面实施系统优化方案：
- 跟踪期限与终结状态保真：杜绝固定“近 3 日”，按各候选自身 followup 期限构建有效索引，结算到期 MISSED
- 证据保真跳写（Evidence-Fidelity Skip-Write）：无检查点/状态/事件变更时跳过磁盘 I/O
- 宽表单次规范化与共享只读投影：大宽表一次性预处理，阻断反复扫描与深拷贝
- 持久待发 (Outbox) + 消费原子提交 + 异步 ACK：支持跨日未送达事件持续投递
- Windows 文件句柄共享与受控隔离自愈校验门：杜绝 WinError 32 与脏自愈
- 配置写入队列限容、超时丢弃与退出 Flush 门禁
- 表格增量渲染脏单元格复用与边界按需测宽
- 休市板块短 TTL 负缓存与实时失效机制
- 注入关键链路微观耗时遥测 (Telemetry)
- 严守约束：保持所有业务语义，不添加或运行测试。
