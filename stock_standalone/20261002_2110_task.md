## 背景与问题诊断
- 用户在使用新制作的 `nuitka_build_ats_console_onlyClang.bat` 打包 ATS 时报错：
  `FATAL: Error, failed to locate module 'h5py' that you asked to include.`
  `[ERROR] ATS Nuitka Clang build failed.`
- 经代码库、依赖调用链及实际打包日志排查：
  1. ATS 全工程源码中 0 行代码使用 `h5py`，底层日线、分时与次日数据均统一使用 `JSONData.tdx_hdf5_api.SafeHDFStore` 和 `pd.read_hdf`，底层引擎全部为 PyTables (`tables`)。

  3. 成熟的 TK 打包脚本 `nuitka_build_console_onlyClang.bat` 中使用的是 `--include-package=tables` 及 `tables._comp_lzo`、`tables._comp_bzip2`，完全没有 `h5py`。

   - 移除 `--include-module=h5py`；
   - 将 `--include-module=tables` 替换为 `--include-package=tables` 并补充压缩模块 `--include-module=tables._comp_lzo` 和 `--include-module=tables._comp_bzip2`。
2. **更新 `restore_tk_nuitka_env.bat`**：
   - 移除环境验证命令中的 `h5py`，防止环境恢复脚本验证失败。
3. **更新 `ats.spec`**：
   - 移除 `hiddenimports` 中冗余的 `'h5py'`，消除 PyInstaller 打包告警。
