# 2026-10-07 10:27 PVE与LXC 102算力倾斜优化：4核提升、内存重调与Docker调度优化

## 任务背景与目标
当前 PVE 宿主机（J4125 4核物理CPU，3.8GB 内存）运行了 iKuai（VM 100）、OpenWRT（VM 101）与 Docker（CT 102）。
由于 iKuai 和 OpenWRT 仅承担基础网间路由与 Clash 功能，负载很轻，用户要求：
1. **全面倾向 LXC 102 与 Docker 的性能调度**；
2. **将 LXC 102 的 CPU cores 提升至 4 核**（从 2 核提升为 4 核，吃满 J4125 4个物理核心算力）；
3. **优化 PVE 宿主机内存分配**：
   - 适当降低 iKuai (VM 100) 内存（从 800MB 降至 512MB，释放 288MB）；
   - 适当降低 OpenWRT (VM 101) 内存（从 608MB 降至 384MB，释放 224MB）；
   - 将释放的物理内存倾斜给 LXC 102（内存从 1792MB 提升至 2048MB ~ 2304MB）；
4. **优化 Docker inStock 容器的性能调度与资源限额**：
   - 适配 4 核 CPU 调度，优化 CPU 优先级；
   - 将 inStock 容器内存限额从 1280MB 提升至 1536MB ~ 1792MB；
5. **保证系统与网络平稳无中断**：
   - 使用 PVE 动态调整指令（`qm set`, `pct set`），安全生效；
   - 验证 iKuai、OpenWRT 网络与路由转发正常，LXC 102 4核与内存正确识别，Docker inStock 策略扫描性能进一步提速。
