# 📈 系统多周期与信号指标使用说明文档

欢迎使用多周期联动策略筛选与信号分析系统。本说明文档支持与 AI 互动实时更新，AI 写入修改后，再次在主窗口按 `Alt+/` 即可即时呈现最新内容。

## 一、核心选股与评分指标：`strong_structure_score`
`strong_structure_score`（强势结构回踩反包评分）是系统筛选**主升浪强势股**的核心评分指标，具有极强的排除低位补涨、防抄底套牢的功能：
1. **基础合格门槛（硬性过滤）**：
   - **均线趋势**：日线级别要求 `MA5 > MA20` 且 `MA20` 保持基本走平或向上趋势；其他大周期（如 2d, 3d, w）要求均线为多头强势排列。
   - **MA5 主升判定**：今日 MA5d 不能处于大跌向下倾斜趋势（要求 `MA5 >= MA5_last1 * 0.995`）。
   - **OBV 白黄线要求**：OBV 白线必须运行在黄线（MAOBV）之上（`obv_val >= maobv * 0.99`）。不满足此资金条件的股票，评分直接清零（0分），直接剔除无增量资金的底部弱反弹股票。
2. **反弹起爆节点（Turnaround Node）特征加分**：
   - **弹性涨幅**：起爆阳线涨幅越大加分越多，最高 +20 分。
   - **倍量加分**：起爆日若成交量翻倍（`vol_ratio >= 1.9`），大幅加分 +10 分。
   - **量能持续性（BS）**：今日成交量相对上一个倍量日的比率：
     - 若 `bs >= 0.7`（量能未萎缩，属于资金加速段），加分 +10 分；
     - 若 `bs < 0.4`（缩量上涨、主力离场嫌疑），**扣减 15 分**（防低位抄底套牢）。
   - **OBV 强势加分**：若 OBV 白线显著拉开黄线距离（`obv_val > maobv * 1.05`），加分 +10 分。
   - **神奇九转（TD）加分**：起爆日若处于 TD买入/卖出结构初期（1、2结构或-1、-2结构，即反包节点），加分 +15 分；若处于 -8、-9 结构，加分 +5 分。
   - **反包范围**：今日收盘价突破昨日最高价，加分 +10 分；突破昨日实体高点，加分 +5 分。

## 二、量能与资金监控指标
系统基于成交量和 OBV 精准度量主力资金意图：
1. **`obv_val`（OBV 白线）**：累积能量潮。反应资金是持续流入（白线抬高）还是流出（白线下降）。
2. **`maobv`（OBV 黄线）**：OBV 的 30日 移动平均线，作为多空强弱分界线。白线在黄线上方运行是主力深度介入的信号。
3. **`obv`（OBV 金叉天数）**：白线在黄线上方的连续周期数。
4. **`vol_ratio`（倍量比率）**：今日成交量 / 昨日成交量。大于 2.0 代表资金倍量起爆。
5. **`bs`（量能衰减度）**：当前成交量 / 上一个倍量日的成交量。
   - `bs >= 0.7` 且股价上涨：量能健康，资金承接良好，主力锁仓加速。
   - `bs < 0.4` 且股价上涨：缩量上涨，买盘衰竭，警惕冲高回落或低位诱多。

## 三、策略编辑器表达式配置指南
您可以在主界面的**策略编辑器**（右侧或双击策略）中为每个周期配置 Pandas 过滤表达式：

### 💡 常用经典配方：
1. **强势起爆共振配方**：
   - 日线 `d` 条件：`strong_structure_score > 65 and obv_val > maobv`
   - 周线 `w` 条件：`strong_structure_score > 60`
   - 2d 周期条件：`strong_structure_score > 60`
2. **资金共振（白线在黄线上 + 均线多头）**：
   - 日线 `d` 条件：`close > ma5d and ma5d > ma10d and obv_val > maobv and bs > 0.6`
   - 周线 `w` 条件：`close > ma5d and obv_val > maobv`
3. **神奇九转起爆（1结构反包）**：
   - 日线 `d` 条件：`td_setup == 1 and obv_val > maobv and vol_ratio > 1.8`

## 四、ESC 二次过滤配置参考
按 **`ESC`**（或 `Alt+Q`）调出主界面下方的二次过滤输入框。该输入框针对全周期的扁平化大宽表（支持后缀 `_d`、`_2d`、`_w`、`_m`）进行过滤：
* **示例 1**：`obv_val_d > maobv_d and bs_d > 0.6 and percent > 2.0`
  *(过滤日线 OBV 白在黄上、日线量能充沛且今日涨幅大于 2% 的个股)*
* **示例 2**：`obv_val_w > maobv_w and obv_val_d > maobv_d`
  *(过滤日线与周线 OBV 双级别多头共振个股)*
* **示例 3**：`vol_ratio_d > 1.9 and close_d > ma5d_d`
  *(过滤日线倍量突破五日线的个股)*

## 五、通达信自动通道与上涨支撑线核心指标说明

系统完整还原了通达信『自动画通道』与『KX DRAWLINE 上涨支撑线』算法：

```text
================================================================================
          【通达信自动回归通道 与 KX DRAWLINE 上涨支撑线 全景图例】
================================================================================
 价格(高)
   ^
   |                 / (上轨 ch_upper 压力位)
   |               /
   |             /                 / (中轨 ch_mid 线性回归线)
   |           /                 /     [全局通道方向: ch_dir == 1, 倾角 ch_slope_deg]
   |         /                 /
   |       /                 /                 / (下轨 ch_lower 通道底座支撑位)
   |     /                 /                 /     [低吸蓄势区间: 0% <= ch_pos <= 35%]
   |   /                 /     .-----------/
   | /                 /     /           /
   |/                /     /           / <--- 支撑线价格: ch_supp_price (通达信 KX DRAWLINE 支撑线)
   |               /     /           /        (★ 支撑线方向由 ch_supp_slope_deg > 0° 标识!)
   |             /     /           /          (对应通达信图表红字『支撑:9.38元』)
   |           /     /           /
   |         /     /           / <--- 股价回踩蓄势区: 在支撑线上方 [-1% <= 偏离 <= 4.5%]
   |       /     /           /
   |     /     /           /
   |   /     /           /
   | /     /           /
   +------------------------------------------------------------------------> 时间(天)
     <---------------------- 通道区间 (ch_nod 天) ------------------------>
================================================================================
```

### 1. 通道方向与物理倾角标识（核心）：
* **`ch_dir`（核心通道方向）**：
  * `1`：**上涨通道**（通道回归中轨向上倾斜，对应通达信左上方绿色通道与向上箭头）；
  * `-1`：**下跌通道**（通道回归中轨向下倾斜）；
  * `0`：水平横盘通道。
* **`ch_slope` / `ch_slope_deg`（斜率与倾角）**：
  * `ch_slope > 0` 且 `ch_slope_deg > 1.5°`：通道昂首向上，过滤走平无动能的弱势通道；
* **`ch_pos`（通道相对位置百分比 0% ~ 100%）**：
  * `ch_pos <= 30`：股价处于通道下轨支撑区域，极佳低吸盈亏比；
  * `ch_pos >= 80`：股价处于通道上轨阻力区域。

### 2. 上涨支撑线专属方向与位置标识（KX DRAWLINE）：
* **`ch_supp_price`（支撑价格）**：通达信图表中红字标出的『支撑:XX.XX元』今日动态基准价格。
* **`ch_supp_slope` / `ch_supp_slope_deg`（支撑线方向标识！）**：
  * **支撑线的延伸方向正是由 `ch_supp_slope_deg` 标识**！
  * 当 `ch_supp_slope_deg > 0`（如 +25°、+43.4°）时，代表自最近低点以来连线的支撑线昂首向上（上涨支撑线）；
* **`ch_supp_pos`（支撑线偏离度 %）**：
  * 当前价格相对支撑线的偏离百分比 `(close - supp_price) / supp_price * 100`；
  * `ch_supp_pos` 处于 `-1.0% ~ +4.5%` 代表精准在支撑线上方窄幅震荡回踩。
* **`reversal_line`（翻转防守价）**：通达信图表中黄字标出的『反转:XX.XX元』短线防守价。

## 六、通道与支撑线实战演示策略

您可以在主界面策略编辑器或手动测试窗口中直接使用以下经典配方：

### 策略 1：通道下轨支撑震荡低吸 (通道百分位法)
```python
ch_dir == 1 and ch_slope_deg > 1.5 and close >= ch_lower and ch_pos >= 0 and ch_pos <= 35
```
* **实战解析**：锁定大趋势处于上涨通道（方向向上），且股价回调到通道下轨支撑区（0%~35%）窄幅震荡蓄势，守住下轨不破位，盈亏比极佳。

### 策略 2：通达信 KX 上涨支撑线回踩企稳 (支撑偏离法)
```python
# 1. 大通道是上涨通道 (中轨向上)
ch_dir == 1 
# 2. 通达信支撑线方向是向上延伸的 (★ 核心判断！)
and ch_supp_slope_deg > 0 
# 3. 股价守住支撑线，且在支撑线上方 -1% ~ +4.5% 的极窄区间内回踩企稳
and close >= ch_supp_price and ch_supp_pos <= 4.5
```
* **单行紧凑写法**：`ch_dir == 1 and ch_supp_slope_deg > 0 and close >= ch_supp_price and ch_supp_pos <= 4.5`
* **实战解析**：要求大通道向上（`ch_dir == 1`），通达信上涨支撑线向上倾斜（`ch_supp_slope_deg > 0`），股价守在今日支撑线价格上方（`close >= ch_supp_price`），且偏离不超过 4.5%（`ch_supp_pos <= 4.5`），属于盈亏比极高的极窄回踩伏击点。

### 策略 3：通道支撑 + 黄金分割 + 见底信号共振 (防破位反弹法)
```python
ch_dir == 1 and ch_pos <= 35 and close >= ch_lower and (close >= fib_50 or sig_bottom == 1 or close >= reversal_line)
```
* **实战解析**：在下轨支撑位附近出现黄金分割中轴(fib_50)、MACD低位见底信号(sig_bottom)或翻转线(reversal_line)三重共振，杜绝阴跌破位。

### 策略 4：多周期周日共振选股 (周线上升 + 日线支撑震荡)
* **周线 (W)**：`ch_dir == 1 and ch_slope_deg > 2.0 and close > fib_38`（周线锁定大级别上涨通道，拒绝下行股）
* **日线 (D)**：`ch_dir == 1 and close >= ch_lower and ch_pos <= 35 and ch_supp_pos >= -1.0 and ch_supp_pos <= 5.0`（日线回踩下轨与支撑线震荡）

## 七、外置持久化补充文档加载机制 (免重新打包)

系统具备外置持久化配置能力：
1. **外置文件路径**：`config/indicator_help_custom.json`
2. **免打包热生效**：程序打包为 EXE 后，如需新增或修改任何指标解释、新增策略演示，**无需重新编译打包程序**！
3. **如何更新**：直接编辑或让 AI 修改 `config/indicator_help_custom.json`，在程序中重新按下 **`Ctrl + /`**（指标说明）或 **`Alt + /`**（多周期说明），即可实现 0 延迟即时加载生效！
