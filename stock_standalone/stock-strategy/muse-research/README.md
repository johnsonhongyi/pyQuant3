# Muse 模拟策略研究

自动策略会话通过官方 app-server 绑定同名原生项目。已有会话另已整理到桌面可见的同名侧栏分组。

当前桌面应用的项目注册表尚未显示该原生项目；新会话的原生项目绑定已验证，但自动进入自定义侧栏分组尚未实现。不要将两者视作同一机制。

打开 [研究索引](INDEX.md)，可按股票代码、任务类型和短 ID 定位最近的研究。

- 标题包含日期时间、任务类型、重点股票代码、提案计数及任务短 ID。
- `reports/` 保存由已校验提案整理的中文研究摘要；原始结构化结果仍由任务账本保存。
- 研究与实际模拟执行分开记录；此目录不保存密钥、账户数据库或行情快照。
