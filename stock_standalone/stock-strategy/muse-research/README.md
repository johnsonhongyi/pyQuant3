# Muse 模拟策略研究

自动策略会话通过官方 app-server 绑定同名原生项目，并由独立桥通过已安装 Codex App Tools 的 MCP 接口自动归入同名侧栏分组。

原生项目与可见侧栏分组是两个接口，侧栏归组不再依赖桌面项目注册表同步。新会话创建时登记待办，分析结束后自动归组并读取确认；失败/中断会话同样处理。

待办保存在独立桥自己的 agent.db，桌面离线或升级连接失效时退避重试，重启后继续；接口不兼容时保持 pending 并在心跳显示 sidebar_error，不伪装归组成功。每次连接动态查找已安装运行时及能力，不固定插件版本、引擎哈希或分组 ID。

打开 [研究索引](INDEX.md)，可按股票代码、任务类型和短 ID 定位最近的研究。

- 标题包含日期时间、任务类型、重点股票代码、提案计数及任务短 ID。
- `reports/` 保存由已校验提案整理的中文研究摘要；原始结构化结果仍由任务账本保存。
- 研究与实际模拟执行分开记录；此目录不保存密钥、账户数据库或行情快照。
