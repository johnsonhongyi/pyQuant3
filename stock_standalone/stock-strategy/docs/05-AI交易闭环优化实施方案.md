# AI 交易闭环优化实施方案

日期：2026-10-31
范围：`#auto-follow` 自动跟单模拟盘、`#stock-ai` 个股/强势股分析、自动 AI 投研
原则：paper only，不接券商、不下实盘单；所有改动可回滚、可追溯、point-in-time。

---

## 1. 现状诊断（来自生产账户与日志的实测）

| 现象 | 证据 | 结论 |
|---|---|---|
| 自动交易长期零成交 | 账户 `cash=500000`、`closed=0`；事件 300 条中 `MARKET_GATE/BLOCK` 87 次、`SKIP` 140 次 | 闭环断在入场第一道门 |
| 市场门禁一刀切 | 2026-10-30 全天情绪 `分歧 / risk 50.9`，`market_blocked` 直接返回，候选池与结构信号根本未计算 | 分歧日完全停摆，无法积累样本 |
| AI 决策门从未执行 | `AI_DECISION` 事件 0 条；`ai_latest` 停留在 2026-10-22 | AI 提案过期后硬阻断，且从未有新鲜提案 |
| 候选结构通过率极低 | `SKIP` 中 `P4 change gate` 122 次、`P8 VWAP gate` 18 次 | 候选来自昨日连板，开盘即超涨幅上限或远离 VWAP |
| 强势股分析不进入执行 | `candidates()` 仅取昨日连板 + 前三题材龙头 + 手动 | `#stock-ai` 的强势股结论与跟单池脱节 |
| 自动投研不闭环 | 研究快照盘后报 `source snapshot expired`；复盘仅在 `closed_count` 增加时触发 | 零成交时永不触发复盘，AI 结论无出口 |
| 无参数优化 | 无归因表、无决策反事实、无参数版本叠加 | `strategy.yaml` 静态，系统不会变好 |

### 根因归纳

1. **单点硬门禁**：市场情绪、AI 提案、P4/P8 任何一项不满足即整轮终止，缺少分层降级。
2. **AI 与执行耦合方式错误**：AI 被当作 5 分钟有效期的硬开关，而不是加权证据；桌面端离线时交易冻结。
3. **缺少决策账本**：没有记录"当时看到了什么、为什么没买、后来涨跌如何"，因此无法归因。
4. **缺少参数回路**：即使有归因，也没有受约束的自动调参、版本叠加与回滚机制。
5. **候选池偏窄**：只盯昨日连板，错过同题材中继、放量突破、回踩 VWAP 确认的强势股。

## 2. 目标闭环

```
S0 数据/宇宙  行情、日线、分钟线、题材、情绪、涨跌停梯队、热榜、强势扫描
      ↓
S1 多层信号   趋势(25) + 日内VWAP结构(25) + 相对强度(20) + 题材(15) + 流动性(15)
      ↓
S2 决策/仓位  市场状态→暴露系数；评分阈值；AI 叠加/否决；仓位与上限
      ↓
S3 执行       模拟委托、T+1、封板不成交、滑点/费用口径、单日去重
      ↓
S4 持仓/退出  止盈、分批止盈、移动止盈、VWAP止损、十日VWAP破位、时间止损、跌停不假定成交
      ↓
S5 归因       决策账本 + 1/3/5 日远期收益 + 被拦截样本反事实 + 交易MFE/MAE
      ↓
S6 优化       有界参数提案 → 护栏校验 → 版本叠加 params.json → 次日生效 → 退化回滚
      └──────────────────────── 回到 S1/S2 ────────────────────────┘
```

### 2.1 市场状态与暴露（解决"一刀切停摆"）

| 状态 | 情绪 `status` | 暴露系数 | 入场阈值 | 最大持仓 |
|---|---|---|---|---|
| attack | 高位延续 | 1.0 | 60 | 5 |
| balanced | 高位震荡 | 0.8 | 64 | 4 |
| cautious | 分歧 | 0.5 | 70 | 2 |
| defense | 强分歧 / 高位退潮 / 高位样本不足 | 0 | 禁止新开 | 0 |

- `defense` 仍执行卖出、网格、轮动，不清仓、不追涨。
- `cautious` 不是"放开"，而是**减半仓位 + 提高评分门槛 + 只做前两名**，用真实小样本换取归因数据。
- 风险分只作为 `cautious` 内的额外扣分项，不再单独一票否决。

### 2.2 多层信号评分

| 层 | 权重 | 关键因子 |
|---|---|---|
| 趋势 | 25 | VWAP1>VWAP3>VWAP5、收盘≥MA20、MA5>MA10、5日斜率 |
| 日内结构 | 25 | 价格处于 VWAP 带、日内 VWAP≥VWAP3、最近三根量价齐升、无冲高回落/高开低走 |
| 相对强度 | 20 | 5日超额、距20日高点、当日涨幅在池内分位 |
| 题材 | 15 | 题材涨幅、上涨节点占优、是否题材前五 |
| 流动性/风险 | 15 | 成交额、非ST、非封板、价格区间 |

- 硬否决仍保留：ST、封涨停、报价/日线不新鲜、上一交易日缺失、T+1、跌停不卖、现金不足。
- `P4` 从"0<涨幅≤7%"改为评分项：`≤-3%` 或 `≥max_day_chg×1.15` 硬否决，中间区间按分位给分；避免把"回踩 VWAP 后转强"误杀。
- `P8` 带宽从 `1.005~1.025` 调整为 `0.995~1.030`（配置化），保留"日内 VWAP≥VWAP3"与量价确认。

### 2.3 AI 投研闭环

- **加权叠加**：AI `follow` 且新鲜 → +12 分；`avoid` → 否决；`observe`/缺失 → 0 分；`fallback=neutral` 时桌面离线不冻结交易。
- **有效期**：提案 TTL 900 秒（原 300 秒），与 15 分钟研究节奏匹配；过期只失去加分，不再硬阻断。
- **复盘必触发**：每个交易日 15:35 触发一次盘后复盘，即使零成交也复盘"为什么没交易"；盘前 08:35 生成当日计划。
- **上下文增强**：研究输入加入 `regime`、`loop` 漏斗、`attribution` 归因、`optimizer` 提案、强势扫描，AI 的结论直接针对闭环瓶颈。
- **输出出口**：AI 叙事与逐股计划进入 `ai_latest/ai_review`，在跟单页与优化提案并列展示；参数变更由确定性优化器执行，AI 不直接改参数（避免不可审计的自动改参）。

### 2.4 归因账本（S5）

`loop.db` 三张表：

- `decisions`：每个交易日每股一条，记录评分、分层明细、状态、拦截原因、AI 增量、当时价格；结算 1/3/5 日远期收益。
- `trades`：平仓记录，含入场评分/状态、退出原因、MFE/MAE、持有天数。
- `runs`：每日归因与优化运行摘要。

产出：

- 按拦截原因：样本数、3日胜率、平均远期收益（"拦掉的该不该买"）。
- 按评分桶：胜率与收益单调性（检验评分是否有效）。
- 按市场状态：attack/balanced/cautious 的期望与样本。
- 交易层：胜率、盈亏比、平均 MFE/MAE、止损后是否反弹。

### 2.5 参数优化（S6，有界自动）

允许调整的键（其余一律拒绝）：

| 键 | 方向 | 单步上限 | 边界 |
|---|---|---|---|
| `execution.signal.entry_threshold` | 双向 | 2 分 | 58–76 |
| `execution.signal.vwap_band.high` | 仅放宽 | 0.005 | ≤1.040 |
| `buy.max_day_chg` | 仅放宽 | 0.5 | ≤9.0 |
| `sell.stop_loss` | **仅收紧** | 0.5% | -8% ~ -4% |
| `sell.take_profit` | 双向 | 1% | 6%–18% |
| `execution.regime_policy.cautious.exposure` | 双向 | 0.1 | 0.3–0.6 |

护栏：

1. 最小样本 `min_samples=8`，同一参数 3 个交易日内不重复调整。
2. 每日最多 1 次变更，写 `params.json` 叠加层（不修改只读 release），版本号 `v1.11+opt.N`。
3. 每次变更写 `optimizer_history.jsonl`：证据、旧值、新值、原因、时间。
4. 自动回滚：应用后连续 5 笔平仓累计亏损超过初始资金 2%，回滚到基线并暂停自动优化 5 个交易日。
5. `mode=propose` 时只展示不应用；`mode=off` 完全关闭。

### 2.6 强势股扫描（补候选池）

- 来源：热榜 Top、当日涨停梯队、题材龙头、手动标的。
- 预筛：涨幅、成交额、题材强度、热榜共识分。
- 精算：批量日线（≤30 只/次）算 5/20 日强度、MA、VWAP；评分≥55 且通过硬否决者进入 `route="strong"`。
- 每 10 分钟刷新，最多 24 只，最多 8 只并入执行候选，避免请求放大。
- `#stock-ai` 顶部展示同一份扫描结果，支持"加入跟单"与"打开分析"。

## 3. 代码落点

| 文件 | 变更 |
|---|---|
| `signal_engine.py`（新） | 纯函数：日线/分钟指标、分层评分、硬否决、入场带 |
| `loop_state.py`（新） | regime 映射、漏斗、状态汇总 |
| `strong_scan.py`（新） | 强势股扫描与缓存 |

| `auto_follow.py` | 接入 regime/评分/AI 叠加/强势池/闭环状态/盘后任务；分批止盈与移动止盈 |
| `follow_ai.py` | AI 门改叠加、TTL、上下文增强、盘后复盘触发 |
| `follow_research.py` | 盘后快照容忍与标记，不再整体报错 |

| `source/easy-stock-web/src/components/AutoFollowWorkspace.tsx` | 闭环总览、漏斗、归因、优化、强势扫描 |
| `source/easy-stock-web/src/components/StockAIAnalysisWorkspace.tsx` | 强势股扫描条 + 加入跟单 |
| `test_*.py` | 新增信号/归因/优化测试；更新版本与门禁断言 |

部署：

1. 服务器上跑全部单测（`python3 -m unittest`）。
2. `package-auto-follow.py` 生成 release → `deploy-auto-follow.sh` 热更新 worker（带锁、preflight、回滚）。
3. Web 构建后按 `deploy-web-assets.sh` 的方式原子替换静态资源（内容哈希资源先落地，再切 `index.html`）。
4. API 无需重建：`/api/v1/auto-follow` 原样透传 state，新字段自动可见。

## 4. 验收标准

| 项 | 标准 |
|---|---|
| Worker | `systemctl is-active`、`NRestarts=0`、preflight 通过、心跳 <240s |
| 闭环状态 | API `state.loop.stages` 九阶段齐全，`funnel` 计数随扫描变化 |
| 市场状态 | `cautious` 日不再整轮 `market_gate` 返回；`defense` 日仅卖不买 |
| AI | 桌面在线时 `ai_latest` 当日更新；离线时事件为 `AI_NEUTRAL` 而非阻断 |
| 强势扫描 | `state.strong_scan.rows` ≥1（交易时段），候选含 `route="strong"` |
| 归因 | 盘后 `state.attribution` 有样本数与远期收益；`loop.db` 有 decisions |
| 优化 | `state.optimizer.status` 为 `hold/proposed/applied` 之一，含证据与版本 |
| UI | `#auto-follow` 显示闭环漏斗与优化卡片；`#stock-ai` 显示强势股条并可加入跟单 |
| 安全 | 无实盘接口；release 只读；params 仅写数据目录；失败自动回滚 |

## 5. 风险与回滚

- **放宽入场导致回撤**：cautious 仅 0.5 暴露、2 只上限、阈值 70；止损 -6% 与单日 -3% 熔断不变；连续 5 笔亏损自动回滚参数。
- **AI 离线误放行**：AI 仅作为加分项，确定性结构门槛仍在；所有 `AI_NEUTRAL` 入决策日志可审计。
- **优化过拟合**：最小样本、单步上限、冷却期、只收紧止损；优化只改叠加层，不改 release。
- **回滚**：worker 用 `deploy-auto-follow.sh` 的 `PREVIOUS` 指针回退；Web 用内容哈希资源天然向后兼容，恢复旧 `index.html` 即可；参数删除 `params.json` 即回到 v1.11 基线。
