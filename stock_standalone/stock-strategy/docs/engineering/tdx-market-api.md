# Go TDX 行情与题材分钟证据接口

## 数据与运行边界

- Go 后端直接连接 TDX TCP 行情节点，不调用 Python、pytdx、ATS 进程，不增加 Docker 运行环境或依赖。
- 协议字段对照 ATS `tdx_realtime_fetcher.py` 当前使用的 pytdx 1.72 解析器；固定历史响应做逐字段数值对照。项目参考：https://github.com/rainx/pytdx 。没有把 Python 包复制进运行镜像。
- 当前范围为沪深 A 股证券 K 线和流通股本；不包含北交所、指数专用协议、逐笔、盘口快照、交易指令，也不宣称完整复制 ATS 全部接口。
- 周期：1/5/15/30/60 分钟、day/week/month。原接口仍支持日线派生 2D/3D。
- TDX 原始价格未作前复权；除权除息跨日收益和长周期信号应结合公司行为数据解读。

## 接口

复用现有 Token 鉴权。

`GET /api/v1/quotes/tdx/bars?symbol=600733.SH&period=1&limit=1280&days=5`

- `limit`：1～8000，默认 1200；每页最多 800 根，排序并按时间去重。
- `days`：可选，1～20；只截取已返回数据的最近 N 个交易日，不保证每个交易日都完整。
- 返回 `data`、`implementation=go-native-tdx`、成交量/金额单位、VWAP 口径及各交易日根数、首尾时间。`full_minute_session_candidate` 仅为覆盖候选标记，不等同完整性或可交易性确认。
- API 成交量统一为股、金额为元。TDX 分钟原始量为股，日/周/月原始量为手，已分别转换。
- 分钟昨收来自同连接读取的日线，不把前一分钟收盘价伪装为昨收。
- 直接 TDX 接口的分钟 VWAP 在裁剪后的请求窗口内连续累计，对齐 ATS 多日分时；原 `/quotes/kline?period=1` 仍仅展示最近交易日、当日累计 VWAP。
- 原行情接口优先 TDX，异常或陈旧时回退原行情源，记录降级原因；直接 TDX 接口失败明确报错或返回显式陈旧缓存，不冒充其他源。

## 外置持久化与配置

- 只有绝对路径的 `MarketDataDBPath` 配置存在时才启用；缓存路径固定派生为其同目录 `tdx-cache.db`，不在源码、工作目录或镜像层创建行情缓存。
- 生产容器：`/data/easy-stock/tdx-cache.db`；宿主机：`/mnt/4TB/dockerf/stockstrategy/data/easy-stock/tdx-cache.db`。
- 结构化保存：证券/周期/时间主键的 bars、拉取时间 snapshots、流通股本 finance。SQLite WAL、单连接写者、事务提交、busy timeout；每序列最多 8000 根，30 天未使用的序列及股本记录自动清理。
- 分钟 TTL 30 秒，日/周/月 TTL 5 分钟，股本缓存 24 小时。TTL 是再次请求时的复用窗口，不是后台全市场采集计划。
- `A_STOCK_TDX_ENABLED=false` 关闭；`A_STOCK_TDX_SERVERS=host:port,host:port` 覆盖默认 ATS 节点，最多 8 个，每次最多尝试 3 个。TCP 直连不使用 HTTP 代理。
- 全局最多 2 个连接、每节点 4 秒、原接口 TDX 阶段最多 8 秒；不可用冷却 1 分钟。用户取消不触发全局冷却。启动、关闭分别管理缓存生命周期。
- 不改动原共享日线数据库，不删除旧缓存，不改实盘或风控。

## 两项“确认限制”的处理

1. 分钟领涨—跟随：按当前页抽样最多 16 只，60 秒刷新；仅比较同题材节点，按时间对齐，禁止跨日/午休/缺分钟补零。至少 3 只有效同题材对照、每只至少 60 组、有效覆盖率至少 60%，目标至少 90 根，且与日线交易日一致时启用 1～5 分钟滞后相关评分。界面显示日期、样本数、覆盖率、滞后；这是观察相关性，不是因果带动力。否则保留日线代理说明。
2. 成交额/换手率：近 5 日有效覆盖达到 80% 才用于相应评分。TDX 提供真实成交额；换手率按当前流通股本估算，仅对不早于财务报告日期的数据补值，`turnover_estimated=true`。未引入历史股本和除权事件，不能当作精确历史换手率；保留置信度折扣和具体说明。

## 验证

- ATS 固定响应逐字段对照；截断报文、压缩分片、握手、缓存、取消、错误证券市场、相对存储路径、分钟量单位测试。
- 多日连续 VWAP、逐日 VWAP、交易日裁剪测试；Go HTTP/SBC 回归通过。
- 分钟滞后样本、陈旧/跨日/不足/平价边界和既有题材评分、图层回归通过。
- 2026-10-10 部署主机独立 Go 只读检查：600733.SH 分钟、5 分钟、日线各 1280 根，末点均 2026-10-09 15:00。分钟末根 943900 股、4464647 元；日线末根 129075100 股、600795648 元，估算日换手率约 2.1353%。本机 TCP 首轮超时，不将其误报为生产不可用。

- 若需要精确历史换手率和除权后收益，接入带有效日期的历史流通股本及公司行为数据；不得直接取消估算提示。
- 若需要全板块而非当前页样本关系，需要另设覆盖完整的采集调度与数据预算，不能把当前抽样推广为全板块结论。
