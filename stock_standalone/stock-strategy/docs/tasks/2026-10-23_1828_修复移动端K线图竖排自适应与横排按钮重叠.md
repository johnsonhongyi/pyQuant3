# 修复移动端K线图竖排自适应与横排按钮重叠闭环

## 任务背景
操盘手使用移动端手机浏览器（iOS / Android）打开 K 线图（连板梯队 KLineModal）时反馈两个关键问题：
1. **竖排（竖屏 portrait）时，窗口没有自适应导致无法正常查看**：弹窗宽度超出手机视口，右侧行情报价卡片列、关闭按钮及走势图右侧价格轴被截断溢出；
2. **横盘（横屏 landscape）后，窗口显示正常但操作区按钮与文字信息出现重叠导致无法正常操作**：弹窗底部的说明文字（Footer）与 KLineExplorer 操作栏的一排周期按钮（`分时`、`3日分时`、`5分`、`日K` 等）在同一物理位置发生恶性重叠。

## 根本原因排查与诊断
1. **竖排撑爆视口根因**：
   - `styles.css` 中 `.kline-chart` 硬编码了 `min-width: 720px`；
   - CSS Grid 容器及其各级子元素默认 `min-width: auto`，被 720px 的 SVG 强制向右撑开；
   - 导致在 360px~430px 的手机竖屏上，整个 `.kline-modal` 宽度被强制撑到 720px+，右半部分内容（最新报价卡片右列、关闭按钮、图表右侧 K 线及 Y 轴刻度）全部溢出到屏幕之外，无法完整查看。
2. **横排重叠根因**：
   - `.kline-modal` 定义为 CSS Grid 布局：`grid-template-rows: auto auto auto auto minmax(0, 1fr) auto;`；
   - Row 1: Header, Row 2: Tabs, Row 3: Quote, Row 4: Summary, Row 5: KLineChart (`minmax(0, 1fr)`), Row 6: Footer；
   - 在手机横屏时，视口可用高度极小（通常仅 300px~360px，扣除移动浏览器顶底栏后不足 300px）；
   - Row 1~4 与 Row 6 的 auto 高度之和已经超出或占满总可用高度，导致 Row 5 的 `minmax(0, 1fr)` 计算高度直接坍塌为 `0`；
   - Row 6（Footer: “鼠标悬浮图表可查看行情细节；数据源：东方财富 / 新浪...”）紧贴 Row 4 绘制，其物理 Y 坐标与 Row 5 顶部的周期操作按钮（`分时`、`3日分时`...）完全重合，造成两层内容叠加冲突，按钮无法点击。

## 核心修复方案
1. **重构 `.kline-modal` 为 Flex 垂直流式布局**：
   - 彻底废除脆弱的 `grid-template-rows: auto auto auto auto minmax(0, 1fr) auto;`；
   - 改用 `display: flex; flex-direction: column;`，各子项自然向下排列，`flex-shrink: 0;`；
   - Footer 永远稳居图表下方自然文档流末尾，根绝 Grid 行高归零导致的交叉重叠。
2. **消除 SVG 移动端 720px 限制，实现 100% 响应式自适应**：
   - 在移动端媒体查询下设置 `.kline-chart { min-width: 0; width: 100%; height: auto; }`；
   - 设置 `.kline-chart-wrap` 为 `min-width: 0; width: 100%; max-width: 100%; overflow-x: hidden;`；
   - 确保 SVG 根据 `viewBox="0 0 960 430"` 自动完美等比例缩放，竖屏全景清晰可见无截断。
3. **移动端竖屏与横屏专门适配优化**：
   - 竖屏（`max-width: 768px` / `620px`）：
     - `.kline-modal` 撑满屏幕宽度（`width: 100vw; max-width: 100vw;`），关闭按钮稳居右上角；
     - `.kline-modal-quote` 设为 4 列 × 2 行紧凑排布，8 项行情完整呈现且高度收敛；
     - `kline-period-controls` 设为单行横向丝滑滑动（`flex-wrap: nowrap; overflow-x: auto;`），操作按钮清爽利落。
   - 横屏（`max-height: 520px`）：
     - 压缩 Header / Tabs / Quote / Summary 纵向间距，Quote 设为 8 列单行，极大释放图表可视空间；
     - 按钮与说明文字层次清晰，滚动平滑顺畅。
4. **验证与回归**：
   - 编写针对性前端测试验证响应式布局类名与 Flex/SVG 自适应属性；
   - 运行前端单元测试确保 100% 通过；
5. **生产环境部署**：
   - 执行 `build-and-deploy.ps1 -AllowLayeredImageBuild`，构建发布至 PVE 192.168.50.60 生产环境；
   - 生产环境发布号：`20261023192841`，健康检查接口 `/api/health` 正常返回 HTTP 200，Web 容器与 API 容器状态 healthy，移动端前端资源已全面同步生效。
