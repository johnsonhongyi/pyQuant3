# AGV 模型目录、性能与用量对齐

- 模型目录：读取当前账户 `agy models`，缓存 5 分钟，失败清空可用目录并退避 30 秒；排除 GPT-OSS 和 Unavailable。Flash 强度后缀保留为真实模型 ID；不再发布静态 Pro/2.5 模型。
- 推理设置：未指定时优先 Flash Low；显式选择保留，不支持的模型或强度明确失败，不静默回退。
- 计时：按 Codex 结果契约回传 queue_wait_ms、engine_ready_ms、thread_ready_ms、turn_started_ms、first_token_ms、bridge_to_completed_ms。CLI init 作为桥准备完成的观测边界，首段等待仍含服务端排队，不代表纯推理。
- 性能：聊天 CLI 使用仓库外隔离临时目录，避免祖先项目规则附带上下文；冻结证据不裁剪。去掉额外 3 秒空闲等待，兼容即时响应服务端的 100ms 最低轮询间隔。完成结果持久化与 outbox 重试，避免回传失败重跑推理。
- 用量：规范真实 CLI usage 字段；旧版字符估算不冒充真实 Token。AGV 面板后台只读聚合本桥保存结果；与 Codex 共用万/百万/亿格式。AGV 不包含其他客户端的独立会话。
- 无窗口：移除管理器 DETACHED_PROCESS 与 CREATE_NO_WINDOW 的冲突组合；管理器、Python worker、CLI 补齐 SW_HIDE。CLI 自身若显式创建可见子窗口，仍需在实际桌面观察。
- Codex 引擎：原有自动发现与空闲验证切换机制保持不变；有效 CODEX_CLI_PATH 会优先固定路径。
