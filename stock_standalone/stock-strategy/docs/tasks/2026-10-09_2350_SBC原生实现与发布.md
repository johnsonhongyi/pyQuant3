# SBC Go 原生实现与生产发布

## 变更内容

- 将 ATS SBC 纯计算逻辑移植至 Go server，新增版本化 `/api/v1/quotes/sbc/v1/analyze`，复用现有鉴权和 KLine 数据结构，不新增运行时依赖。
- 移植主跌通道、反弹子通道、回退通道、KX 支撑、反转线、MA、九转、启动/逃顶、先锋及评分/介入/止损/目标；日线增加近五日振幅活跃度，图表增加黄金分割。
- 网页统一使用 KLineChart，新增独立图层开关和 SBCProvider 自定义接口；请求使用当前显示的同批 K 线，校验版本、标的、周期和全部时间，取消过期请求。
- 接口限制 10–1000 根、2 MiB 请求体和 10 秒计算上下文；拒绝非法 OHLC、时间、重复/尾随 JSON。沿用行情来源、日期和陈旧标记，不触发交易。
- Python 仅保留为开发对照工具；源算法通过 AST 提取并记录 SHA256，Go 算法需人工同步并通过冻结样本验证，不会由同步工具自动生成。
- 部署脚本补充非阻塞 flock 互斥锁，沿用固定 SSH 指纹、资源门槛、隔离健康检查和失败回滚。

## 验证与发布

- 31 组 ATS 冻结对照样本，以及非法输入、取消、并发确定性和无 Python 原生运行测试通过。
- Go SBC/HTTP 定向回归、Linux amd64 CGO_DISABLED 构建通过；前端类型检查、8 项相关测试和生产构建通过；Python 对照测试 4 项通过。
- 按部署手册第 9 节执行 build-and-deploy.ps1，上线版本 20261009233755，入口 http://192.168.50.60:20073。
- API/Web 均 healthy、restart=always；线上经 Web 代理对 20 根合成 K 线调用 SBC，返回 go-native/schema_version=1/20 点，前端新资源确认。
- 外置数据、日志挂载保留；未新增后端 Python 环境，未执行实盘交易、手动回补或数据修复。

## 后续任务

1. 在浏览器对照 ATS 实际标的核验图层开关、缩放、日周月周期切换、快速切股及陈旧行情提示；当前已验证构建和接口，尚未人工验收交互。
2. ATS SBC 算法更新时，运行 tools/sync_sbc.py 更新开发参考和来源清单，再运行 tools/generate_sbc_fixtures.py 更新对照样本，按差异修正 Go 并执行定向测试。
3. 如需额外多日换手缓存或新指标，先扩展兼容字段与对照样本，再接入自定义 Provider；本次未包含多日换手缓存。
