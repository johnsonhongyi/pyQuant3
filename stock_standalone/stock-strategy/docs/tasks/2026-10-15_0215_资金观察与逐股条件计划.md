# 资金观察与逐股条件计划

- 状态：2026-10-15 02:15（香港时间）已在 LXC 102 部署并验收；仍仅独立模拟盘。
- 入口：自动跟单 → 资金轮动 / 计划；强势股跟踪也可直接展开计划。

## 实施

- `follow_research.py` 提供只读研究扫描；执行周期先监控退出及原有入场逻辑，再更新研究。研究每五分钟运行，手动扫描/范围变更可触发刷新；单次请求六秒超时、研究循环四十秒预算，旧计划保留原时间并优先补齐。
- 行业和题材分别请求已有资金接口，最多各二百项；展示返回集合前后各八名、覆盖数量、来源、抓取时间、交易日。以 available_fields 选择净流入或主力净流入，不读缺失字段默认零；分类重叠不累计为全市场资金。
- 仅同交易日、同来源、同字段口径、新抓取且有效的快照计算排名和净流入变化。不能从分类净流入推断 A 板块资金直接转入 B 板块。
- 市场门禁、暂停、非交易时段不再导致研究视图长期空白。候选证据未通过时保留原池；首次无池时从题材领涨成员生成明确标记的参考观察池。执行仍独立重新生成有效候选，不消费参考池作下单指令。
- 个股计划展示日线截止日、当日/多日 VWAP、MA20、量价、条件区间、首个结构阻断及条件状态、随结构变化的应对、参考整手/金额/止盈止损、账户执行约束。实际结构判定复用 `entry_ok`。
- 模拟账户资金按现金和实际持仓题材归属展示，观察池不冻结预算；成交后按实际模拟成本建立退出锚点。持仓未留在候选时也加入研究监控。
- 修复 Python 3.9 对 Go RFC3339Nano 分数秒兼容，保留时区和过期校验。适配本地 `instock-tdx-daily` 股数契约：InStock 写入侧 `core/tdx_hq.py` 将 TDX 手数乘一百，`core/stockfetch.py` 原样导出，Go `marketbars/tdx_daily.go` 原样读取；额外核对成交额/股数均价位于当根高低价范围附近，拒绝混合单位文件。
- 不修改既有风险阈值、账户资金、实盘接口、p22 权重或 Muse 系统任务。不调用逐股付费 LLM 生成交易指令。
