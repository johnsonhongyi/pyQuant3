# 策略总览 — 给本地 Agent 的实施指南

版本: 跟随 strategy.yaml(当前 v1.9,2026-10-04)｜ 真源: `strategy.yaml` ＋ 本目录《P规则实施手册》

---

## 1. 一句话

一套"感知→编码→模拟验证→复盘迭代"的机械交易系统:用户出交易感知,经评估编码成 P 系列规则,
三套独立模拟账本按规则执行攒样本,每周一复盘归因,用户批准才升版本。**模拟盘只认 strategy.yaml 和决策日志。**

## 2. 版本管理铁律(实施前必读)

1. `strategy.yaml` 是唯一真源;每次调参必须升版本(version 字段)+写 changelog(版本/日期/改动/原因)。
2. 升版本只影响之后的交易日,不追溯历史样本。
3. 止损只收紧不放宽;不凭小样本(<20 笔)改规则;用户批准才升版本。
4. 所有决策写 `log_decision`,自动打 `strategy_version` 戳;统一门因子全记录,供 `gate_attribution.py` 归因。

## 4. 统一决策链路(各市场同一套代码链)

`paper_trade.py do_signal()` 执行顺序(数据层按市场分发,逻辑层统一):

```
P11 两日网格做T(已有持仓,不受新开仓门禁限制)
→ P12 资金轮动(卖弱/强者打码)
→ P15 板块龙头换仓双轨(证伪先行→轨1换入→轨2次日跟踪)
→ 门禁:池分≥8 / 早盘结构 / 情绪(两市情绪缺失统一 fail-closed)
→ P8 早盘买入四条件 → P24 大阳跟随单(并行通道) → P18 止盈补回
```

- 美股:同一链路;数据=us_pool(复用 score)/Yahoo5m 早盘/SPY+QQQ+VIX 情绪/Yahoo 日K VWAP 锚点。
- 币圈多头:同一链路;数据=crypto_pool 现场打分/Kraken 小时K/ BTC 情绪/UTC 日K。
  注意 T+0 无锁仓;UTC 00:00–03:00 小时K不足 3 根时 fail-closed 跳过。
- 币圈空头(`--side short`):独立链路,S-P25 空头趋势门→S-P8 小时触发→S-P24 大阴跟随;
  平空优先级:强平守卫 > 硬止损(+1.5%) > 部分止盈(-1.5%平2/3,镜像用户"盈利先卖2/3") >
  全止盈(-3%) > VWAP 收复 > 24h 时间止损。P11 网格对空头无意义,跳过。

## 5. 统一决策门(影子模式)+ 熔断

- `decision_gate`:mode=`shadow`(只记录不干预)。权重(满分100):P8四条件30 / P25趋势20 /
  P26板块15 / 池分15 / P22龙头L2(预留)10 / 情绪10;阈值 60。攒 20–30 笔后周复盘定是否转 enforce。
- 硬 kill:`logs/kill_switch.json`,单日已实现亏损≥3%自动拉起→停 P8/P24/P18 新开仓
  (卖出/网格/轮动照常)+企业微信告警。空头用账本内独立 short_kill(单笔保证金亏≥30%或单日≤-20%停新开空);
  实验仓用独立 in-ledger `exp_kill`,三者互不干扰。

## 6. P30 时间周期结构(只读,不交易)

`cycle_structure.py`(纯函数,point-in-time,只用已收盘小时K):
`detect_legs` 按摆动高低点切分上涨/下跌/反弹段(时长/点数/斜率)→`analyze` 输出
time_ratio/retrace_ratio + 四判定:weak_rebound(弱反弹=情绪消耗)/steady_up/steady_down/regime_switch。
只读展示(crypto_short_watch 预警文案、盘面简报一行)+回测验证,不进信号链。
不及预期时间窗:反向段时长达原段 1.0 倍→强预警;达 2.0 倍→策略空单自动平(镜像单只预警);
平空后该币种 12h 内不再新开空(防 churn)。

## 7. 币圈动态宇宙

每天 00:05 UTC 从 Kraken 全量 Ticker 按 24h 成交额选币:静态 6 币(BTC/ETH/SOL/XRP/DOGE/ADA)+
动态 Top12,上限 18;剔除稳定币/法币/杠杆代币;流动性门 2000 万 USD(低于直接 SKIP);
新币自动回填 180 天日K(seeded 防重复);pair 映射持久化 `crypto_pairs.json`。
