# InStock 策略收益列自适应显示 v1.0.0

## 行为

- 保留日期、代码、名称等固定列。
- 对 `rate_N` 收益列，先根据表格可用宽度计算能容纳的列数；再与当前策略、日期中已观察到的最大非空收益期数取较大值。
- 因此近期数据不足以填满窗口时，补足到窗口可显示的列数；历史期数多于窗口时，全部显示并沿用横向滚动。
- 翻页时累计已发现的最大期数；调整窗口大小时重新计算最小显示列数；切换策略日期时重置数据期数。
- DataTables 请求仅传后端实际使用的列搜索值。复制、CSV、打印仍包含全部列。

## 应用与恢复

`deploy/patch_adaptive_strategy_columns.py` 对现有 `stock_web.html` 做锚点校验，只修改需要的 JavaScript 配置；改写前保存原文件及 SHA-256，并以临时文件原子替换。目标文件与备份位置由调用方传入，不把生产主机路径写入源码。

恢复时将原文件副本还原到原位置即可。此改动无需重建容器镜像。

## 性能与验收范围

少数据日期减少空白收益列的 DOM 渲染；历史数据保留全部实际期数。请求参数省去 DataTables 未被后端使用的列元数据。没有改用 CSV，也没有将全表数据加载到浏览器。

补丁已应用到当前 InStock 页面模板。自动测试及已登录浏览器验收尚未执行，不能据此给出实测耗时或性能提升百分比。
