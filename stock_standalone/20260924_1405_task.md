# 2026-09-24 14:05 SBC Alt+鼠标滚轮同步缩放底层失效彻底修复任务清单

## 任务背景与用户反馈
操盘手实机测试反馈：“测试alt+鼠标滚轮缩放没有生效,其他测试正常”。
经深度审计排查，键盘 `Alt + Up` / `Alt + Down` / `Alt + 周期快捷键` 均能正常识别并同步同组窗口，唯独 **按住 Alt 滚动鼠标滚轮** 无法触发同组窗口同步缩放，退化成了当前单窗缩放。

## 根本原因深度分析
1. **Windows 消息规范物理限制**：
   - Win32 原生 `WM_MOUSEWHEEL` 的 `wParam` 仅定义了 `MK_CONTROL`、`MK_SHIFT`、`MK_LBUTTON` 等标志，**Win32 消息本身没有任何 `MK_ALT` 修饰符**。
   - Qt 在 Windows 平台下将 `WM_MOUSEWHEEL` 打包派发为 `QWheelEvent` 时，由于 Alt 键触发时 Windows 系统默认会激活系统菜单状态（System Menu Mode / WM_SYSKEYDOWN），Qt 的 `event.modifiers()` 与 `QApplication.keyboardModifiers()` 在滚轮事件到达的瞬间返回的往往为 `NoModifier`（0）。
2. **逻辑短路退化为单窗缩放**：
   - 原代码 `is_alt = bool(event.modifiers() & Qt.KeyboardModifier.AltModifier) or bool(QApplication.keyboardModifiers() & Qt.KeyboardModifier.AltModifier)` 误判为 `False`。
   - `eventFilter` 与 `canvas.wheelEvent` 直接执行单窗 `zoom_in()` / `zoom_out()` 并拦截消费，导致同组其他 SBC 窗口完全没有收到同步广播。
3. **部分鼠标驱动水平滚轮映射**：
   - 某些鼠标驱动在用户按住组合键时可能将滚动转换为水平 delta (`angleDelta().x`)，原代码若仅检查 `y` 会导致 `delta == 0` 被误判为未滚动。

## 核心改造与工程落地
1. **三层严密穿透判定引擎 (`is_alt_modifier_active`)**：
   - 第 1 层：检查当前事件 `event.modifiers()`（若携带则直接通过，0 纳秒）；
   - 第 2 层：检查 Qt 应用程序级 `QApplication.keyboardModifiers()`；
   - 第 3 层：🛡️ **Windows 原生物理穿透**：通过轻量内置 `ctypes` 调用 Windows `user32.dll` 的 `GetAsyncKeyState(0x12) & 0x8000` (VK_MENU)、`0xA4` (VK_LMENU 左Alt)、`0xA5` (VK_RMENU 右Alt) 及 `GetKeyState`，直接读取硬件按键物理电平状态，彻底消除 Windows 滚轮丢失 AltModifier 的物理缺陷！
2. **滚轮全向 delta 自适应回退**：
   - 优先读取 `angleDelta().y`，若为 0 依次自动回退 `angleDelta().x`、`pixelDelta().y`、`pixelDelta().x`，彻底兼容全品牌鼠标驱动与触控板。
3. **交互全链路对齐与 DRY 治理**：
   - `SBCChartCanvas.wheelEvent`：接入 `is_alt_modifier_active(event)` 与水平 delta 兜底；
   - `SBCIntradayChartDialog.eventFilter`：Wheel 事件与 Key_Up/Key_Down 接入 `is_alt_modifier_active(event)`；
   - `SBCIntradayChartDialog.switch_period_mode` & `switch_period_by_index`：接入 `is_alt_modifier_active()`；
   - `SBCIntradayChartDialog.closeEvent`：复用 `is_alt_modifier_active()`，消除重复代码。
4. **全量自动化测试与回归**：
   - 在 `tests/test_sbc_zoom_right_anchor.py` 中新增 `test_is_alt_modifier_active_three_tiers` 与 `test_wheel_event_with_alt_and_win32_physical_sync`；
   - 模拟 Windows 现场（Mock 丢弃 Qt 修饰符但触发底层硬件 GetAsyncKeyState 0x8000），确证滚轮缩放 100% 触发同组所有 SBC 窗口毫秒级同步，右侧最新数据锚定不丢。
