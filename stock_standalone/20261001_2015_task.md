## 3. 代码重构与核心改进

在 `tools/codex_token_stats.py` 中实施了严格遵守实事求是原则的重构：

### 3.1 彻底清除硬编码，动态加载真实配置
- 新增 `load_antigravity_client_model()`：从 `~/.gemini/antigravity-cli/settings.json` 动态读取用户当前配置（如 `Gemini 3.8 Flash (High)`），未配置则显示 `Auto/默认`，绝不凭空臆造标签；
- 数据中存在级别（如 `gemini-3.1-pro-low` -> `Gemini 3.1 Pro (Low)`，`claude-opus-4-6-thinking` -> `Claude Opus 4.6 (Thinking)`）时如实展示，没有级别标记的模型保持原生名称，**绝不硬凑任何“(中模型)”**。

### 3.2 支持会话级多模型时序切换完整链条展现与 `[SWITCH]` 状态
- 引入 `models_timeline` 追踪模型调用时序流转；
- 单模型会话：根据客户端请求与实际路由主干判定 `[MATCH]` 或 `[REDIRECT]`；
- 多模型切换会话：完整输出时序流转链条（例如 `Claude Sonnet 4.6 ➔ Gemini 3.8 Flash`），状态列精准标明 **`[SWITCH]`**，真实还原用户切换过程。

### 3.3 深度解耦支持独立端、IDE端与全量合并审计
- `app_type="standalone"`（`--agy` / `--antigravity`）：专门审计桌面独立端；
- `app_type="ide"`（`--ide` / `--antigravity-ide`）：专门审计 IDE 插件端；
- `app_type="merged"`（`--gemini`）：合并扫描两端全部记录，并在会话列自动打上 `[APP]` 与 `[IDE]` 标签；
- `--all`：依次分析 OpenAI Codex、Antigravity 桌面独立端与 Antigravity IDE 端，并在末尾输出三方横向综合对比。

### 3.4 命令行优先级与跨平台兼容性修复
- 重构 `chosen_source` 判定顺序，解决 `--all` 因默认参数优先级被覆盖的问题；
- 优化控制台输出符号为安全跨平台字符，杜绝 Windows GBK 控制台下的编码崩溃。
