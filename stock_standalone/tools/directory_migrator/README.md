# Windows Directory Migrator

独立的 Tkinter 工具，用于把目录复制到另一块 NTFS 卷，并用 Windows mklink /J 让原路径继续可用。

## 运行

在此目录运行：

    python app.py

选择源目录和目标父目录后，工具会以源目录名生成目标完整路径。目标目录必须尚不存在。预检查和迁移前会用 Windows Restart Manager 检测正在打开源目录文件的程序，并在切换原路径前再次检查；发现占用会显示程序名和 PID 并停止迁移，不会自动结束进程。

## 迁移安全步骤

1. 检查源目录、目标路径重叠、NTFS 文件系统、目标空间、符号链接和目录联接创建权限。
2. 流式检测正在使用源目录普通文件的程序，每登记 256 个文件就查询一次，发现占用后立即返回；界面显示已登记数量和当前路径。取消会在当前目录项或 Windows 系统调用返回后响应；占用检测和预检查均为只读任务，可直接关闭窗口。文件符号链接不跟随扫描，链接指向源目录内的目标文件会通过该目标文件检测。
3. 不跟随目录内的符号链接或联接；记录链接类型、链接目标、目录结构、文件长度、SHA-256、修改时间、常见属性和目录内硬链接组。
4. 复制到目标卷的临时目录。符号链接按目标语义重建；目录联接会在临时副本安装到最终位置后重新指向正确目标。
5. 重新扫描源目录，确认复制期间源数据没有变化；逐项比较临时副本和源目录。
6. 将临时目录安装为最终目标，再次扫描占用进程。没有占用时，把源目录原子重命名为回退副本，再创建源路径的 mklink /J。
7. 再次比较回退副本和目标；只有所有项目一致且原路径能解析到目标时，才逐项删除回退副本。
8. 任一切换或最终核验失败时，移除新联接并恢复源目录。未核验通过的 E 盘副本会保留供检查。

占用检测基于 Restart Manager 登记的文件资源，能识别打开这些文件的进程/服务；仅持有目录句柄的程序、检查后新打开文件的短暂竞态不一定能被提前列出。检测 API 出错时工具会报错并停止，不会将错误当成“未占用”。

工具仅支持 NTFS 目录迁移。遇到未知重解析点、外部硬链接、FIFO 等特殊文件、NTFS 备用数据流、压缩/加密/脱机/稀疏文件时会中止，不会把它们当普通文件静默复制。源目录的 NTFS 所有者和 ACL 不复制；目标内容继承目标父目录权限，界面会在确认步骤中提示。

## 测试

    python -m unittest discover -s . -p "test_*.py" -v

## 打包

安装 PyInstaller 后运行 build.bat。脚本优先使用 `C:\JohnsonProgram\SetDisplayMode\init\upx\upx.exe`；该程序不存在时会回退为未压缩构建。脚本仅生成此工具目录下的 dist 和 build，主程序目录不会被清理。
