# ATS 优化实施与验证记录（2026-09-26）

## 本轮落地

- 候选池历史行查询改为单轮代码规范化、候选行物化；历史 cohort 按冻结的 `followup_trading_days` 推进，到期未走强结算 `MISSED`。
- 候选池评估保留观测检查点与待确认事件；仅无证据、无状态、无事件和计数变化时跳过写盘。IPC 增加有界收包、完整帧/超时校验、版本连续性和 ACK；旧版无版本全量帧会清除版本元数据。
- 候选池 UI 读取改为后台加载，并限制为一个在途请求加一个最新待处理请求；配置写入有界合并，退出时集中入队后执行一次 1000ms Flush。
- 表格定时更新沿用 Item 原位复用；显式列宽保存保留同步兼容入口，刷新和关闭路径走异步队列。仅修复所有列均为 100 的旧占位布局。

## 验证

- ATS 定向回归：31 项通过；`compileall` 与 `git diff --check` 通过。
- 有界配置队列冒烟：容量拒绝、相同键合并、Flush 通过；模拟两个表格退出时集中入队后单次 Flush，通过。IPC 旧版全量切换后拒绝缺基线版本化差分并请求全量，通过。
- 全量 pytest 已执行，剩余 5 项失败：周末实时行情用例要求返回 2026-09-26 当日数据（数据只到 09-23）；TDX 缓存用例手工注入缓存但未初始化 `_last_rolled_date`，首次读取触发设计中的换日滚动；影子 dry-run 未传候选代码却断言完成两轮；工作区外纸面账户迁移用例因 fixture 对象缺 `ledger_baseline` 无法写快照。表头异步契约相关失败已修复并通过定向回归。
