# 2026-09-18 20:20 任务记录：集中交易指挥室角色映射中文、全表数值排序支持与极窄模式深色分割线对齐

## 1. 核心需求与视觉痛点
- **操盘手现场明确指示 (P0)**：
  > “1.角色映射对应的中文,2.列不支持排序,3,如图2分隔线等跟ats和检测工具一致的全面使用极窄模式的,”
- **痛点诊断**：
  1. **英文枚举暴露**：天梯表中角色直接显示为 `CLIMAX_EXIT`、`LEADER`、`VANGUARD`、`PANIC_DEFENSE` 等英文代码，不够直观，无法瞬间识别全局战术分工；
  2. **缺少排序能力**：表头无法点击排序，且未采用量化金融标准 `NumericTableWidgetItem`，即便排序也会出现字符串乱序（例如 99 排在 100 后面）；
  3. **非极窄模式与边框缺失**：表头没有右侧垂直分割线，表格无深色网格线，且滚动条回退为原生 Windows 粗大白色条，出现横向滚动条撕裂。

## 2. 架构设计与工程落地 (KISS / SOLID / DRY)

### 1. 角色与持仓状态 100% 中文映射
- 定义集中交易全局战术角色对应标准中文映射字典 `ROLE_CN_MAP`：
  - `LEADER` -> `🥇 领头羊` (亮金 `#ffaa00`)
  - `VANGUARD` -> `🥈 梯队前锋` (亮青 `#00e5ff`)
  - `FOLLOWER` -> `🥉 后排跟风` (淡灰 `#8f93a8`)
  - `CLIMAX_EXIT` -> `🚨 高潮平仓` (鲜红 `#ff3333`)
  - `PANIC_DEFENSE` -> `🛡️ 全局避险` (橙红 `#ff7733`)
  - `STOP_LOSS` -> `⛔ 买错立斩` (玫红 `#ff4444`)
  - `CLIMAX_DEFENSE` -> `🌋 高潮避险` (金橙 `#ffaa33`)
- 实盘持仓状态映射字典 `POS_STATUS_CN_MAP`：
  - `HOLDING` -> `🟢 持仓中`
  - `CLOSED` -> `⚪ 已平仓`
  - `STOP_LOSS` -> `⛔ 止损清仓`
  - `PROFIT_EXIT` -> `💰 止盈锁定`

### 2. 全表引入 `NumericTableWidgetItem` 深度支持点击表头数值排序
- 在 `IPOCommandRoomTableWidget` 中开启 `setSortingEnabled(True)` 与 `horizontalHeader().setSortIndicatorShown(True)`；
- 重写 `sortItems` 方法，实现表头排序指示器箭头与排序行为严格同步；
- 天梯表、持仓表、指令表中的数值列（排名、代码、现价、动能分、股数、成本价、浮盈%、建议仓位）全部采用 `NumericTableWidgetItem` 封装，支持高精度浮点数、整数排序，自动剥离千分位与正负号；
- 数据刷新时执行 `setSortingEnabled(False)` -> 填充 -> `setSortingEnabled(True)` -> `sortItems(sort_col, sort_order)`，保证用户当前自定义排序列与顺序平滑保持，杜绝动态刷新跳变。

### 3. 全面换装极窄模式 (Narrow Mode) 与暗黑深色分割线
- **表头垂直右边框与下边框分隔线**：
  - `border: none; border-right: 1px solid #232536; border-bottom: 1px solid #232536; padding: 2px 4px;`，各列界限清晰分明；
- **表格深色网格线与紧凑行高**：
  - `setShowGrid(True)`，`gridline-color: #1d1f2e;`，`alternate-background-color: #131522;`；
  - `verticalHeader().setDefaultSectionSize(24)`，信息密度高，与检测工具和竞价赛马监控 100% 视觉对齐；
- **极窄模式暗黑滚动条**：
  - `QScrollBar:vertical` 宽度 8px，滑块 `#2c2e3e;` 圆角 4px；
  - `QScrollBar:horizontal` 高度 8px；
  - `QTableCornerButton::section` 深色无缝填充，彻底消灭原生 Windows 白色大粗条与边角白块；
- **精调极窄默认列宽**：
  - 赛马天梯表前 7 列总宽仅 449px，在左侧分屏下完美舒展，彻底消除底部横向滚动条。
