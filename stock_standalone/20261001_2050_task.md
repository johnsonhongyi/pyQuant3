# 2026-10-01 20:50 修复龙头突击跟单榜冷启动无数据显示任务清单

## 现象与问题
- **现象**：冷启动时，每日涨停分析与强势股天梯（`DailyLimitUpDialog`）能正常展示 124 只标的，但 Top 3 强势板块龙头突击跟单榜（Hot Alpha Leaderboard / `ats/ui/hot_sector_leaderboard.py`）没有数据。
- **具体表现**：
  1. 顶部 No.1, No.2, No.3 按钮均显示为 `--`；
  2. 底部统计：“标的: 0 | 👑龙头: 0 | 🚀先锋: 0 | 💎回踩: 0 | 👑 板块领涨: --”；
  3. 右下角显示：“💤 非交易休眠 (20:49:11)”；
  4. 表格完全空白。

## 根本原因确诊 (Root Causes)
1. **非交易时段冷启动首刷被一刀切拦截**：
   - `_on_ui_timer_tick` 第 1955 行原代码为 `if not is_trading and not force: return`；
   - 尽管上方英文注释明确规划了 `# Allow one off-hours cache initialization`，但实际逻辑缺失了 `and self._has_init_fetched` 守卫；
   - 导致非交易时段打开窗口时，定时器首拍回调因 `force=False` 被直接 return，冷启动连**一次**数据拉取与渲染都无法执行，直接冻结在初始空状态；
2. **缺乏即时异步首刷机制 (对比天梯差距)**：
   - 天梯 `DailyLimitUpDialog` 在 `showEvent` 与 `__init__` 中具备 `ensure_rendered()` 机制，窗口打开瞬间即触发底板装载；而龙头突击榜在 `showEvent` 中未触发刷新，仅被动依赖定时器；
3. **冷启动阶段热力图未就绪导致板块与成分股缺失**：
   - 冷启动时 `main_app.heatmap_widget` 的 `sectors` 尚未完成首刷，`get_top_sectors` 返回空列表；且未向底层 `SectorDataAggregator` 请求权威竞价快照兜底，导致 `top_sectors` 无法解析出成分股；
4. **`HotSectorEngine.build_target_universe` 成分股为空时无兜底**：
   - 当 `sector_to_codes` 字典为空时，直接返回空代码池，导致计算结果为 `[]`；
5. **底部领涨标签遗漏赋值**：
   - `_render_table_data` 遍历生成了 `leader_strs`，却漏掉了调用 `self.lbl_sector_leaders.setText(...)`，导致领涨文本永远停留在初始 `--`。

## 实施改进措施 (KISS / SOLID / DRY)
- [x] **1. 修复非交易时段冷启动首刷守卫**：
  - 将休眠拦截条件重构为 `if not is_trading and not force and self._has_init_fetched: return`，放行冷启动首刷加载底板，首刷完成后自动进入 60s 节流休眠；
- [x] **2. 补齐即时异步首刷与 showEvent 守卫 (对齐天梯)**：
  - 新增 `ensure_rendered()` 方法；在 `__init__` 末尾通过 `QTimer.singleShot(0, self.ensure_rendered)` 异步秒级触发；在 `showEvent` 中补发 `self.ensure_rendered()`，保证初次展示必定拥有底板数据；
- [x] **3. 增强板块与成分股冷启动底板解析**：
  - 若冷启动时 `heatmap_widget.sectors` 不足 3 个，主动调用 `hw.load_live_sectors(force=True)`；
  - 若仍为空或无主窗口，自动从 `SectorDataAggregator._load_bidding_sector_data()` 权威快照中瞬间提取 Top 3 强势板块；
  - 宽表数据 `current_df` 接入 `SectorDataAggregator.resolve_active_strategy_df` 递归感知兜底；
- [x] **4. 补全成分股与股票名称自适应解析**：
  - 在 `HotSectorEngine.build_target_universe` 中，当板块成分股为空时，自动调用 `SectorDataAggregator.resolve_sector_member_codes(sec)` 补充成分股代码与股票名称映射；
- [x] **5. 修复底部领涨标签更新与空结果状态同步**：
  - 补齐 `self.lbl_sector_leaders.setText(...)`；`_render_table_data` 在空结果时显式重置并正确标注时间；休市时自动关闭语音报警，避免打扰；
- [x] **6. 自动化测试与全量回归矩阵 100% 绿灯**：
  - 新增测试用例 19 `test_hot_sector_leaderboard_cold_start_off_hours` 覆盖休市冷启动底板装载、Top 3 按钮更新、表格行数校验与节流守卫；
  - 全量 54 项回归测试 100% PASS（耗时 23.93s）。
