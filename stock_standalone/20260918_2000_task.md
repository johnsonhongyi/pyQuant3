## 1. 核心需求与交互痛点
- **操盘手现场明确指示 (P0)**：
  > “对齐检测工具的点击联动,上下联动,右键功能,或者不作为子窗口,点击直接联动到检测工具中的code直接操作”
- **痛点诊断**：
  1. 原指挥室为模态弹窗（`exec()`），阻塞主窗口，无法边看指挥室边在主窗口操作；
  2. 指挥室表格缺少点击联动与上下方向键移动联动，无法像系统其他 Tab 一样随切随看；
  3. 缺少右键快捷菜单（SBC走势、定位主表、单只决议执行、复制、联动通达信）；
  4. 细节瑕疵：启动时点在分时跨度大时出现 `09:179` 越界格式；且原 `leader_is_crashing` 判定过宽导致后排误报为 PANIC_DEFENSE。

## 2. 架构设计与工程落地 (KISS / SOLID / DRY)
1. **非模态独立伴侣窗口 (`IPOSubnewDetectorDialog._on_open_command_room`)**：
   - 彻底废弃阻塞式 `dlg.exec()`，改为非模态伴随窗口（`show()`, `raise_()`, `activateWindow()`）；
   - 操盘手可自由将指挥室拖至副屏或并排摆放，主窗口操作丝毫不受干扰。
2. **点击与上下联动：直接联动检测工具中的 code 进行直接操作**：
   - 在主检测工具中新增公开标准接口 `select_and_focus_code(code, trigger_linkage=True)`：
     - 自动寻找对应的代码行（解开隐藏、滚动至视野中央、高亮选中该行）；
     - 同步驱动通达信/外部行情联动；
   - 自定义 `IPOCommandRoomTableWidget` 拦截 `Up / Down / PageUp / PageDown`，切行时防抖 20ms 平滑驱动主看板聚焦对应 code；
   - 鼠标单击行时立即联动主检测工具对应行。
3. **快捷键与 SBC 走势图联动**：
   - 双击行 / 按 `Space`（空格键）：秒级调出该标的 10d SBC VWAP 走势图；
   - 按 `F` 键 或 `Return / Enter`：强制联动通达信看盘。
4. **全套右键功能菜单 (`_show_context_menu`)**：
   - 📈 调出 SBC 10d 走势图 (空格 / 双击)；
   - 🔍 在检测工具中高亮并聚焦 (单击)；
   - 📡 联动通达信看盘 (F / 回车)；
   - ⚡ 针对当前标的立即执行集中决议 (单只精准执行)；
   - ⛔ 针对当前持仓立即一键平仓；
   - 📋 复制股票代码与决议详情。
5. **严密修复与体验打磨**：
   - 标准 A 股分时时间换算（`09:30~11:30` 与 `13:00~15:00`），彻底消灭 `09:179` 越界；
   - 优化 `leader_is_crashing` 判定优先级，确保爆款领头羊和梯队前锋正常评定，仅对后排跟风标的进行退潮避险。
