# 新股情绪感知与 T+1 交易决策系统建设计划书

- 版本：v0.2.0
- 日期：2026-09-26
- 状态：迭代落地版 / LRRM增强 / 可持续迭代源稿

> 核心定义：不是解释已经发生的行情，而是利用已经发生的市场行为，感知下一阶段资金行为正在发生变化，并据此决定交易资格与操作节点。

## 一、项目定位与目标

本项目不是建立一个“新股涨跌打分器”，而是建设一个具有先验感知能力的新股/次新股交易决策层。系统必须先识别整个新股市场所处的情绪阶段，再判断单只新股是否具备成为资金载体的条件，最后通过 T+1 可兑现性与 VWAP 结构决定是否允许进入交易节点。

核心目标：
1. 在上市前或当前交易日尚未结束时，利用当时可获得的数据形成先验判断；
2. 明确区分“市场情绪强”“个股爆炒”“可买入”“可跨 T+1”四件不同的事；
3. 避免看到上涨后再追认强势的事后解释；
4. 将情绪感知结果接入 TradingDecisionEngine，形成可执行的 ENTRY / WATCH / BLOCK；
5. 支持历史截断回放，严格验证预判能力，禁止未来数据泄漏。

## 二、设计原则

1. 市场状态优先：先判断 IPO Regime，再判断单股。
2. 先验优先：任何回测只能使用当时已经存在的数据。
3. T+1 优先：当日浮盈如果次日不可安全兑现，不得被当作有效交易优势。
4. 情绪与执行分离：情绪感知负责“该不该关注”，VWAP/价格结构负责“何时允许操作”。
5. 多状态而非单分数：至少保留 Market Regime、Pre-Heat、Live Heat、T1 Carry、VWAP Structure、Risk 六个独立维度。
6. 可解释：每一次状态变化必须能回溯到具体因子，不允许只输出黑盒分数。
7. 可迭代：规则、权重、阈值、样本和验收结果全部版本化，不在代码里散落硬编码。

## 三、总体架构

完整决策链：

IPO Market Regime
→ IPO Pre-Heat
→ IPO Live Emotion
→ T+1 Carry / Survival
→ Multi-Day VWAP Structure
→ TradingDecisionEngine
→ ENTRY / WATCH / BLOCK / EXIT

其中 IPO Market Regime 是上游环境门禁；Pre-Heat 是上市前先验；Live Emotion 是上市后的实时资金强度；T+1 Carry 判断今天建立仓位后下一交易日是否仍可能存在可兑现空间；VWAP Structure 负责实际操作节点确认。

## 四、IPO Market Regime：新股市场情绪阶段

系统按最近 5～10 只新股以及最近 10～20 个交易日的横截面行为，识别五类状态：

DISTRIBUTION：首日兑现型。首日高溢价后，D+1 / D+2 普遍负反馈。
REPAIR：杀跌减弱，次日大幅亏损率下降，开始出现修复。
CONTINUATION：首日上涨后，D+1 / D+2 仍有明显赚钱效应，接力意愿增强。
MANIA：首日极端溢价、多只新股连续爆炒，情绪高度亢奋。
EXHAUSTION：绝对涨幅仍高，但次日/三日亏损迅速恶化，出现高热度与低可兑现性的背离。

状态机允许向前或回退，例如：
DISTRIBUTION → REPAIR → CONTINUATION → MANIA → EXHAUSTION → DISTRIBUTION。
任何状态切换必须记录触发因子和置信度。

## 五、Regime 核心指标

建议至少维护以下指标：
- D1_positive_rate / D2_positive_rate / D3_positive_rate：最近 N 只新股次日、第三日、第四日正收益比例；
- first_day_peak_ratio：上市首日即未来 3～5 日最高价的比例；
- new_high_after_listing_ratio：D+1～D+3 继续创新高比例；
- D1_max_drawdown / D2_max_drawdown：次日和后续最大回撤；
- limit_down_rate：次日大跌或跌停比例；
- ipo_relative_strength：新股组合相对全市场/主要指数的超额收益；
- turnover_median：首日换手中位数；
- close_location：收盘在当日振幅区间中的位置；
- ipo_listing_frequency：近期新股上市间隔与稀缺度；
- market_amount_percentile：全市场成交额分位；
- advance_decline_ratio：市场涨跌家数比；
- hot_sector_concentration：资金是否从常规主线向高弹性新股集中。

## 六、IPO Pre-Heat：上市前爆发潜力

Pre-Heat 只允许使用上市前已公开信息，输出 0～100 的先验潜力评分与解释标签。

建议输入：
- issue_price：发行价绝对水平；
- float_shares / float_market_cap：首发流通股本与流通市值；
- valuation_position：PE/PS/PB 相对可比公司的位置；
- online/offline_subscription_multiple：网上、网下申购热度；
- winning_rate / allocation_rate：中签/获配稀缺度；
- scarcity_score：行业稀缺性、国产替代、头部客户、细分龙头等；
- theme_match：是否处于当期强主线，如半导体、AI、机器人、创新药、高端制造；
- ipo_regime_match：当前市场状态是否适合高弹性新股。

Pre-Heat 只能回答“值得重点关注的概率有多高”，不能直接触发买入。

## 七、IPO Live Heat：上市实时情绪

实时观察：
- 集合竞价相对发行价溢价；
- 竞价金额与匹配量；
- 开盘后成交速度、换手速度；
- 临停次数；
- 首日价格发现速度；
- 价格相对 Day VWAP 的偏离；
- 高点回撤；
- 分时承接强度；
- 尾盘是否仍保持强势。

Live Heat 必须采用非线性解释。首日涨幅极端并不代表“越高越好”；当溢价、换手、VWAP 偏离进入极端区间时，应同步提高 Overheat / Exhaustion 风险。

## 八、T+1 Carry / Survival：可兑现性核心门禁

T1 Carry Score 回答的问题不是“明天一定涨吗”，而是：今天买入后，下一交易日是否仍有合理的可兑现空间。

正向因素：
- IPO_Regime = REPAIR / CONTINUATION；
- 最近新股 D+1 / D+2 胜率上升；
- 最近没有连续次日大跌/跌停；
- 个股尾盘收在高位；
- Day VWAP 向上且价格稳定在其上；
- Listing Anchored VWAP / 2D / 3D VWAP 同向上行；
- 尾盘回踩缩量、再上攻放量；
- 高低点持续抬高。

负向因素：
- 首日溢价极端；
- 首日换手接近完全换手；
- 尾盘放量滞涨；
- 最近同类型新股 D+1 负反馈明显；
- IPO_Regime = MANIA 后段或 EXHAUSTION；
- 价格过度远离 VWAP；
- 收盘明显低于全天高点；
- 尾盘跌破 VWAP；
- 盘中极端冲高回落。

建议输出：
t1_carry_score = 0～100
t1_carry_state = ALLOW / CAUTION / BLOCK
并保留每个贡献因子的解释。

## 九、多日 VWAP 结构与实际操作节点

现有新股次新股交易中心保留并扩展：
- Daily VWAP；
- Listing Anchored VWAP；
- 2-Day VWAP；
- 3-Day VWAP；
- 5-Day VWAP；
- VWAP slope；
- Price/VWAP distance；
- VWAP compression；
- VWAP reclaim；
- VWAP support count。

VWAP 不是单独的买点，而是执行层的结构确认。

操作节点状态机建议：
OBSERVE：仅观察，Pre-Heat 或 Regime 尚未满足；
ARMED：市场环境和个股先验均满足，等待价格结构；
ENTRY_READY：T1 Carry 允许且 VWAP 结构确认；
ENTERED：已经建立仓位；
HOLD_T1：进入隔夜持仓管理；
EXIT_READY：次日出现兑现条件；
BLOCKED：任一上游门禁失败，禁止新开仓。

任何状态转换必须有明确条件，并记录 transition_reason。

## 十、TradingDecisionEngine 门禁

最终 ENTRY 必须通过三层门禁：

Gate 1：IPO_Regime 允许；
Gate 2：T1_Carry 允许；
Gate 3：VWAP/价格结构允许。

示意：
if ipo_regime in [REPAIR, CONTINUATION]    and t1_carry_score >= threshold    and vwap_structure == STRONG:
    ENTRY_ALLOWED
else:
    WATCH_OR_BLOCK

如果 Live Heat 极高但 Regime 已进入 EXHAUSTION，则默认 BLOCK，而不是因“涨得快”而提高买入评分。

## 十二、历史截断回放与无未来函数验证

必须建立 Historical Cut-Off 回放器。

验证任意新股时：
1. 指定 cut_off_time；
2. 数据层只加载 cut-off 之前已经存在的数据；
3. 先运行 Regime / Pre-Heat；
4. 再逐分钟/逐日推进；
5. 每一步记录状态变化；
6. 之后才打开真实未来走势比对。

禁止：
- 使用未来最高价定义当时标签后再参与同一时点决策；
- 使用未来 D+1/D+2 结果反向调当前评分；
- 根据已知涨幅人工修改阈值。

首批验证样本：
华大海天、百迈科、腾信精密、信诺维、沈鼓集团、世纪数码、中塑股份、凯达重工。

## 十三、验收指标

第一版不以“总收益率”作为唯一验收。

必须统计：
- regime_transition_accuracy：情绪阶段切换识别质量；
- high_carry_vs_low_carry_spread：高/低 T1 Carry 组未来一天收益分布差异；
- bad_t1_filter_rate：高风险隔夜交易过滤率；
- continuation_capture_rate：高延续样本覆盖率；
- false_entry_rate：被允许 ENTRY 后的快速失败率；
- future_leakage_count：未来数据泄漏次数，必须为 0；
- explanation_coverage：每次评分可解释率，目标 100%。

只有高 T1 Carry 组与低 T1 Carry 组出现稳定、可重复的统计分离，才证明情绪感知具备真实预测信息。

## 十六、下一轮讨论重点

本基础版完成后，不立即进入“加更多分数”。下一轮应集中讨论三个真正决定操作节点的问题：

1. Regime 转换的最小充分条件：
   什么变化足以把 DISTRIBUTION 切换成 REPAIR / CONTINUATION？
2. T1 Carry 的失效条件：
   哪些极端结构必须一票否决，即使单股 VWAP 仍然漂亮？
3. 操作节点状态机：
   ARMED 到 ENTRY_READY 到 ENTERED 的每一步，分别由哪些可观测条件触发？

目标是把“感知能力”落实为交易资格和操作节点，而不是停留在分数展示。


## 十七、v0.2.0 增量：LRRM 决策链与流动性 Regime

### 17.1 LRRM 主链

v0.2.0 将断线前讨论的 LRRM 作为显式上游层接入现有 IPO 决策体系。LRRM 不替代 IPO Regime / T1 Carry / VWAP，而是负责识别“市场是否具备让新股情绪扩散、接力和兑现的流动性条件”。

完整链路升级为：

Liquidity / Risk Regime
→ IPO Market Regime
→ IPO Pre-Heat
→ IPO Live Heat
→ T+1 Carry / Survival
→ Multi-Day VWAP Structure
→ TradingDecisionEngine
→ ENTRY / WATCH / BLOCK / EXIT

LRRM 至少输出：
- liquidity_regime：LOOSE / NORMAL / TIGHT / SHOCK；
- risk_appetite：RISK_ON / NEUTRAL / RISK_OFF；
- concentration_state：BROAD / THEME_CONCENTRATED / IPO_CONCENTRATED；
- liquidity_confidence：0～100；
- transition_reason：本次状态切换的可解释原因。

LRRM 只能做环境门禁与阈值调节，不得直接触发买入。

### 17.2 流动性 Regime 输入

建议纳入：
- 全市场成交额及其 20D / 60D 分位；
- 融资余额与高频变化；
- 涨跌家数、炸板率、跌停率；
- 高波动品种成交占比；
- 主要指数相对强弱；
- 新股/次新股成交额占全市场比例；
- 热门主题集中度；
- IPO 上市频率与供给节奏。

### 17.3 与 IPO Regime 的联动

LRRM = LOOSE / RISK_ON 时：
- REPAIR → CONTINUATION 的转换阈值可适当降低；
- T1 Carry 对高波动但结构健康的样本容忍度可提高。

LRRM = TIGHT / RISK_OFF 时：
- IPO Regime 即使短时显示 CONTINUATION，也不得自动放宽 ENTRY；
- T1 Carry 阈值上调；
- 对高换手、高溢价、高 VWAP 偏离样本提高 BLOCK 权重。

任何 LRRM 阈值调节必须记录，并允许历史回放复现。

## 十八、非线性临界点与过热识别

v0.2.0 明确：首日涨幅、换手率、成交速度、VWAP 偏离不得线性加分。

建议将以下维度改为分段/饱和/反转函数：
- first_day_return；
- turnover_rate；
- price_vwap_distance；
- opening_premium；
- intraday_velocity；
- close_location。

原则：
1. 从弱到强阶段可以加分；
2. 进入极端区间后边际贡献下降；
3. 超过过热门槛后，Live Heat 继续升高，但 T1 Carry 必须下降；
4. “热度高”与“可持有”必须允许出现背离。

建议保留：
- heat_score；
- overheat_score；
- exhaustion_risk；
- nonlinear_zone = NORMAL / HOT / EXTREME。

## 十九、首日关键锚点与 T+1 生存规则

每只新股必须记录并冻结以下首日锚点：
- listing_open；
- listing_high；
- listing_low；
- listing_close；
- listing_vwap；
- listing_anchored_vwap；
- first_30m_vwap；
- close_location；
- first_day_turnover。

次日及后续重点判断：
- 是否守住首日开盘价；
- 是否守住首日低点；
- 是否守住 Listing Anchored VWAP；
- 是否出现开盘价 reclaim；
- 是否出现低点破位后无法回收。

硬规则：
1. 次日低开且同时失守 listing_open 与 listing_low，T1 Carry 默认降至 BLOCK；
2. 若随后在有效成交量支持下快速 reclaim，可从 BLOCK 恢复到 CAUTION，但不得直接恢复 ENTRY_READY；
3. 首日 VWAP 强势不能覆盖次日双锚失守；
4. 任何“强势”判断必须同时检查 close_location 与高点回撤。

## 二十、华大海天反例：伪强结构

华大海天作为 v0.2.0 的强制反例样本。

反例结论：
- 首日价格位于 VWAP 上方，不等于结构健康；
- 极端换手 + 弱 close_location + 高点回撤，可能代表筹码已充分交换但承接不足；
- 如果次日低开并同时跌破首日开盘价和首日低点，应视为 T+1 生存失败；
- 在这种情况下，前一日的 VWAP 强势不得成为继续持有或补仓理由。

该反例进入 regression_case 集合，后续每次参数调整必须重新验证，防止策略重新把“伪强”识别为高 Carry。

## 二十一、8 月至今 Historical Cut-Off 全样本回放

v0.2.0 将首批 8 个样本扩展为“8 月至当前日期的全部可得新股/次新股样本”。

回放步骤：
1. 以每只新股真实上市前一交易日为起点；
2. 生成当时的 LRRM / IPO Regime / Pre-Heat；
3. 从上市竞价开始逐分钟推进；
4. 每个时间点只能读取 cut_off_time 之前的数据；
5. 记录 Live Heat / T1 Carry / VWAP Structure / Decision 状态变化；
6. D+1 / D+2 / D+3 再逐日展开；
7. 最后才解锁未来收益用于事后评估。

每个样本至少输出：
- preheat_at_listing；
- first_entry_ready_time；
- max_heat_before_entry；
- t1_carry_close；
- D1_open_gap；
- D1_min_vs_listing_open；
- D1_min_vs_listing_low；
- D1_reclaim_status；
- false_entry_flag；
- survival_flag；
- blocked_by_rule；
- transition_log。

必须额外统计：
