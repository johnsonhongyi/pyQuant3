# 全网人气共振与 ATS 连板天梯、TDX 盘口双向挖掘与逆势破局龙感知全面升级实施方案

## 1. 目标与背景

当前 `popularity_resonance_gui.py` 与 `popularity_resonance_service.py` 仅依赖静态网页爬虫（东财、同花顺、淘股吧、龙虎大师），属于“事后看热度”的滞后结果呈现。实战中，**天梯与盘口异动是先验通道（因），全网热榜是合力确认器（果）**。

本次升级旨在：
1. **打通全链路**：将全网热度数据源直连 ATS 连板天梯引擎 (`ats/limit_up_engine.py`) 与 TDX 高频 API 盘口引擎 (`ats/tdx_realtime_fetcher.py`)；
2. **时钟自适应特征切换**：依据实盘交易时钟自动切换 5 大结构特征挖掘算子（竞价突破、秒级定龙、逆势破局、分时承接、尾盘锁仓）；
3. **大盘逆势破局龙感知 (Counter-Market Divergence)**：在大盘连续回踩缩量冰点期，精准识别外盘突发催化或跳空高开的逆势先锋（如深中华A、白银有色、海鸥住工等），计算逆势偏离度 ($RS = Pct_{个股} - Pct_{大盘}$)，打破大盘弱势犹豫；
4. **狭窄时间窗口三大黄金挂单点推演**：自动推演【买点 A（09:25 竞价定盘价）】、【买点 B（09:30 秒级抢跑回踩价）】、【买点 C（VWAP 均线支撑价）】并提示可参与时间窗口倒计时；
5. **双向共振决策与诱多过滤**：天梯先发探测 $\to$ 热榜跃升追溯验证 $\to$ 终极真龙确立，同时对“热度高但盘口卖压重/对倒出货”坚决拦截；
6. **GUI 毫秒级流式呈现与双向联动**：表头新增天梯梯队、买盘压强、逆势偏离、挂单决策列，支持键盘 $\uparrow/\downarrow$ 60ms 防抖直连 TDX/同花顺终端切屏。
