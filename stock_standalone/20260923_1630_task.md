# SBC 底部提示单双行抖动消除、重点数字涨红跌绿高亮与 Alt 切换新窗屏幕亲和度落地任务清单 (2026-09-23 16:30)

## 任务背景与核心目标
1. **底部提示信息抖动根治**：SBC 底部 `self.lbl_info` 文字因为内容过长或策略回测/测算更新时从单行变双行，导致整个窗口重新计算高度/布局抖动。必须彻底消除抖动；
2. **重点数字涨红跌绿突出显示**：底部提示文字中的关键数字（如交易笔数、胜率、盈亏、得分、介入价、止损、目标价等）要用 HTML 富文本进行涨红跌绿（红 `#ef4444` / 绿 `#22c55e` / 青蓝 `#38bdf8` / 琥珀金 `#f59e0b`）重点高亮显示，提升辨识度与专业质感；
3. **Alt 切换新窗口屏幕感知**：在 SBC 底部输入框按住 Alt 切换新标的开独立窗口时，根据当前 SBC 所在的屏幕打开新窗口并就地平铺重排，而不是都在主屏幕打开新窗口。
