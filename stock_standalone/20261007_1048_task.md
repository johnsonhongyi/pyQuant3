# 2026-10-07 10:48 inStock 非缓存机械硬盘I/O瓶颈根治与CPU 300%安全门禁

## 任务背景与目标
经底层硬件与拓扑审计，PVE 宿主机硬件构成确立：
- 系统盘：`sda` 32GB 电子盘（SSD）；
- 数据盘：`sdb` **WD Elements 4TB 外置 USB 机械硬盘（ROTA=1，5400 RPM，USB 接口）**，所有的通达信日K数据（`/data/InStock/instock/forwardp`）与缓存均挂载在此盘上；
- 机械硬盘具有随机寻道延迟高（8~15ms）、随机 IOPS 低（<100 IOPS）的物理特性，USB 传输协议更加剧了小文件寻道摩擦。
用户的核心需求为：
1. **彻底攻克非缓存时读写磁盘及内置磁盘性能硬伤**；
2. **严格将 CPU 控制在 300% 以下**（保留至少 1 个完整物理核心给底层 PVE 宿主机、iKuai 主路由及其他 Docker，确保网络转发与系统响应绝对安全）。
