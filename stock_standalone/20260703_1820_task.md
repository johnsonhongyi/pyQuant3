# Task: K线备份查看器 (KlineBackupViewer) 自动文件路径记忆与 HDF5 数据集快速切换 & 列表选中项一键诊断

## 目标
提升 PyQt 备份 K 线查看器 (`minute_kline_viewer_qt.py`) 的易用性，缩短用户多次重复打开文件、切换数据集以及诊断个股的操作路径：
1. **自动文件路径记忆 (Auto File Path Memory)**：点击 "Open File" 按钮时，文件选择对话框能够自动定位并预选最后一次成功打开的文件。如果当前未打开任何文件，则智能退避至历史打开记录（`file_history`）中第一个仍然有效的物理文件路径，避免用户频繁进行目录导航。
2. **HDF5 数据表快速切换 (HDF5 Table Switching)**：在工具栏 "Delete Table" 按钮左侧新增 "Read Table" 按钮，允许用户直接重新唤起当前 HDF5 文件的 Key 选择界面以切换不同的数据表，同时弹出的选择项列表能够默认高亮选中当前已加载的 Key。
3. **列表选中项一键诊断 (Fallback Selection Diagnosis)**：当用户在诊断个股的输入框没有手动输入代码，但已在左侧的摘要表、右侧的详情表或底部的完整结果表中点选了某只股票所在的行，点击“🔍 诊断”按钮（或直接回车）时，系统能够自动获取该列表选中项的股票代码并直接调起诊断报告，无需人工二次录入。

## 具体变更
1. **记忆最后打开的文件路径 (`minute_kline_viewer_qt.py` 中的 `on_open_file`)**：
   - 重构了 `on_open_file` 方法中 `QFileDialog.getOpenFileName` 的 `dir` 参数定位逻辑。
   - 提取 `self.current_file`，如果其物理路径存在，则作为文件选择器的起始路径。
   - 如果没有当前活动文件，则遍历 `self.file_history` 中的历史记录，优先匹配并使用第一个存在的文件路径。
2. **工具栏新增 "Read Table" 按钮与响应逻辑**：
   - 在 `KlineBackupViewer` UI 初始化中，创建并配置了 `btn_read_table` 按钮，绑定样式并将其插入到工具栏中。
   - 实现了 `on_read_table()` 成员方法，针对非 HDF5 文件进行提示，并在加载 HDF5 文件时直接通过 `self.load_data(self.current_file)` 唤起数据表加载与切换。
3. **优化 HDF5 数据表加载的默认选择**：
   - 重构了 `load_data` 方法中解析 `.h5` 文件的 `keys` 选择框。
   - 检测当前活跃的 `self.current_key`，如果其存在于该 HDF5 文件的 `keys` 列表中，则在弹出的 `QInputDialog.getItem` 对话框中默认选中其对应的索引。
4. **实现未输入代码时自动获取表格选中项**：
   - 重构了 `on_diagnose_click` 方法：如果 `self.diag_input.text().strip()` 为空，则调用 `_get_selected_code_from_tables()` 尝试提取选中行的股票代码。
   - 实现了 `_get_selected_code_from_tables()` 方法，依次检测 `self.summary_table`、`self.detail_table` 以及 `self.full_results_table` 的选择状态，从当前高亮的 `DataFrameModel` 中智能读取 `code` 列或首列的值作为选中的股票代码返回。
   - 若依然未选中任何股票，则弹出警告提示。
5. **编译与验证**：
   - 使用 `python -m py_compile` 工具对 `minute_kline_viewer_qt.py` 执行了物理编译校验，确认无语法或缩进层面的 Bug。
